## 0. 数据来源与口径局限

数据来自 2026-09-26 的一轮公开资料调研：五个平台榜（红果、抖音、快手、腾讯系与小程序、出海）共 512 行，加五份补充源（第三方周榜、官方/年度榜、社区盘点、AI 漫剧榜、AI 真人剧榜）733 行，按剧名去重合并成 916 部，再打分排出综合前 100。各平台口径互不相同：红果是站内"热度值"，抖音多是 DataEye 月播放增量，快手没有公开的单独榜单（只凑到 83 部，排序是跨口径的人工归档），腾讯/优酷/爱奇艺是分账榜，视频号几乎是黑箱，出海是 DataEye 投放榜；归一化只是粗略近似，不同平台的数字不能直接比。补充源加分的权重是人为定的，AI 头部剧的名次对它很敏感。**越播越涨、昙花一现这两个趋势标记只来自一个第三方周榜站**（6/1–9/7 共 15 期加 9 月 3 天日榜），全量 916 部里 642 部没有趋势标记，"没标记"不等于"不涨"；长青是代理指标（出到第 2 季以上、或在榜跨度 ≥6 个月、或进 2025 年度榜且 2026 年仍在榜）。形态和金手指仍有大量待核实（全量里形态待核实 380 部、金手指待核实 403 部），题材与金手指归类是关键词规则，会有误判。短剧市场按月变化，本文结论要**定期刷新（建议每季度一次，或平台政策大改后）**，刷新方法见 §9；距"数据截至"超过 3 个月时，立项引用本文要在决策记录注明"市场数据可能过期"。

## 2. 平台偏好与首发建议

| 平台 | 偏好题材 | 形态 | 金手指 | 其他特征 |
|---|---|---|---|---|
| 红果 | 修仙玄幻、萌宝团宠、系统逆袭（漫剧）；家庭、契约恋爱（真人） | 9 月总榜 TOP20 里漫剧 14 席，8 月漫剧百强全是 3D；AI 真人剧榜以年代、赶海赶山、断亲反击为主 | 系统/图录、废柴 + 外物、团宠靠山；真人头部多靠情绪设定、不靠金手指 | 按季快速连载（一两周一季）；漫剧用户男性约六成、18–34 岁过半；50 岁以上下沉用户吃年代与断亲 |
| 抖音 | 现实向：饭桌伦理、小本生意、职场维权、邻里纠纷、赶山赶海、年代 | AI 化最深：8 月原生百强里 3D 漫约七成、仿真人其余；真人很少 | 很多剧标明无金手指，爽点是"被欺负后拿证据或人品反转"；心声类性价比高 | 新剧短期扶持、衰减快，长尾弱；系列化靠快速出续季；平台政策在向真人和"真人 + AI"融合倾斜 |
| 快手 | 乡土家庭 + 泼辣女主、男频逆袭、当众揭露 | 以真人为主，漫剧在扶持期 | 83 部里 31 部没有金手指，偏"普通人当场反击" | 下沉用户多，偏"善恶有报"；免费看剧加广告为主；生命周期比抖音长（2–3 个月）；整治下架频繁，跟拍同名剧不稳 |
| 腾讯 / 小程序 | 古装宅斗权谋、赘婿穿越、悬疑罪案（爱奇艺）、东北喜剧（优酷）；投流端是"母亲/父母 + 逆袭" | 几乎全是真人（79/102），多为横屏精品 | 金手指密度低，靠制作质感和成熟套路 | 系列化有额外激励，续作最稳；视频号公开数据极少 |
| 出海 | 西幻狼人、兽世、龙族、神明；复仇 + 隐藏身份 | 仿真人（29）多于真人（17） | 隐藏身份/实力 + 当众打脸最通用；觉醒血脉次之 | 一剧多语种铺量；TikTok 剧场号偏猎奇 AI 剧，和 App 付费剧是两套生态 |

**首发平台建议**（drama-forge 产出的是 AI 剧）：

- 现实向题材（家庭、职场维权、年代赶山赶海、小本生意）→ 首发抖音，形态选 3D 漫或仿真人，单部打爆为主。
- 修仙玄幻、萌宝团宠、系统升级 → 首发红果，形态选 3D（`guoman_3d`），从立项起按"每季一个境界或一张地图"规划续季。
- 古装穿越 + 种田/科举 → 抖音与红果都能首发，是少数能跨两端的组合。
- 想做出海 → 西幻超自然或隐藏身份复仇，仿真人，规划多语种版本。
- 横屏精品、靠演员的情绪剧 → 不适合本流水线，不作首选。

## 3. 金手指长青度分级

判断标准只有一个：**爽点能不能持续再生**。每季都能在同一条规则下拿到更大的东西，就能续；亮完一次底牌就没东西可升级，就只能活一季。

| 等级 | 金手指类型 | 为什么 |
|---|---|---|
| 长青 | 系统 / 图录 / 轮回 | 自带一条看得见的进度条（收录数量、第几世），每季换地图就有新东西可收 |
| 长青 | 废柴 + 一件外物 | 外物本身不膨胀，膨胀的是主角能拿到的材料等级；每次变强都要先去弄材料，剧情自己长出来 |
| 长青 | 觉醒 / 血脉 / 数值 / 形态进化 | 数字或形态一直往上走，观众不看剧情也知道主角在变强；每个量级对应一批新敌人 |
| 长青 | 团宠护短 / 满级靠山 | 爽点来自"被偏爱"，不是升级；靠山可以一个一个登场，偏爱的对象和场合可以一直换 |
| 长青 | 古装穿越 + 种田或科举 | 家业、官职是阶梯，一季升一级；跨平台 |
| 中等 | 反差 / 倒练 / 装怂 | 笑点能再生，但同一个脑洞谁的画面好、集数多谁赢；2D 做不长 |
| 中等 | 收徒 / 开局封顶 | 主角不再升级，要把升级线外包给弟子，并靠"弟子遇险"制造紧张 |
| 中等 | 读心 / 心声 / 听物 | 成本最低、单部很强，但只有设定没有情感就会首周高、三周掉（《我靠听物成团宠》首周第一、第 3 周跌到 23 名） |
| 中等 | 契约 / 假关系、身份错位 | 真人能一年续一部，靠人物和情感，不靠规则升级 |
| 中等偏低 | 年代重生回档 | 单部能爆，重生的信息差用完就没了；仿真人长青率低 |
| 昙花一现 | 隐藏大佬亮身份 / 下山 / 归来 | 爽点在"亮身份"那一刻用完，后面没有可升级的东西；修仙里 10 部 0 部长青 |
| 昙花一现 | 一次性爆发（"退婚后一日连破七境"式） | 一口气兑现到顶，下一集没有更高的地方 |
| 昙花一现 | 借来的强（大 IP 角色出场兑现） | 爽感属于 IP 不属于剧；原创没法照抄，热度越高审查风险越大 |
| 昙花一现 | 跟风复制的设定 | 爆款出来后一天能冒出 5 部跟风（赖皮蛇之后的蛇题材），同质供给互相稀释 |

用长青型金手指不等于自动长青：还要满足 §4.3 的长篇不崩三要素。用昙花型金手指也可以做，但要么按单部打爆规划（不承诺续季），要么给它补一条可升级的进度条（例如隐藏大佬每季揭一层身份，而且每次揭的方式不同）。

## 4. 修仙玄幻专节

背景：红果 9 月 AI 真人剧榜里没有一部修仙，这个赛道几乎全是 AI 漫剧（尤其 3D）。头部 IP 改编占多数，原创漫剧破亿率只有约千分之五，供给已经过剩，所以修仙项目必须靠**视觉上能差异化的设定**和**续季规划**取胜，而不是台词换花样。

### 4.1 升级线结构（节拍）

- **一集一次小兑现**（1–2 分钟一集）：斩一只妖、强化一株药、数值跳一格。第一次兑现不晚于 EP001 第 60 秒，可以是私人的爽（只有观众看见），但必须画面上看得见。
- **3–5 集一次公开打脸**：一个欺压单元或一个秘境结束时，由之前看不起主角的人亲眼见证。
- **一季（80–140 集）一次大境界突破 + 一次身世揭露**：明线是境界，暗线是身世；季末两条线同时推一格，作为下一季的钩子。
- 慢爽也能做（《凡人百世书》一世一大爽），前提是有一个贯穿多世的明确仇人；不适合当冷启动模板。

### 4.2 打脸对象升级梯

身边人（同门杂役、同班同学、亲戚）→ 本地势力（地方妖王、城中大族）→ 宗门 / 官府 / 圣地 → 更高位面（灵界、天庭、古神）。每升一级都**换地图、换反派阵营**，至少写出 4 级。最高一层用虚构的天道、仙庭、古神，不用真实宗教的神佛本尊。

### 4.3 长篇不崩三要素

1. **世界观能一季一季扩**：每季一张新地图（新州域、新妖庭、新秘境），有原著时沿用原著世界观。
2. **至少一条跨季的情感线或因果线**：例如收录进图录的妖带着没了结的因果，隔几季回来找主角。
3. **升级线可以外包**：主角封顶后由弟子、族群、搭档承担升级；主角本人保留"明线升级 + 暗线身世"两条线。

### 4.4 集尾钩子三类

- **胜负未分**：战斗停在半空。
- **真相揭一半**：回放还没放完、身份差一步揭晓、证据出现但没打开。
- **更强的人登场**：系统发新任务、上一级反派露脸、新威胁上门。

每集结尾用一种，不连续两集用同一种；最后 5 秒停在"下一秒就要发生"。

### 4.5 禁区

- **不碰真实宗教的神佛本尊**：《菩提临世真人 AI 版》4 月登顶红果总榜，4 月底因被举报侮辱宗教、煽动宗教对立、血腥暴力而全平台下架，时间点在 AI 漫剧备案新规发布后不久。打脸层级顶到天花板时换成虚构神系。
- 台词可以狂，但不挑衅真实信仰，不写粗口式的藐视天道。
- 不用明星脸或仿冒真人形象；不做未授权的网文 IP 改编（番茄新规已让未授权改编的 AI 创作者停更）。
- 热度越高越容易被审查，合规检查在写剧本时就做，不留到上线后。

### 4.6 3D 优于 2D

同一个"不识字倒练功法"设定，3D 的《谁让这个文盲修仙的》做到第 4 季、7000 万量级热度，2D 的《倒练三年》两季后下滑；红果 8 月漫剧百强全是 3D。修仙项目默认选 `guoman_3d`（[styles.md](styles.md) §7），不要选 2D 平涂。

### 4.7 续季打法

- 立项时就按"每季一个境界或一张地图"切分，不按单部剧想；AI 的成本结构允许一两周出一季，这是真人剧做不到的，也是 AI 漫剧长青的核心。
- 每季开头重新校准角色参考图和风格句，保证跨季人物形象一致（观众吐槽集中在表情生硬和更新慢，不在剧情反转）。
- 身份揭晓型单元每次换一种揭晓方式，否则第三次就腻（《糯糯下山》相认情节被批复制粘贴）。

### 4.8 AI 好拍与难拍

- **好拍**：审判 / 回放结构（一个固定场景 + 大量反应镜头）；数值面板、计数器、图录点亮（后期叠加，见 [styles.md](styles.md) §12，生成画面不出字）；形态进化（每个形态一张参考图）；一击秒杀（蓄力、光效、倒地三个短镜头）；群体下跪或震惊的静态反应镜头；天庭、山门、云海空镜；现代场景里的修仙大佬（客厅、医馆、祠堂）。
- **难拍**：长时间来回过招（拆成 2–3 秒短镜头，用反应镜头穿插）；多人同框群战；萌宝的细腻表情和口型；喜剧节奏（靠剪辑补）；持物连续性（巨剑、盆、令牌每镜重申）；跨季人物一致。

## 5. 越播越涨与昙花一现的共性

**越播越涨**（全量 28 部，只对进过第三方周榜的剧有效）：

- 已知形态的基本是真人剧；题材以爱情情感、古装、家庭伦理为主。
- 首周起点不高（首次上榜名次中位数约第 15），靠口碑一路爬到第 7 左右，不是投流冲出来的首周峰值。
- 金手指弱或没有，靠情绪和人物（《好雨知时节》《勇敢后妈，专治不服》《昼以继夜》）。
- 情感比设定耐看：认亲测人心类剧从第 19 名涨到第 7 名，而只有设定的《我靠听物成团宠》三周就掉出前二十。
- 对 AI 剧来说，现实的"越播越涨"路径是**一季比一季热的续季**（AI 漫剧里唯一在榜上上涨的《废物垫底皇子，反倒成为千古一帝》靠的是第 2 季）。

**昙花一现**（周榜标记 172 部，是常态）：

- 首周靠投流冲高，第二周就掉出 TOP20，是真人短剧的主流曲线；爱情情感和都市最多。
- 金手指是一次性亮底牌（隐藏大佬、一次性爆发），亮完没东西可升级。
- 只有设定没有情感，或者是跟风复制的设定。
- 评估一部剧不能只看首周，至少看第 2 到第 3 周还在不在榜。

## 6. 开头 1 分钟通用结构与"照这个水平写"检查清单

两份热榜拆解（热榜 12 部、修仙 12 部）的开头秒数大多是根据简介和投放切片重建的估计值（误差按 ±10 秒理解），下面是去重后的通用结构。drama-forge 的 B1 前 3 秒钩子仍然优先，下面的时间段是在它之后展开。

| 时间 | 该发生什么 |
|---|---|
| 0–10 秒 | 反常或最惨的画面，抛出"为什么会这样"：被按在刑台上、婚礼上当众宣布、觉醒测出最低级、儿子要跳楼。不交代背景，不从日常慢慢铺 |
| 10–30 秒 | 死局或当众受辱：观众看得见是谁在欺负主角，有围观者，最好伤及家人或主角最在乎的东西 |
| 30–45 秒 | 金手指激活，规则一句台词讲完，同时带出一个限制 |
| 45–60 秒 | 第一次兑现，画面上看得见（数值跳、光效、对方倒地、形态变化），只给一小口，留更大的一口 |
| 最后 5 秒 | 停在"下一秒就要发生"：胜负未分 / 真相揭一半 / 更强的人登场 |

**检查清单**（写完 EP001 或一个开头逐条过，少一条就改）：

开头
- [ ] 前 10 秒是反常或最惨的画面，不是街景、起床、旁白介绍
- [ ] 前 30 秒主角有生命危险或当众受辱，欺负者和围观者都在画面里
- [ ] 30–45 秒金手指激活，规则一句台词或一个画面讲清
- [ ] 60 秒内第一次兑现，画面可见，只兑现一小口
- [ ] 第 1 集最后 5 秒停在"马上要发生"的地方

金手指
- [ ] 一句话讲得清，能拍成一个画面，观众刷到切片 3 秒内能懂
- [ ] 有明确限制或代价，能写出"主角为了下一次变强必须去做 X"，限制在前 3 集给主角制造过麻烦
- [ ] 有一个视觉上一眼看得出变强的机制（数值、形态、图录、材料等级）
- [ ] 考虑过"身边的人强"或"人格强"：2026 年的新趋势是靠山型和性格型金手指，爽感更温、观众更广
- [ ] 对照 §3 标出长青度；昙花型要么按单部规划，要么补一条进度条

爽点与打脸
- [ ] 一集（1–2 分钟）一次小兑现；3–5 集一次公开打脸；大爽点（身份全揭晓、大境界）憋到第 10 集以后或季末
- [ ] 前 3 集内有第一次公开打脸，由之前看不起主角的人亲眼看着
- [ ] 打脸阶梯至少 4 级、逐级往上，每级换地图或换反派阵营
- [ ] 反派贪一件具体的东西（家产、拆迁款、位置、成果），损失具体到画面（跪、断、夺、秒、失去位置）
- [ ] 最高层级敌人是虚构的，不碰真实宗教神佛，台词不挑衅真实信仰

人物与情感
- [ ] 主角性格一句话说清，而且性格本身能制造爽点或笑点；反派可以蠢，主角绝不被剧情降智
- [ ] 至少 3 个能单独产出冲突或笑点的配角（群像比单 CP 好续）
- [ ] 有一段让后面的爽有正当性的情感戏（认亲、亲情、被护短）；至少一条跨季情感线或因果线

台词与集尾
- [ ] 短句、直球、狂而不脏，信息先行；没有大段世界观独白，每句都在推进冲突、给笑点或交代规则
- [ ] 至少一个角色的说话方式让人记得住（方言、辈分错位、口头禅）
- [ ] 每集结尾是三类钩子之一，不连续两集用同一种

## 7. 对做 AI 短剧最有用的 12 条结论

1. **AI 剧已经是榜单头部**：综合前 100 里 AI 剧 40 部，前 10 里占 9 部；抖音和红果月榜头部的真实体量（单月十亿级播放增量）主要是 AI 剧。
2. **AI 漫剧三个首选组合**：跨抖音红果选"古装穿越 + 开荒种田或科举"；红果长线续季选"修仙 × 系统/图录"或"修仙 × 废柴 + 一件外物"；女频选"萌宝/团宠 × 满级靠山护短"。共同点是金手指能直接画出来，而且能一季一季升级。
3. **AI 仿真人选"年代 × 重生回档"或"家长里短 + 弱金手指"**，出海选"西幻狼人 × 觉醒血脉"或"复仇 × 隐藏身份"；仿真人长青率只有 5%，而且份额在被 3D 漫挤压，按单部打爆规划。
4. **修仙里长青的是能不断升级的金手指**（系统、外物、血脉数值、团宠），昙花一现的是一次性亮底牌（隐藏大佬下山、一日连破七境、纯重生开局）。
5. **越播越涨靠口碑和情绪**，首周起点不高、金手指弱；AI 剧的现实路径是一季比一季热的续季。
6. **昙花一现是常态**：评估不能只看首周，至少看第 2 到第 3 周。
7. **高频续季是 AI 漫剧的核心打法**：真人一年续一部，AI 漫剧一两周出一季（12 季、30 多季），立项就按季规划。
8. **平台分工清楚**：抖音 AI 化最深、偏现实向；红果是 3D 修仙和团宠续季的主场；腾讯/小程序几乎全是真人；出海仿真人多于真人。AI 剧首发优先抖音（现实向）和红果（修仙、团宠续季）。
9. **官方/年度榜和商业爆款基本是两套名单**：想兼顾过审和流量，已验证的交集是"年代家庭 + 方言 + 温情"，AI 仿真人也能走。
10. **社区口碑最高的是反套路加现实逻辑爽**（靠证据、法律、规则赢）；AI 漫剧口碑的关键是表情和更新节奏，不是剧情反转。
11. **读心 / 心声是性价比最高的差异化点**：用字幕和画外音就能演，几乎不加生成成本，能叠在家庭剧、萌宝剧上；但要配情感线，否则三周就掉。
12. **三个坑**：2D 不如 3D；仿真人不用明星脸、不碰真实宗教和敏感 IP（上万部 AI 剧被回查下架）；数据空白多，趋势结论只看方向，不当定量结论。

## 9. 如何刷新

原始调研与合并脚本不在 skill 里，在 `~/Desktop/ai-drama-skill-refs/_reports/top100/`：

- 五个平台榜：`hongguo`、`douyin`、`kuaishou`、`wechat-tencent`、`overseas`，每份一个 `.csv`（数据）和一个 `.md`（口径说明、来源清单、平台特征观察）。
- 五份补充源：`extra-weekly-3rd`（第三方周榜，趋势标记的唯一来源）、`extra-official-annual`、`extra-community`、`extra-manju`、`extra-ai-live`，同样各一对 `.csv` / `.md`。
- 合并脚本 `merge_top100_v2.py`（只用标准库，装了 `openpyxl` 时顺带导出 `.xlsx`）；v1 脚本 `merge_top100.py` 保留不动。

刷新步骤：

1. 按各平台原来的口径重新抓公开榜单，沿用原 `.csv` 的表头；每份 `.md` 更新口径说明和来源（每条带来源和日期）。抓不到的名额不要用猜测补齐，字段写"待核实"。
2. 把上一版结果另存为 `ALL-top100_v1.csv` / `ALL-top100_v1.md`（脚本用它算名次变化；原来的 v1 文件先改名备份）。
3. 在该目录运行 `python3 merge_top100_v2.py`，产出 `ALL-top100.csv`、`ALL-top100.md`、`ALL-top100.xlsx`。新发现的别名（错字、缩写、续季副标题）加进脚本里的 `ALIAS_RAW`；补充源权重是脚本顶部的 `W_*` / `CAP_*` 常量，改权重要在报告里写明。脚本里的 12 条结论是写死的文字，只有数字会跟着变，要人工重读改写。
4. 裁列复制到 skill（只保留公开信息列，`YYYY-MM` 换成数据截至月份）：

   ```bash
   cd ~/Desktop/ai-drama-skill-refs/_reports/top100 && python3 - <<'PY'
   import csv, re
   rows = list(csv.DictReader(open("ALL-top100.csv", encoding="utf-8-sig")))
   dst = "<skill 根>/drama-forge/assets/market/YYYY-MM-top100.csv"
   cols = ["综合排名", "剧名", "平台", "形态", "题材", "金手指一句话", "趋势", "上线时间", "数据来源"]
   src = lambda s: "；".join(p.strip(" ；;") for p in re.findall(r"来源[：:]\s*([^\[]*?)(?=\s*[；;]?\s*\[|$)", s))
   with open(dst, "w", encoding="utf-8-sig", newline="") as f:
       w = csv.writer(f); w.writerow(cols)
       for r in rows:
           w.writerow([r["综合排名"], r["剧名"], r["上榜平台"], r["真人/AI"], r["题材归类"],
                       r["金手指一句话"], r["趋势标记"], r["上线时间"], src(r["代表数据+来源"])])
   PY
   ```
