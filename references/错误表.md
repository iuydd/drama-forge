# 实拍错误表 E1–E40

生产（F–J）开工前读一遍；每条是实拍踩过的错和以后的做法。新发现的错照同样格式追加，编号接着往下排。

| # | 错在哪 | 以后怎么做 |
|---|---|---|
| E1 | 队列开跑后才改 refs.json，`produce.py refs` 启动时已读入全部提示词，后面出的图仍是旧描述 | 改参考图提示词前先 STOP 队列；改完对已排队未出的 ID 也 `--retake`，出图后核对是新描述 |
| E2 | 设定改了（锈剑→神剑），分镜生成器和 shots.json 仍残留旧词，起始帧照旧词画 | 设定变更后对剧本、视觉设定、refs.json、生成器、shots.json 全部 grep 旧词，清零再出图 |
| E3 | 过肩双人镜给前景听者挂了头肩参考图，模型把主角画两次 | 双人镜写「两人并排一左一右」；过肩时前景只露背、肩、后脑，不挂头肩图；只多人时可裁切回 16:9（不许镜像） |
| E4 | 要求第三人「后景虚焦背对」，模型两次把他拉到前景正脸 | 多人写死 `exactly N figures`、逐人写位置朝向，不写弱存在；不参与的人不入画，写明在画外哪侧 |
| E5 | 揭晓镜手指指错物件、反派该在门外却站店内 | 写限定构图（只拍这一件的特写、隔门往外看），不写要模型数位置的句子 |
| E6 | 状态变化（一缕白发）在近景里被画没，与下一句台词穿帮 | 状态在 frame_prompt 和 video_prompt 各写一句可见描述，不只靠参考图 |
| E7 | 同一人前后镜脸和胡须漂移 | 近景绑头肩图（G38），提示词写年龄与标志特征；不写「和上一镜同一个人」这类回指 |
| E8 | `audio_from` 不写 filter 默认 phone，同场喊话被压得听不见 | 同场画外声写 `hall` 或 `none`；听筒用 `phone`，隔门墙用 `glass` |
| E9 | 接收镜已自带画外那句，又从音源镜垫一遍，同句出现两次 | 先听接收镜原声；已自带就删 audio_from，字幕走 overlay，音源镜 drop |
| E10 | 整片 ASR 在静音段幻听重复前句，像多出对白 | 可疑段单独切出开 `vad_filter` 再转写，确认无人声才过；时间戳会偏，对照剪辑单定位 |
| E11 | 队列跑完没人接手，接口空转一夜 | 每条后台队列配「跑完唤醒主会话」的等待；队列之间用锁文件接续 |
| E12 | 断网（BrokenPipe），脚本停在 submission_intent | 查供应商任务列表：无新任务 → `reconcile --not-submitted` 附证据；有 → 用任务号 collect；绝不直接重投 |
| E13 | fal H3 Max Turbo 偶尔把 `<d>` 里的中文台词画成烧入字幕 | 逐镜看帧下沿有没有字；有就换 take，不接受烧字版 |
| E14 | 中文字幕大量方框：默认日文字体缺简体字 | 已修（zh 优先 Hiragino Sans GB / PingFang）；新语种先剪一小段看字幕 |
| E15 | `max_takes=3` 在 fal 下挡住便宜的重拍 | 上限不擅自调高；不承担剧情的缺陷才可 weak 写 acceptance_reason；承担剧情的改写或改分镜，用尽就暂停正式成片、记未决 |
| E16 | 台词情绪只写「furious, loud」，模型只会大吼，听不出气、委屈、恐惧 | 表演写四层：内心（情绪与原因）、声音质感、重音与节奏、脸；`shouts` 只在真喊时写且带前两层 |
| E17 | 把「能看懂」当放行标准，一批 weak 镜直接进成片 | 用户要细节时每个 weak 改写法重拍；换写法仍做不到且不承担剧情的才留 weak 并单列汇报 |
| E18 | 台词提到别人的白发，模型把白发画到本镜这个人头上 | 状态词只写在拥有者的镜头里；别人的镜头换说法，并正面写本人发色 |
| E19 | 同场 20 多镜同一底板、同一机位、镜头不动，整集像静态对话 | 每场 3–4 种背景视角，相邻镜不用同一视角；有动机的镜写一个具体运镜，对白镜默认锁定；每场一个建立远景 |
| E20 | 为赶开幕把开头挤成一串结果：冲突无起因、剑凭空出现、坠落从容、会飞没解释 | 遇险前至少一镜交代在哪、为何冲突；金手指道具先被看见；表演与处境一致；超常结果用台词或画面说明机制 |
| E21 | 同场连续镜人物站位互相打架，各镜挂不同底板 | 分镜每场先写站位表，逐镜继承上一镜终态；同站位同底板；审片把本镜与前后镜首末帧并排看，不连续判 retake |
| E22 | 上一镜已完全坠落，下一镜却挂在崖沿；人摆好姿势等被推 | 每镜终态等于下一镜起始状态；动作镜第一帧就在动作中 |
| E23 | 跨镜运动速度变了（快坠变缓降）；人物离场横穿平台不走石阶 | 跨镜运动每镜重写速度与环境证据；人物移动走场景里真实存在的路线 |
| E24 | 重拍在提示词末尾追加补丁句，与底板空间矛盾，连续出错 | 禁止打补丁：单一变量只改原位写法；两次仍失败按封闭世界整段重写（先看底板→空间布局→人物位置朝向与动机→姿态四层→参考图分工） |
| E25 | 衔接动作没拍到，靠收出点遮掩，观众仍接不上 | 收出点不算修好；衔接动作必须在画里发生；本镜出点帧与下镜入点帧并排看要物理连得上；重拍写死运动轨迹和结束状态 |
| E26 | 审片 ASR 开 VAD，把台词前模型自编的乱语过滤掉，报「台词齐」 | 审片 ASR 再关 VAD 跑一遍（`condition_on_previous_text=False`），两遍结果路径写进 evidence；区间内剧本外人声即 asr_ok false |
| E27 | 三镜合成一条 15 秒多 shot：不按秒数走、晚开口、第三段被挤掉 | 不用 15 秒多 shot，单镜约 5 秒（台词多到 7–10 秒）；fal 时长向上取整、不足 5 取 5 |
| E28 | 用户列的问题只修一部分就汇报完成 | 逐条对账写修法、证据、结果；没修好明说「还没修好」 |
| E29 | 别的会话改 skill 脚本到一半，本会话 cut.py 报 ImportError | 不动别人未提交的改动；用 `git archive HEAD` 导出已提交版本到 scratchpad 跑 |
| E30 | 分工句写「Picture 1 as a soft out-of-focus background」，模型把底板当背景板，人站到云上 | 分工句改为「Picture 1 is the real place… every foot rests on solid ground」；先看底板再写人站哪；目检查脚下是不是实地 |
| E31 | 短句写句中停顿，H3 在停顿处补字、重复重音词；省略号同样被当停顿 | 短句写「one smooth unbroken breath… each syllable said exactly once」；`<d>` 里省略号改逗号或删（字幕仍按剧本）；复听关 VAD |
| E32 | 用户拒绝一次工具调用时 produce videos 其实已提交计费 | 被拒或中断后先查账本：`h3_client.py unresolved`，submitted 未 collected 的逐条收回，只有 intent 的按 `--not-submitted` 对账；如实报已花费 |
| E33 | 台词镜大量单人、听者在画外，人对空气说话；各镜起始帧各自生成不连贯 | 默认听者入画；单人对白要有建立镜并写 `single_reason`，预演读不出对象就退回同框；出帧默认用已核验底板、身份图或父起始帧 |
| E34 | 远景重新建轴镜漏写在场的人和朝向，成片少人、朝向全乱 | 远景/建立镜列出此刻在场全部人物 `exactly N figures, each once`，逐人写位置朝向并继承上一镜；目检逐个数人头、核朝向 |
| E35 | 画面逐项「看着对」但不合常理（手按剑喊剑沉、凭空的手、人消失又出现、坐在悬空横杆上、牢房套牢房） | 审片每镜答常识七问：因果、在场名单、完整身体、支撑、空间结构、路线、状态延续；提示词写明谁在栏内外、手属于谁、离场的人 not present |
| E36 | 「湿砖打滑摔倒」四条都拍成人走出画面；攻防修到 v4 才拍出，但摔得像慢慢坐下 | 动作拍不出先查提示词、走攻防：朝向写死、方向用实物加画面侧、位移可量、一个时间窗一个动作、倒下写画内证据、终点姿态写死、锁机位写全；物理镜头写速度、失控和落地 |
| E37 | krea2_turbo 挂餐厅底板换角度，出来是另一个房间 | krea2 只当风格参考；带底板/父帧的起始帧用可编辑档位（qwen21）；每个机位先派生自己的底板并目检，要直接换角度须满足 rules-detail 6d 三条 |
| E38 | 正面双人镜写「他抓着她的椅背」，两轮都在他身前多画一把椅子 | 抓/按椅背这类接触改用从被抓者背后的插入镜；正面双人镜里手不碰椅子；失败两次直接改插入镜 |
| E39 | 中近景人物身后多出第二张餐桌 | 写「exactly one dining table… behind them only…」并收紧景别让桌沿在画面下沿；仍复现换同向底板或改不挂底板的近景 |
| E40 | 全部门和审查通过，用户看片：第 2 镜像换了场景、台词接不上、三只手、同一人两次、身体穿桌 | 执行 SKILL.md 五条硬规则：盲看复述、一场戏一个空间、少镜头、`frame_dump.py` 逐帧原图审片加独立子代理、粗剪通看复述 |
