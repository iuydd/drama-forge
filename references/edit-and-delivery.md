# 剪辑与交付

阶段 J 读本文件。来源：实战项目的剪辑脚本（通过实战的出点、字幕、印章字、响度做法）、本地 `short-drama-edit`（可用带先于入出点、字幕取剧本转写只定时、verify 只报数字）。

## 1. 输入与顺序

`cut.py <项目> EP001` 读三样：`shots.json`（镜序、台词、叠加）、`审查/EP001-review.json`（take、in/out、mode、verdict、speed）、`脚本/asr_cache.json`（词级时间）。`cut_order` 存在时按它排，否则按 shots 顺序。verdict 为 drop / missing 的镜跳过；mute 的镜去原声。每段重编码到项目画幅与帧率后 concat，再叠字、混音、归一。

## 2. 出点规则

| mode | 出点 |
|---|---|
| after_last_word（有台词默认） | max(review.out, min(素材 − 0.1, 末词结束 + 0.5))；有印章字时尾巴 = hold + 0.1 |
| to_end（留白结尾） | 末词结束 + 0.02 |
| fixed | review 里的 in/out |
| full（无台词默认） | 素材 − 0.2（生成素材片尾常有回弹或异常帧） |

入点默认 0；模型看图后按可用带收紧。段长 < 0.5 秒的镜跳过并打印。

## 3. 字幕

- 文字逐字取剧本（`dialogue[].text`），不信 ASR 的字，只信它的时间。
- 时间：每句先用 ASR 词序列按文字对齐（`align_phrases`），对不上的句子再按字数比例落在 [首词 − 0.1, 末词 + 0.25] 里；没有 ASR 时落在段长的 20%–80%。
- 样式：底部居中，白字黑描边加投影，≤16 字 50px，否则 40px；按像素宽自动换行，优先在标点后断。字体候选在 `drama.json` 的 `fonts.sub`，默认 Hiragino / PingFang / Noto CJK。
- 双语字幕（日语台词配中文）：剧本里先有译文，作为 `dialogue[].subtitle` 另给；没有就只出原文。

## 4. 后期叠加

- 生成画面里不出任何字；所有字都在这一层。
- `text` / `panel`：画面中上部（30% 高），58px，白字描边；多条按段长均分依次出现，或用 `at` / `until` 指定；有录音垫入的镜等录音放完（42%）再出。
- `stamp`（印章字，例如一个代表"谎言"或"命中"的大字）：`drama.json.overlays.<name>` 定义字形、字号、颜色、发光、透明度、hold、位置比例、抖动。亮起时机 = 谎的那一小句最后一个音落下（`overlay.phrase` 用 ASR 词序列对齐；没写 phrase 才用整段末词），停 hold 秒，本镜内淡出，不跨剪辑点；放在说话人脑后留空的一侧（`side: L/R`，起始帧构图要留出这块空位）。
- 系统面板类叠加同理，位置固定在画面一角，用 `panel`。

## 5. 声音

- **录音垫入**（`audio_from`）：从另一镜的对白抽音，加 phone / hall 滤波后按 `at` 垫进本镜；字幕跟录音走。
- **环境声**（`drama.json.beds`）：按场景映射到 wav，循环铺底，默认 −18 dB；同场相邻镜底声一致。
- **配乐**：属于时间线层，成片阶段统一加；生成里一律 `non_diegetic_music: N/A`。
- **响度**：整体归一到 `loudness`（默认 −16 LUFS）+ 限幅 0.8；用编码后的成片实测 LUFS。

## 6. 冷开场与剪辑单

- 冷开场不新生成：`cut_order` 把本集最强的一句（兑现或亮红）放到片头，再黑场接第一场。
- `剪辑单.md` 由 cut 自动写：每段的镜、take、取用、时长、成片位置、字幕、叠加、结论，末尾总长。它是成片的账，不是创作文档。

## 7. 交付核对

只报数字，不冒充质量结论：成片时长与目标差值；画幅帧率；LUFS 与真峰；每段平均亮度。再对成片跑一遍 ASR，比对全集台词表，漏句就回到该镜的取用区间。台词完整性、画内文字、边界帧没测就写"未测"。

## 8. 已知坑

- Homebrew 的 ffmpeg 没有 libass，烧 ASS 字幕会失败；本工具用 PIL 出 PNG 再 overlay，不依赖 libass。
- faster-whisper 不在系统 Python 里：`ASR_PY` 指向装了它的 python（例如 `~/.venvs/asr/bin/python`；不设则自动扫 `~/.venvs/*`）；模型 `ASR_MODEL` 默认 medium，快测用 tiny。
- 印章字字体：macOS 的教科书体/凸版文久明朝在 AssetsV2 里，Linux 用 Noto Serif CJK；找不到就退到字幕字体。
- H3 无台词镜会自编人声：审片标 mute，剪辑去原声后用底声补。
- 生成素材片尾 0.1–0.2 秒常有异常，full 模式默认去掉 0.2 秒。
