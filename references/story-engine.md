阶段 A（系列简报）和 B（情绪集纲）读本文件。它整合了原 short-drama 开发套件的故事方法（承诺、冲突引擎、商业爽点、前提装置、机制循环、分集契约、揭示与反转）、su-ai-short-drama 的男女频故事引擎、shuohao 的爽点表和 AI-drama-pound 的验证方法，规则只在 drama-forge 内维护。本文件够写出一部能追看的商业爽剧；另有三份配套参考：

- 有小说、网文或多集原稿要改编：[adaptation.md](adaptation.md)（原著拆解、改编契约、回原文取细节）。

## 0. 立项：新颖度与爽感（先于四问）

用户的口味：点子要新颖、吸引人，最重要是让观众爽；老套点子没人想看，做出来等于浪费钱。过去五个点子（看破谎言、摸物知价、挨打到账、强制说真话、短时回溯）全是"主角多一个感知/信息能力 → 当场打脸"同一形状。所以四问之前先做选点子这一步，完整做法在 [premise-novelty.md](premise-novelty.md)：

1. **饱和设定清单**（§1）：上面五个，加读心/心声、系统面板、重生复仇开局、赘婿/战神/退婚、霸总傻白甜、隐藏大佬靠亮令牌兑现等。可以用，但必须带新内容（新内容 = 新规则/新限制、新代价、新视角、新的兑现方式、新的反派反制循环、与另一引擎的新组合、新的世界观/职业承载，至少一项）；用了就在候选表"新在哪里"一栏写清观众在前 3 集能看出的具体差异，只换皮不算，记决策记录。
2. **同质化一句话测试**（§2）：能压成"主角多了 X 能力，所以当场揭穿 Y"，说明还没有新内容；补上新内容再进打分。
3. **≥6 个候选**（§6）：用 10 种生成法（§3）和不靠感知外挂的爽感引擎（§4）出候选，两两机制不同，感知/读取类最多一个；每个写一句话钩子、前 3 秒画面、爽点兑现方式、秘密 + 时钟 + 见证者、新在哪里（用了饱和设定时必填）。
4. **打分选一**（§7）：按爽感检查表快筛 7 项（写作者与 reviewer 盲打各一份）、按两份之和选最高分，再对入选点子全表打分（前 3 秒钩子、第一次兑现时间、兑现可见性、反派损失可核对、群体见证、以弱胜强、期待—兑现间隔、每集新问题、不靠能力碾压也成立等）。候选表写进系列简报 `## 立项候选`，打分表写进 `## 爽感打分`；`project_tool.py next` 缺这两节会 warn。

**出候选之前先查市场**：[market-hits.md](market-hits.md) 给出 2026-09 的题材 × 金手指 × 形态矩阵、平台偏好、金手指长青度分级、修仙玄幻专节和开头 1 分钟检查清单。先定目标首发平台和形态，每个候选在候选表"对标爆款 / 长青度"一栏标注对标的爆款组合和长青度；爽感检查表的 A7（有长青先例）、A8（平台与形态匹配）按它打分。它是市场参考，不替代上面的新颖度要求：对标组合照样要写清新在哪里。

选定点子之后，再用下面 §1–4 把它落成四问、主类型、冲突引擎和装置条款。

## 1. 先定观众要什么

"一个被看不起的人逆袭"不够。写系列简报之前先答四问，答案要落到动作和物件上：

1. **观众替主角受什么气**：被抢功、被背叛、被羞辱、被剥夺机会。具体到"被删掉的署名""被推离桌子的椅子""当众被拿走的手机"。
2. **观众盼着什么结果**：当众打脸、夺回利益、让对方后悔、获得别人得不到的偏爱。写清落点是**关系**（他意识到弄丢了什么）、**位置**（没有我你什么都不是被当众证实）还是**认知**。落点定了，哪些事件算数就定了。
3. **主角凭什么能做到**：身份、能力、证据、资源、信息差。观众要在受气段之前或之中先看见一角，否则反击像作者塞来的。
4. **这一轮兑现多少，下一轮更大的期待是什么**：全兑现则追看动力归零；每轮兑现一部分，兑现本身长出更大的问题。

再选**一个**主爽点类型，辅类型只做调味：

| 类型 | 观众真正想看的 | 容易写坏的地方 |
|---|---|---|
| 身份打脸 | "你看不起的人，其实比你强得多" | 身份迟迟不揭，主角反复受辱而不出手 |
| 智斗复仇 | "你以为占了便宜，其实已经入局" | 主角靠临时塞来的证据取胜，观众没见过布局 |
| 能力碾压 | "别人做不到的，他轻松做到" | 只有旁人夸厉害，没有别人能当场核对的结果 默认只作辅类型，除非 premise-novelty §7 A4"不靠能力碾压也成立"得 2 分 |
| 资源升级 | "原本稀缺的东西，现在我有了" | 只有数值增长，处境、关系和别人的态度没变 |
| 甜宠 / 关系拉扯 | "别人不被选择，偏偏选择我" | 反复误会不推进；解除误会后没有残余 |

题材 = 核心题材 + 1 个次类型 + 1 条差异化规则，差异化规则要在全剧至少影响三次关键决策，否则它只是标签。主类型说"观众要什么"，题材卡说"这类戏通常怎么拍"：选定后按 [genre-cards/索引.md](genre-cards/索引.md) 取主题材那一张卡校准压力来源、场面颗粒和制作难点（跨题材时主卡读全、辅卡只摘一两条）。题材卡只在内部校准用：用了哪张卡记进决策记录，卡名、置信度、"已按题材卡执行"之类的字样不写进系列简报、集纲和剧本。

**情绪流还是剧情流**：观众追的是"他什么时候信、认、跪"，是情绪流，按 §9 的升级刻度排往返回合；追的是"接下来会发生什么"，是剧情流，按信息阶梯排（[genre-cards/悬疑规则.md](genre-cards/悬疑规则.md) 多集结构）。混合剧主线走一种，另一种只调味；选定哪种写进决策记录。（取自 short-drama-factory）

**回报先有舞台，再有能力**：观众期待的不是"主角得到了什么"，而是"得到之后，那些人会怎样"。所以先让观众认得回报会花在谁身上、什么场合、哪句话上，再让主角拿到能力、证据或身份；三样里至少先立起一样。能力先到、再临时找个人来被打脸，这段再热闹也不解气，因为观众事先不知道该盼什么。确实需要新对象时，先给它一拍独立的建立，不和兑现在同一场第一次出现。

**可生成性预算**（立项时在系列简报里写一行，reviewer 核对；超预算先改点子——合并角色、合并场景——不留到分镜阶段硬扛）：[社区][自测]
- 每集有台词的角色不超过 4 个；首场有名有姓的人物不超过 3 个。
- 每集主场景不超过 3 个，多出来的场景必须能复用已有底板。
- 核心冲突尽量落在两人之间：台词镜的听者要入画（两人同框或听者背影在前景，SKILL 硬约束 11c），接触动作（撞、递、抓、让开）两人同框，每场接触镜不超过 3 个，超了就改剧情、减少接触动作，不把多出的接触拆成单人镜凑数；不写需要三人以上同时同框才能读懂的群戏（人越多模型越容易多画漏画）。
- 关键情节点（被撞、让开、撞空、递物）要能用"常见动作 + 接触镜"拍出来；EP001 复盘里撞、让开、撞空全被拆成单人镜，因果链在画面里断了 6 处。
- 金手指的视觉表现不能依赖生成画面出字：规则靠台词说出来（§7），面板、倒计时之类的文字走后期叠加。

这些数字是默认值，豁免要写进 `项目开发/决策记录.md`。[推断]

## 2. 承诺压成一句话

> 当【主角】用【惯常策略】追求【当前目标】时，【对抗机制】迫使其付出【核心代价】；系列反复兑现【观众回报】，直到【终止性转变】发生。

压力测试：换掉人名职业还和大量故事没区别 → 独特矛盾不够具体；对手只需解释一句就会停止阻碍 → 阻力没有结构；主角不行动也能得到结果 → 没有戏剧主动性；只有大结局有回报 → 中间各集没东西可看；每次回报完全同形 → 系列没有变化空间。

"独特矛盾"指主角最有效的策略同时在伤害他珍视的东西（替人隐瞒保住了大家的饭碗，却让公开规则越来越不可信）。写不出这一条，引擎只能靠外部事件推动。

写完一句话承诺，再补六个部件，缺哪个中段就在哪里空转：

| 部件 | 要回答的问题 |
|---|---|
| 压力来源 | 哪个人、规则、秘密、资源限制或关系义务会反复施压？最好两三种来源交织，单一坏人没筹码时只能重复阻挠 |
| 对抗能力 | 它凭什么真能挡住主角，而不只是态度恶劣（§3 对手卡） |
| 主角策略 | 主角通常怎么解决问题？优点和盲区各是什么 |
| 退出成本 | 主角为什么不能走开、报警、坦白或换个目标 |
| 变化空间 | 压力能在哪些状态维度上变（§3 的八个维度），不只是更大声 |
| 终止条件 | 什么事实、选择、关系或能力变化会让这套回路再也转不下去；具体到可核对（"让当年那份名单被公开更正"，不是"变成最强的人"） |

主题不靠台词宣读：把主题写成两项不能兼得的价值（诚实与保护、被看见与保持自主），放进有代价的选择里，让不同人物用行动给出不同答案。核心冲突至少同时碰到外部目标和人物珍视的价值，胜负才不只剩流程。

## 3. 冲突引擎

一轮回路：

```text
触发压力 → 主角按信念选策略 → 对手有能力地反制 → 局部结果 + 新代价
→ 权力/知识/关系/暴露/资源/时间/物理/道德代价 之一改变 → 下一轮更难的选择
```

升级必须能指出上面八个维度里哪一项变了；"更生气、更吵、更危险"不算。删掉"选择"和"代价"两步剧情照样发生的，是作者在搬运事件，不是人物在驱动。

升级常见四种运动，写集纲时标出本集用的是哪一种，相邻集尽量不同：**扩张**（同一矛盾波及新的关系、场合或责任）、**反制**（对手学会主角的办法并封住旧路）、**代价落地**（先前选择的损失现在真的发生）、**意义改变**（新证据让旧事件有了另一种解释，但不抹掉已发生的事实）。转折不一定是秘密揭晓：一次拒绝、联盟变化、证据失效、人物主动换策略都能改变方向。主要转折优先来自人物选择和此前压力的后果；巧合只用来开启问题，不用来替人物解决核心困境（screenplay §7）。

常见承诺重心与可持续压力（选压力来源时对照，同一题材可选不同压力，不要让"霸总 = 羞辱升级""悬疑 = 每集新秘密"代替引擎）：

| 承诺重心 | 可持续压力 | 可变化的回报 |
|---|---|---|
| 身份 / 伪装 | 暴露风险、两套义务、识别证据 | 观众多知道一层，角色被迫选边 |
| 职场 / 制度 | 签字权、时限、替罪链、程序筹码 | 规则被反用，责任归属改变 |
| 家庭 / 遗产 | 照护债、记忆版本、物件归属 | 关系真相或选择成本落地 |
| 复仇 / 追责 | 证据可信度、共犯关系、代价升级 | 对手失去一项保护，主角背上新债 |
| 悬疑 / 秘密 | 谁能看见什么、证据可否解释 | 排除一种解释，同时出现更难的选择 |
| 轻奇幻 / 修仙 | 有限规则、使用代价、和普通秩序的摩擦 | 规则被聪明运用，而不是法术不断加大 |
| 情感 / 关系 | 需求不对称、面子、承诺、边界 | 一方改变策略或公开真实代价 |

**反派要有可执行手段**：签字权、账号密码、监护权、把柄、舆论、对规则的解释权。只会骂和威胁的反派撑不过三集。**反派要会学习**（su 对手学习三步）：第一次失败后识别主角的方法；第二次改变资源、规则或舆论环境；第三次迫使主角放弃旧优势、依靠别人或付出代价。升级沿个人 → 团队 → 供应链/机构 → 制度 → 伦理选择推进，新问题必须换解法，不要"更大的富二代"。

对手卡十一项：目标、资源与权限、已知信息、方法、能造成的具体损失、对主角的误判、失败后学到什么、下一步策略、边界、**节制理由**、被击败后改变的格局。节制理由回答"他为什么没有更早、更直接地把主角按死"（没把主角放在眼里 / 有所顾忌 / 在等更好的时机 / 规则不允许）；写不出来，观众会问"他早干嘛去了"，反派就成了替剧情让路的笨人。[社区]

**反派台词按层级写**：小反派直白嚣张、看不起人，被打脸就结巴、改口、找台阶；中反派不骂人，用利诱和"好心提醒"施压，输了不认、暗示背后还有人；大反派话少、从容，输了就亮出新的筹码或真相。同一个反派被打脸前后，用词、语速和情绪标签（screenplay §4b）都要明显变（EP001 的鬼塚被戳穿后还在笑着说"可恶"，情绪和台词对不上）。[社区][自测]

**交锋节奏**：小反派 1–2 个，一次打脸就退场，不反复纠缠。中反派至少交锋三次：第一次主角小胜或打平（试探），第二次中反派反击、主角受挫（中反派至少要真赢主角一次），第三次主角翻盘；他的失败要给大反派铺路（被靠山弃掉，或阴谋败露后牵出上一层）。大反派分三期：铺垫期只闻其名，通过中反派的话或行为让观众感到他的存在；亮相期第一次正面交锋，主角受到重大挫折；决战期给足 2–3 集，不一集打完。隐藏反派不是必需的；要用，必须是主角身边的人，之前每个行为都能被"好人""坏人"两种解释说通，揭开后观众回看能恍然大悟，时机放在观众以为已经结束的时候。（取自 0xsline/short-drama、short-drama-factory）

**憋屈只能来自反派的手段和信息差**，不能来自主角的迟钝或作者的拖延。主角不出手要有观众看得出的理由：在等一份东西、在让对方多押一注、当场翻脸拿不到结果。观众说"不爽"有两种：恨反派（要制造的）和嫌主角蠢、嫌剧情拖（观众直接划走）。受气段的检查：受气段结束前，观众是否已经看见底牌，或已经看见主角在行动？两样都没有，每多一场就多一批划走的人。反派太弱受气不成立，主角太弱受气变成拖，和 §9"对手为了让机制生效开始变笨"是同一件事的两面。

**攻守转换**：主角连续被动应对（否认、辩解、挨打）最多 3 个回合（回合见 §9 升级刻度），第 4 回合必须改打法。标准做法三种：假意认下，让反派以为得手；以身入局，主动走进对方的局里取证；主动设局。转换之后反派因误判而变本加厉，施压方反过来成了暴露方，主角借此收集反证，最后闭环反杀。转换的那一拍本身要能当集尾钩子用（反转型）；全剧级的大转换放在第二单元开头，主角从"自证的人"变成"追债的人"。第一单元可以没有大转换，但被动的代价必须真的发生（卖房自证、当众求一个说法），不能只是站着挨骂。（取自 short-drama-factory）

## 4. 底牌与金手指

带装置（异能、系统、重生、隐藏身份）的剧，先写**条款级契约**（DEV-01…）：能力范围、失效条件、使用限制（次数、范围、冷却、触发条件；金手指不设代价，见 SKILL.md 6a）、可靠性。契约从第一集起就可以完整，剧中披露可以晚、可以残缺、可以被人物误述；不许的只有一件事——剧中先写出契约里没有的能力，事后回填（规则通胀）。新增条款走"先改系列简报，再在剧中披露"。

装置提供"凭什么"，不提供憋屈；去掉装置这一集还剩不剩选择，是审查题。

**装置不是题材**：题材决定压力来源和情绪落点，装置只决定"主角比别人多拥有什么"。同一个重生装置可以装在商战、宅斗、修仙或破镜重圆上，是四件不同的事；所以带装置的项目照常取主题材那张题材卡，装置这一层用本节校准。设定里本来没有外来优势的，不为"更有卖点"硬加装置。

装置坏掉只有四种形状：阻力被抽空（主角每次都提前知道答案，段落变成执行已知正确操作）；对手不学习（主角一直正确，对手一直用老办法）；装置替戏说话（本该由行动、证据、对峙承担的信息，改成规则宣告直接讲）；规则通胀（写不下去就加新能力救场）。共同解法：给装置装边界，并让边界本身产生成本。

**条款级闸门的实质判据**：新增条款走"先改系列简报、再在剧中披露"在程序上合规，但如果新条款只在主角脱不了困的那一集出现、又不带来新代价或新限制，照样按规则通胀处理。观众某一刻不知道全部边界从来不是缺陷；缺陷只有"剧中出现了追溯不到条款的能力或豁免"。装置的宣告也可以设计成不可靠（记错的前世、别有用心的系统），前提是"会误述"写进条款的可靠性一栏，揭穿时观众能回看出线索。

**先知型装置**（重生、看过结局、被告知未来）：
- 未来信息要切开才有戏，按项目挑一两种切法：只知结果不知过程；只知亲历不知全局；只知旧版本（主角一行动时间线就偏，越往后记忆越不可靠）；记忆有损且不知道自己记错。第三种最能长线供能，装置随剧情自然衰减，不用作者找理由削弱主角。
- 重来的起点落在主角当年做错一个可指认的选择之前，或某样东西还没失去之前；起点定了，全剧第一笔债就定了。
- 观众知道多少前世是另一个旋钮（与主角同步 / 比主角多 / 比主角少），选定后全剧不换。前世信息按时间顺序在当下用台词、物件或字幕交代，不插回放镜头；确要闪回按 SKILL.md 6b 标清时间与信息来源。
- 合成例：她记得三个月后仓库失火，不记得起火点。她提前换了线路，火仍然烧了，只是提早两周，这次她在场。信息被用掉、结果偏离记忆、偏离本身成了新悬念，三件事同时发生，这一段才成立。

**授权型装置**（系统、面板、契约能力）：
- 剧中宣告是一次披露，不是新增条款：先有条款，才能宣告。数值、时限、冷却、次数一经说出就会被观众逐集对账；守不住就在条款里写成定性条件，披露时也只说定性部分。宁可少披露：条款可以完整而暂不说，说出口又违反的收不回来。
- 金手指不设代价，只设限制（用户 2026-09-26 定：有代价就不爽了）。限制要观众看得见、能对账：每日次数、作用范围、冷却、触发条件；"消耗精神力"这类看不见的量等于没有限制。
- 装置给能力、给信息、给限期任务，但不替主角选：让装置摆出选项，由主角在限制内选。每次宣告后主角只是照做，他就成了执行者。
- 载体：条款用台词或 `[OS]` 宣告说出来（SKILL.md 6c），当前数值与变化走后期面板叠加（styles.md §12），生成画面不出字；声音和面板不逐字重复同一句，一个给条款、一个给数值变化。
- 合成例：同一处所内能让一个人忘掉刚发生的三十秒，每日一次，不能远程、不能对两人、不能连用，用完这一次，当天再遇到事只能靠脑子。能力、边界、次数一句给全，后面每集都能从中长出选择。

金手指七项契约（su）：来源、功能、边界、成本、反制、升级条件、滥用后果。三次节奏：第一次展示功能，第二次加限制，第三次让主角创造新用法。身份三段释放：小露一手（观众知道、配角怀疑）→ 证据加码（在更难的问题里验证，对手开始调整）→ 公开兑现（改变资源和权力关系），兑现后马上开新问题。

爽剧默认**观众先于反派看见底牌**，走期待感；反派先于观众知道是惊讶路线，选它要写明放弃了哪段期待。

**可逆状态登记**：人物有会来回切换的状态（失忆、变身、附身、被控制、隐藏实力）时，在系列简报里写一张小表：状态名、触发切换的条件、每种状态下能做和不能做的事、观众靠什么画面分辨当前是哪种状态。每次切换都要在剧本里有可见的触发；没有触发就切换，或同一场里状态前后不一，是 Major（review-checklists §C5）。这类状态不是金手指，条款闸门管不到，所以单独登记。（取自 screenwriter-skill）

## 5. 分集：情绪集纲六件事

每集在写正文前先填一行（模板 `assets/templates/情绪集纲.md`）：

| 受什么气 | 底牌与谁先知道 | 主角行动（可见动作） | 反派失去什么 | 兑现什么爽点 | 留下什么新问题 | 交接事实 |
|---|---|---|---|---|---|---|

写法规则：
- 每格写具体动作、物件、人名，不写"关系紧张""矛盾升级"。
- 主角行动是动作不是功能："她放下笔说授权自己给"，不是"她夺回主动"。
- 反派失去格写不出来的集，说明整集只在受气：并入下一集，或补一次小兑现。
- 新问题必须从本集兑现里长出来，不是新人物踹门。
- 交接事实只写下一集第一场要用的：位置、持物、谁知道谁不知道、已开始的动作。
- "留下什么新问题"格在内容后用括号注明**钩子型**，相邻两集不用同一型，最后一集不要钩子、要收束（下一集开头怎么接见 screenplay §8b）：[社区]

| 型 | 停在哪一拍 | 本项目的附加条件 |
|---|---|---|
| 揭示 | 主角刚知道一件不可逆的事，还没来得及反应 | 这件事能追到信息权限表里的载体（§8） |
| 反转 | 权力或关系正在翻转 | 翻转在前面场次找得到线索位置 |
| 危机 | 威胁到了眼前，主角来不及反应 | 威胁来自反派已经亮过的手段 |
| 时限 | 钟开始走，或到点了 | 死线必须是题面给出的、可核对的数字 |
| 情绪 | 情绪顶点被打断 | 打断者或打断事件先有起因拍（screenplay §5b） |
| 闯入 | 已铺垫过的人或物到场 | 没有起因拍的人不许用这一型，否则就是"新人物踹门" |
| 抉择 | 对手逼主角在两个同样惨烈的代价里选一个，并且在读秒 | 两个代价都是前面已经亮过、观众在乎的人或物；读秒要用题面里的数字（取自 short-drama-factory） |

用"主角一句狠话让全场静住"收尾时，这句话必须伴随一个已经落地的事实（证件、文件、结果），并接一个全场静默的反应拍；只有台词、没有事实，就是 L1 口头打脸（premise-novelty §5），不能当集尾兑现。

**爽点间隔门**（shuohao beat-gap 收紧到爽剧）：每一集都要有一次可核对的兑现（哪怕小），最晚第 1 集就要有第一次；最大的兑现不在最后一集才第一次出现。每集不可逆的新信息、选择或代价至少一项，不用重复事件填充。

**受气和兑现的力度配比**：给本集受气和兑现各打 1–3 档（1 = 口头轻视；2 = 当众失去东西或尊严；3 = 失去在乎的人、位置或安全）。兑现档位低于受气档位，观众会觉得没出完气；受气只有 1 档而兑现 3 档，会显得小题大做。连续只挨打、没有任何正反馈（一个小胜、一次反击预告、一个盟友出现都算）的时长，单集不超过全集一半，跨集不超过 1 集。（取自 screenwriter-skill）

**反应句**：集纲里每个标了兑现、笑点、泪点、燃点的格子，旁边写一句观众会在这里打的弹幕或评论（口语、10 字左右，例如"活该！""这波我站男二"）。写不出，或只能写出"好爽"这种泛词，说明这个点还没具体到可以感受，回去加强对象、代价或当场确认；同一季里反应句高度重复，说明兑现在机械轮换（review-checklists §B.12）。反应句只用于自测，不写进剧本和字幕。（取自 screenwriter-skill）

发行模式默认按 **IAA（免费看，看完一集靠广告解锁下一集）** 写：观众随时可能划走，所以每集都要有兑现，不设付费门槛集、不长时间卡着不揭。[官方][社区] 其他模式只在用户明确声明时启用，并记进决策记录：

- **付费解锁（IAP）门槛集**：门槛位置由用户定，本 skill 不给默认集号。门槛集本身仍是普通一集，有自己的局部兑现；它只让三条在这里收紧：门槛后面必须还欠观众一样东西（刚兑现完一次大回报就设门槛，满足的人不会付钱），所以放在一次尚未兑现的爆发之前；门槛处的悬念只依赖观众已经认识的人、已经理解的规则、已经看见的赌注；越靠近门槛越不能出现只做交代的集。可核对的补充（取自 short-drama-factory、0xsline/short-drama）：
  - 前置蓄水：门槛集之前的 2–3 集，持续抬高反派的嚣张程度和主角的隐忍成本。
  - 断点：停在反击出手前一瞬，或身份揭开前一瞬；不停在爽完之后。
  - 付费后立刻兑现：门槛后第一集开头约 15 秒内兑现门槛处吊着的东西，同时抛出新悬念。
  - 一个悬念只卡一次：相邻两个门槛不吊同一个问题。用户给的门槛相邻不到 5 集、或前 10 集超过 2 个门槛时，照用户的位置写，把风险写进决策记录，不擅自挪位置。
  - 免费区的产出：第一个门槛之前，观众手里至少有 3 个未回答的问题，而且已经尝过一次小兑现。
- **承制 / 买断 / 保底**：先写清客户要的受众、情绪和验收标准，再立项。
- **品牌 / 文旅定制**：产品或地点要进入冲突的解决过程（证据、工具、场合），单插一段口播会破坏剧情。
- 出海沿用上面的模式再加本地化；只换语言不一定能复制原来的情绪效果（台词本地化见 screenplay §4c）。目标市场不是中文观众时，先检查压力源和兑现方式在当地是否成立，常见替换：孝道绑架 → 经济控制或情感操纵；跪地道歉 → 公开道歉或实质补偿（失去职位、资产）；重男轻女 → 继承权之争或能力证明；包办婚姻 → 家族利益联姻、主角反抗；长时间忍辱负重 → 缩短忍耐期、尽早反击；扇耳光 → 言语打脸或资源碾压；大段苦情哭诉 → 压缩；无动机的背叛 → 补上具体利益驱动。场合换成当地观众熟悉的公共场景（慈善晚宴、法庭、节日家宴），身份道具也换成当地的（律师函、家族信托）。日本市场同样要查"当众下跪""长辈一句话定终身"在目标年龄层是否仍有效，失效的换成当地的公开失态方式。（取自 0xsline/short-drama）

**转折和兑现写成那一下动作，不写那一下的功能**。集纲"主角行动""反派失去"两格最容易写成一句正确的功能描述，而功能描述不是一场戏：

| 写成功能（不够） | 写成动作（够） |
|---|---|
| 他不再讲道理，用自己的信用担保 | 有人在群里问他是不是急了，他删掉打了一半的辩解，只发出一条链接 |
| 裁决权从立场转到作品本身 | 刚才喊举报的那个人点开了视频 |
| 上级选择维持现状 | 上级把申请表推回来："等有了成绩再谈" |

判据：这一拍观众看见的是谁做了什么？答不上来就是停在了功能层。反派的筹码同样写成他做过或将要做的事（"他们已经约好一起去平台投诉"），不写属性（"人多、态度一致"）。

**本集结果要追溯到焦点人物的一次选择**。结果可以由外力送达（援兵、证据浮出、对手内部翻脸），但要同时写清两件事：主角此前哪个动作让它**现在**到达，以及他拿到之后做了什么处置。反例：主角被当众羞辱，全程只是承受，随后一辆车开来、随从递上身份凭证，全场哗然——所有格子都填得满，主角却是这一集的观众。修法不是加动作，是把一次被动承受改成主动选择（他本可以走后门办完事，是他自己坚持走正门，随从的到达就成了这个选择的后果）。

**用"所以 / 但是"朗读相邻两拍**：因为前一结果，所以人物现在这样做；但是对手利用新状态反制；所以人物必须换策略或付代价。只能用"然后"连起来的，缺的是人物选择、对抗反应、可见后果或下一股压力之一。

**集纲只写这一集独有的事**：删掉某一格，写剧本的人会不会失去一个约束？不会就不写。可以从别的格推出来的、整部剧只发生一次的（人物跨集弧线、装置条款写在系列简报）、解释理由的，都不进集纲。同一句话被抄进六个格子，表看起来完整，其实只做了一个决定。

**容量估算**（EP001 做完后才做）：用本项目已完成集的实际比值（每场剧本字数对应几个镜头、每镜平均几秒）换算待写各集的镜数和时长，只看量级偏差（某集是均值两倍以上）。偏差是提示，优先用拆成两集、把说明改成动作、合并同质节拍来处理，不按数字删兑现。EP001 没有基准可比，由 screenplay §6 的时长估算和剪辑后的实测兜底。

一场戏里把四个时刻放在同一段可见链条上：观众看见底牌的时刻、反派押注的时刻、事实落地的时刻、新问题打开的时刻。合成例（职场抢功）：

| 步骤 | 剧情与台词 | 画面与信息 |
|---|---|---|
| 受气 | 主管删掉方案上她的名字："外包也配署名？" | 先给删名字的动作，别先拍全景 |
| 加压 | 主管坐主位，把她的椅子推离桌子 | 拍清位置和地位差 |
| 底牌 | 她收到客户消息："今天需要您本人确认授权。" | 观众先于主管知道 |
| 反击 | 她放下笔："名字可以删。授权，你自己给。" | 动作和态度，不解释心路 |
| 押注 | "少了你，这项目还不转了？" | 留住他的笃定 |
| 兑现 | 客户拒绝主管签字："我们只接受原作者授权。" | 事实落地，再给主管笑容消失的反应 |
| 新问题 | 客户问她："授权费上周就打给公司了，你还没收到？" | 从抢功进入扣钱 |

## 6. 兑现五要素

一次公开兑现至少包含（su 五要素 + 本地三件事合并）：

1. 前置的质疑或不公（观众攒过气）；
2. 主角可验证的行动；
3. 证据、结果或第三方规则当场生效（客户、审计、系统记录证实，不是主角自己宣布）；
4. 对手失去可核对的东西：资源、信用、权限、策略位置；
5. 主角获得新空间，同时背上新责任或新问题。

只有"所有人震惊、跪下、后悔"而局势没变，不算兑现。反应镜头放在事实落地之后。胜利要存档不归零：每集账上至少更新一条主轴（技能、资源、声望、团队、权限、信息），失去已得的进展要有因果。

**兑现子模式**（主爽点类型不变，各集在子模式间轮换，同一子模式不连续两集用；与 §9"换向量不换靶心"一致）：[社区]
- **证据反杀**：录音、记录、回单在见证者面前亮出。
- **原话奉还**：反派早先某集的一句狠话，兑现时由主角或第三方原句还给他；这句话要在前面场次先种下，并登记进信息权限表。按时间顺序在当下说出来，不插回放镜头。
- **局中局**：反派以为得手，其实已经入局；布局要在前面露过一角。
- **第三方裁定**：客户、审计、系统、长辈当场按规则判。
- **一通电话**：有权力的人来电改变局面；来电人要先铺垫，手机屏幕背对镜头，来电声走 `[OS]`。
- **当众公开**：在见证者面前揭露，见证者的反应放在事实落地之后。

不管哪种子模式，决定胜负的那件证据或那个动作要在画面里读得出：物件用近景亮给观众，状态（例如"箱子是空的"）要有一拍让人看清（EP001 的空箱在全景里看不出是空的，兑现只能靠台词）。[自测]

## 7. 人物：可跟随，不只是可分析

行动模型八项（预测他会怎么选）：表层目标、保护对象、自我解释、惯常策略、筹码、盲区、底线与越线条件、可变事实。主角和主反派再加两项：**被捍卫的信念**（一句偏颇但有来历的判断，例如"只要我把记录做平，所有人就能保住工作"）和**前史成因**（哪件旧事让这套信念和策略曾经有效）。前史只储备在系列简报里供作者预测选择，不倒进首集台词；前史储备、切入时刻、人物弧线的压力测试和跨集记忆见 [series-long-form.md](series-long-form.md) §1–4。

再答四问，至少一条要在第一集画面里看得见：他正在承受什么不该由他承受的东西；他正在替谁扛；他想要的东西观众自己是不是也想要；他有什么本事是观众想借来用一次的。人物一直正确、一直被善待、一上来就赢，观众就没东西可替他争取。

**开场模式**：默认 story_driven，按已有故事建立目标与阻力；power_acquisition 仅用于明确选定的能力获得型故事。时间跳跃必须可辨识，不把异能、遇险和前 20 秒强加给所有项目。

**必要规则要可理解**：用可见行动、台词或字幕表达当前情节需要的规则；不一口气解释所有设定。世界事实、角色认知和观众获知分别记账，见 [信息与连续性](scene-state-and-reveal.md)。

关系写成双向压力：A 需要 B 提供什么 / 害怕 B 看见什么 / 用什么约束 B；B 反过来同样三项。

配角策略：承担主要冲突的配角要有自己的目标和筹码；事务性角色保持简洁，不为检查表硬加秘密。

**感情线要有事件支撑**（项目有感情主线时）：两人每升一级关系（敌对 → 合作 → 心动 → 确认），都要指得出一件共同经历的具体事件，不靠婚约、系统绑定、"命中注定"推进。被爱的一方凭什么被爱，要落在另一方为他付出或冒风险的动作上，不只是微笑、点头、喊名字。确认关系的那一拍，放在"已经知道代价之后仍然选择留下"。甜宠向每集至少一个可截图的亲密或暧昧名场面（肢体接近、护住、只对对方破例的台词），尺度按平台规则和用户要求；写成"好的"关系，不能靠监控、羞辱、封锁资源施压。审查见 review-checklists §C7 第 7 条。（取自 screenwriter-skill、su-ai-short-drama）

**名册纪律**：全剧具名角色（有名字、有台词、要定参考图和音色的）一般不超过 12 个，多出来的降为无名群演。每个新登场的对手必须把压力往上推一档：他一出现，施压阶梯就升一档，或主角多付一档代价（§9 升级刻度）；不推档的反派，删掉或和已有反派合并。同一条对手链上的恶沿用同一种逻辑（§9 单元帽"对手换层不换欲"）。（取自 short-drama-factory）

## 8. 信息权限表

实战项目审查里的剧情类 Major 全是知情时机和证据链问题。每集维护一张表，写进系列简报或集纲附注：

| 事实 ID | 世界事实 | 谁知道 / 误信 / 未知 | 观众何时知道 | 可见载体 | 改变谁的选择 |
|---|---|---|---|---|---|

规则：
- 载体只能支持它直接证明的结论；"设备只对 00:17 反应"证明不了"某人改了记录"，责任归属保持未决，等下一个独立载体。
- 主角每一次"知道"都要能指出来源镜头；指不出的就是"看过剧本"。
- 反转要回看成立：每次底牌揭晓列出至少一个更早的场次作为线索位置，列不出就是缺陷。
- 揭示之后追问：谁现在能质疑、交易、逃跑、撒谎或公开？没有行动后果的信息可以删。

**证据结论边界**：可见载体出现时，分三层记（写在信息权限表的"可见载体"格里）：`看见了什么`（观众和人物实际看见或听见的）→ `直接证明什么`（这个载体能支持的最强结论）→ `仍未证明`（可能成立但还缺独立载体的身份、原因、动机或机制）。角色说得再笃定，信息权限也只能升到"直接证明"那一层；角色误判是允许的，但角色信念和世界事实、观众所知要分开记。

**登记不等于兑现**：系列简报里登记为"不可改"的事实（改编项目的原著事实、用户点名要的设定），每一条要么写明落在第几集、观众从哪个画面得到它，要么写明延后到第几集；两样都答不出的只是备注。同理，集纲写了某个可见载体，剧本就必须真的演出它；需要前后对照才成立的证据（装置生效前后哼同一句歌，音准完全不同），前后两端都要上屏。写完剧本按集纲的载体逐条回读一遍。

**铺垫台账**：铺垫是一笔债。跨集铺垫在系列简报里记一行：`铺垫 ID｜首次出现（集-场）｜观众当时自然会怎么理解｜承诺回答什么问题｜计划兑现 / 改义方式｜状态（计划 / 已兑现 / 有意悬置 / 待解决）`。首次出现要有当场的表面理由；回扣时既回答旧问题，又改变当下的选择；改写铺垫要标出受影响的集和镜头。只为延迟说明而存在、不改变任何人下一步的铺垫，删掉或改成有用的。

**揭示与反转**：四种动作分开叫，一次动作可以兼任但不混称——**揭示**（有人得知一件已有的事实）、**反转**（已有事实让计划、解释或关系位置失效）、**情绪兑现**（承诺的爽、痛、甜真正落到可感知的结果上）、**钩子**（新决定、危险或问题让状态继续运动）。只亮出秘密而没人改变选择，是揭示不是反转；只在最后藏住一句话，是扣留不是钩子。

公平揭示五问：观众之前是否见过足够的可解释迹象？谁此前接触得到这个事实？证据为什么现在出现，而不是作者需要时凭空出现？新事实排除了哪个旧解释？得知之后谁必须改变行动？有效的揭示多半来自"旧事实的新关系"，而不是突然加一个更大的秘密。

反转要能填完这一句：

```text
因为〈已建立的事实或选择〉，原计划〈为什么不再成立〉，人物现在只能在〈新代价 A / B〉之间行动。
```

常见能成立的反转：胜利触发对手早有准备的程序反制；证据是真的，但证明的是另一项责任；被保护者拒绝这种保护方式；主角的长处暴露新的盲区；盟友要求兑现此前的承诺；规则没失效，人物用规则改变了时间或权限。不成立的：陌生人突然出现宣布一切都是误会。

## 9. 机制循环与耗尽

单元剧靠同一套机制反复运行。第一次运行要把机制演示完整（宁可慢），之后每次运行必须改变：对手的认知、执行难度、适用范围、知情者名单、退路之一。打乱运行顺序不损失东西的，是重复不是升级。

耗尽症状（两项以上就处置）：观众能提前说出结果；兑现规模变大而状态变化变小；必须加大羞辱或金额维持强度；对手为了让机制生效开始变笨。处置只有三种：收束（一次不能再重复的运行）、改造（换一项前提）、移交（把机制交给另一个人物）。不许并接（旧循环没结清就开新循环）。给循环一个具体到可核对的去处："让那份名单被公开更正"，不是"变成最强的人"。

避免重复时换向量、抬阈值、不换靶心：对手质疑"拿不出钱"，第二次不是更大一笔钱，而是一个只有真正拥有者才会有的日常细节。换承担者也可以（由新人物的态度完成同一次回应）；判据不是"有没有换人换事"，而是"换过之后观众追的还是不是同一件事"。为了不重复而换一件和核心回报无关的事（换靶心），重复没了，观众追的线也断了。

**每次运行记五项**（写在集纲附注或系列简报的单元规划里）：谁在用什么已知优势、观众此刻知道多少；对手基于他手里的什么事实做出合理选择（不是变笨）；观众比对手多知道一步还是同样被蒙住（选定一种）；本次改变了什么状态；本次的成本（主角付出或欠下了什么）。没有成本的运行让循环变成免费的，免费的循环耗尽最快，观众很早就算出它可以无限进行。

**升级刻度（施压 × 反击双阶梯）**：一个单元内，对手压向主角的证据或手段按"可抵赖程度"逐档递减：①传闻、旁人告知 → ②能辩解的物件 → ③外观像铁证、程序上有漏洞 → ④权威鉴定，但程序可以质疑 → ⑤人证、记录、轨迹多方合围 → ⑥无法推翻的专属证据，且当事人亲眼确认。主角一方的回应按代价逐档递增：①口头否认 → ②质疑证据效力（开始得罪人）→ ③挑战程序（花人情或钱）→ ④找更高层或公开对质（付出社会成本）→ ⑤押上财产、名分或自由（风险不可逆）→ ⑥无牌可打，要么崩溃，要么以身入局、反守为攻。两条阶梯双方都能用：反派按 ①→⑤ 施压、主角在第 ⑥ 档亮出官方证明反杀，也是一种排法。每个回合两条阶梯至少各升一档，都没升就是废回合；这一回合的反击必须带新信息、新行动或新代价中的至少一项，只重复上回合的话术就重写。集纲附注按"回合 N（EPa–EPb）：施压 = 档 x 具体物｜反击 = 档 y 具体动作｜回合尾钩子"逐行登记。这把尺和上面"换向量、抬阈值、不换靶心"是一回事的量化：升档靠换证据种类和代价种类，不靠更大声、更多钱。（取自 short-drama-factory）

**循环是套着的**：几次小循环构成一个大循环的一次运行，几个大循环构成整部剧（续季项目里，一季就是一个大循环，见 series-long-form §6）。外层的赌注要更早建立：观众正在跟的是小循环，让他们留到几十集之后的是大循环。

**换代时交接紧迫性**：新循环往往更新奇却更弱，因为旧循环攒下的三样东西没交过来——可感的时限或到期代价、主角不能退出的理由、观众已经押上的具体的人或物。检查问题："主角这一轮什么都不做会怎样？"新循环的答案必须比旧循环更具体、更糟；变抽象了，先补时限和退出成本，再谈新机制好不好玩。

**把下一个循环埋在这一个里**：当前循环还在运行时，让下一个循环要用的东西以次要身份出现一次（一个没解释的人、一份顺手放下的文件、一句当时不重要的话），旧循环收束时才被提起，观众会觉得"原来那个有用"，而不是"怎么又来一件事"。所以下一个循环大概是什么要在分集走向里提前定。收束和下一个循环拉满之间留一小段处理后果、确认损失的过渡；在爽剧里这段过渡不能占满一集，本集仍要有自己的小兑现（§5 爽点间隔门）。

**落差型循环**（回报是"紧张被解除"：反复陷入危险又脱身）耗尽得更快，只要连续几次都没真出事就没人担心。修法：每次脱身都带走一点确定的东西（一条退路、一个知情者、一次机会、身上一处伤），损失可以小，但必须真的发生。

合成例（机制 = 让对方在有第三方记录的场合重新说一遍自己的说法）：运行一，主角当着交接班的人问排班依据，护士长说"按上月轮次"，主角把交接本翻到上月那页，护士长改口"临时调整"——他从"有规则依据"退到"临时决定"，主角暴露了自己在查；运行二，家属投诉，护士长说"人手不够"，主角摊开签到表，他改口"我安排失误"，主角被调离能接触交接本的岗位；运行三，护士长在会上干脆不解释，反问主角为什么总盯排班——对手学会了机制，这就是耗尽点。三种处置分别是：把最后一次机会用在对方无法沉默的场合（收束）；改由那位年轻护士自己在有记录的场合发问（改造，风险转到她身上）；护士长反过来用同一套办法逼主角表态（移交）。直接另开一条"药品短缺"新线就是并接。

**单元帽与换单元**（取自 short-drama-factory）：
- 同一个核心矛盾（主角要证明或讨回的那一件事）最多跑约 6 个回合；按 90–120 秒一集约 20–30 集，集更长时按内容量折算（3 分钟一集约 10–15 集）。到帽必须闭环：真相落地，或一方防线崩溃，不再加一级阶梯硬拖。
- 换单元换矛盾、战场和对手，不换情绪契约：观众追的那口气（比如"让看不起我的人当面认错"）全剧不变。
- 对手换层不换欲：下一单元的对手是上一个对手背后的那一层（执行者 → 指使者 → 规则本身），恶的逻辑保持同一种（贪、势、妒三选一），强度自然升一档，观众也不用重新理解"这人为什么坏"。
- 打法随单元升级：第一单元被动自证，第二单元主动设局，第三单元掌控规则。打法没变的下一单元会像复读。

**数字不算进展**（取自 su-ai-short-drama）：等级、财富、粉丝数、手下人数、头衔，只有改变了主角能做的事才算进展。每次升级要指得出至少一项：能完成以前做不到的任务；选择空间变大；团队能离开主角独立执行；对手被迫换打法；规则或组织被真实改变。阶段差距写成具体缺口，不写"他很弱、很穷"：缺某项资格或权限、设备只能做基础活、团队缺一个关键岗位、证据不够进入下一层调查、势力只保得住一个地点。每季开头列出缺口，每次兑现划掉一个。

## 10. 自动模式的默认与假设账

无人值守时不问人。缺什么按 `pipeline-contract.md` §8 的默认补，并把每条假设写进 `项目开发/决策记录.md`：假设是什么、影响哪些下游产物、什么条件下推翻。缺口分两类：会改变主角、冲突引擎、结局承诺的叫关键缺口，也照样按默认决定但单独标出；其余是可逆假设，直接推进。

优先级固定：用户给的硬约束 > 生产约束（台词镜听者入画、同框人数写死、镜长按内容定且同一人不拆镜、语言、画幅） > 题材爽点 > 其他手感。

每批开写前回锚三件事（su 三回锚）：本批任务是什么；上一批结束时的状态（交接事实）；当前规则（系列简报、装置条款、最新修改）。

**入口判断**（无人值守时自己判，写进决策记录）：
- 只有点子、题材或情绪目标 → 按本文件和 premise-novelty 从 A 阶段做起。
- 有小说、网文、梗概或多集原稿 → 先按 [adaptation.md](adaptation.md) 做原著拆解和改编契约，再进 A 阶段；原著事实是用户的契约，不偷换原意。
- 方向已定、只要分集 → 读已有系列简报，直接做或改 B 阶段集纲。
- 已有单集剧本 → 不为流程完整虚构开发材料，直接进 C 阶段规范化（保留原文台词），缺的系列简报字段按 pipeline-contract §8 默认补。
- 超过一季、计划续季或续写下一集 → 另读 [series-long-form.md](series-long-form.md)。

用户提供对标剧、样例剧本或提示词时，只学它解决问题的机制，不仿写表达（adaptation.md §8）。未选的候选不进入既定事实：系列简报 `## 立项候选` 里落选的点子，后面不许悄悄混进剧情。

## 11. 审查问题与失败征兆

reviewer 子代理的必答问题统一在 [review-checklists.md](review-checklists.md) §A（立项与系列简报）、§B（情绪集纲）、§C（剧本），按那里的分级与格式引用证据回答，不给空泛分数。原来列在本节的 18 问（受气、主爽点类型、底牌、兑现五要素、新问题、知情来源、装置条款、对手学习、机制运行、状态台阶、因果可见、场景合理、节制理由与钩子接缝、新颖度与爽感、动作与选择、证据与台账、循环成本、承诺六部件）都已收进该文件；写作者交稿前可按同一清单自查。

失败征兆：人物、援兵、证据凭空出现，观众不知道从哪来；主角站着挨打、外力替他翻盘；集纲格子里全是功能描述没有动作；道具只证明了时间或地点，却被写成证明了作案者或动机；承诺只有题材词；主爽点不明；受气靠主角迟钝维持；观众到反击才知道有底牌；兑现只有狠话和脸色；一集全兑现下一集从零受气；反派只会骂；主角"看过剧本"；能力规则在剧本里先出现再回填；每集都是同一种羞辱—亮牌；点子能压成"主角多了 X 能力所以当场打脸"。

审阅产物要带 `keep:` 清单（哪些段落有效、修改时必须保留），修订后对 keep 清单做字面比对，被改动的回退。
