# 信息权限、因果与跨镜状态

剧本先说明世界内发生了什么，再决定观众何时知道。不要把“观众不知道”误判成“世界没有原因”。

## 三本账

- 世界事实：物件真实归属、人物位置、事件原因，以及谁做了什么。
- 角色认知：每人通过亲见、听说或推断知道什么；没有信息来源就不能突然知道秘密。作者知道、观众知道、系列简报或审查意见里写着，都不等于角色知道。
- 影响行动的秘密（识破、抢答、选择、反击要用到的）在系列简报或跨集记忆里记一行：

| 事实 | 世界里的真实状态 | 谁知道/误信、何时、通过哪一拍得知 | 观众何时知道 |
|---|---|---|---|
| 钥匙去向 | 师傅交给了邻居 | 徒弟 EP002-SC03 只听见"交给别人了"，不知道是谁；邻居 EP002-SC01 当面接过 | EP002-SC01 看见交接 |

  "师傅交出了钥匙"不授权徒弟直接找到邻居：他得先问、先找到证据，或做符合他当前所知的事。角色可以猜错，但剧本要让观众分得清猜测和确定的事实。只记影响后续选择的，不登记日常细节。
- 观众认知：本镜明确展示什么、暗示什么、暂时隐藏什么。隐藏项写计划揭示镜与证据；揭示不得否定已经明确呈现的客观事实。

隐藏项除了计划揭示镜与证据，还写**保护方法**（靠裁切、遮挡、背影、画外空间还是台词回避来藏），说不出什么时候、靠什么释放，就是还没设计完。同一个人身上可能有几层要分开扣的信息，例如"来者认识主角"和"来者是谁"：前者可以先让观众看到反应，后者留到揭示镜，两层各记一行，不要一个镜头同时泄掉。

`setup_for` / `requires_setup` 只记录观众必须提前掌握的依赖。例如观众要看懂钥匙为什么打不开门，需知道换锁或错误钥匙；悬疑片可以先展示打不开，再揭示换锁原因，这时不声明该原因必须预先曝光。

## 跨正反打连续性

`boundary` 描述本镜主体可见状态；跨主体仍要记住已经发生的变化。在同一 scene 的镜头填 `scene_state`（道具归属按需写，在场名单每场必写，见下），键名全场保持一致：

```json
{"scene":"SC01","scene_state":{"start":{"props":{"contract_owner":"甲"},"characters":{"乙":{"injury":"无"}}},"end":{"props":{"contract_owner":"乙"}}}}
```

随后切甲的反应镜，再切乙，合同仍属于乙。G41 累积已声明的 end，检查后续显式 start；省略字段表示沿用，而非恢复默认。

**在场名单也走 scene_state**：`characters.<名>` 写 `present`（true/false）、`where`（世界位置：门口、栏内/栏外、崖沿哪侧，不写画左画右）、`facing`（朝向谁或哪个地标，不写屏幕方向）。每场第一镜的 start 从剧本场首 `[连续性] 在场：` 行抄全员（含画外在场者，`present: true`、`where` 写他在哪）；有人离场，离场那一镜的 end 写 `present: false`——省略等于沿用，已经走掉的人会留在名单里。起始帧和视频正文的封闭清单（video-prompts-general §2b）从这里抄。

```json
{"scene":"SC03","scene_state":{"start":{"characters":{"顾长生":{"present":true,"where":"栏内","facing":"萧烈"},"萧烈":{"present":true,"where":"栏外走廊","facing":"顾长生"}}},"end":{"characters":{"萧烈":{"present":false}}}}}
```

**陈设和可变环境也走 scene_state**：`set.<物件>` 写 `count`（整数）和 `where`（三方向世界位置：左右用房间地标、前后用「书桌与后墙之间」这类写法、高度写「地上 / 桌面」），`en` 写提示词里用的英文名；`fixtures.<门窗抽屉帘灯>` 写 `open`（可量开度，如「约一掌宽，约 15°」）或 `lit`。每场第一镜的 start 写全画内会出现的陈设和门窗，之后只在 end 写变化；G41 按同一条链查跳变（多一只箱子、门开度变了都会报）。起始帧和视频正文的陈设清点句、开度句从这里逐字翻译，同一场内所有镜用同一句英文。

```json
{"scene":"SC02","scene_state":{"start":{"set":{"纸箱":{"count":1,"en":"cardboard box","where":"地上，书桌与后墙之间，书桌远离镜头一侧"}},"fixtures":{"书房门":{"open":"约一掌宽，约15°"}}}}}
```

允许在 end 写合理变化，但脚本无法判断变化是否有动作原因，仍需审分镜。时间跳跃、梦境或回忆使用不同 scene 标识，另记其真实时间及恢复点，避免混进同一连续状态链。

## 递合同示例

1. 起点：甲右手拿合同，乙空手。观众已知道这是待签合同。
2. 交接镜：手部特写可识别两人的袖口；甲递出，乙接稳，甲松手。画面或连续声音要支持交接确已发生。
3. 反打：甲等待答复；合同仍在乙手里，不因镜头切走重新回甲手中。
4. 结果：乙翻到签字页，发现空白并质问。若空白是此刻的悬念揭示，前镜不必提前曝光；但不能前镜明确拍到已签字、此镜无因变空白。

对白、动作、环境声可以并行。比如递合同 2 秒同时说 2 秒台词，是约 2 秒加必要停顿；先递完再说才相加。未确定排演时记录区间，不伪造精确时长。
