# 使用说明

当前版本以 [SKILL](../SKILL.md) 的 metadata 为准。从 [README](../README.md) 看目录，AI 从 SKILL 按当前任务读取。默认由同一个 agent 完成前期和生产。机器阅读工具使用由现行章节同步的 [完整规则](../assets/source.md) 和 [阅读地图](../config/stage-reading-map.v3.json)。

## 恢复任务与配置

先确认本次是写作、修稿、提示词、诊断、剪辑还是实际生成，再恢复相关原稿、当前集、已验收版本和缺口。纯文本工作不因缺少服务、槽位或媒体而停下，也不自动触发生成。

恢复时核对执行者实际加载的 Skill 路径/版本、当前方案和最终请求；下载包、桌面副本与安装副本可能不同。文件已更新不代表会话或 worker 已刷新，按 11 重读受影响章节并重新生成、核对请求，生产中的版本切换仍按 10 接管，不能热改在途批次。

模型、服务、硬件、并发、费用政策、画质、声线与交付限制来自当前项目。用户另行提供个人配置时，只提取本次适用设置；其中的历史实测须复核，历史授权不能扩展本次范围。不要搜索或加载其他人的私人配置。没有个人配置也能使用公开规则。

## 各阶段怎样执行

- **正文**：按 [01](01-story.md)–[04](04-adaptation.md) 写用户指定题材与口味的自然正文，再提取字段；改编才读 04。
- **分镜与素材**：按 [05](05-space-assets.md)/[06](06-storyboard-prompts.md) 从完整事件推导各镜状态、机位与 prompt，分别验收人物、道具、场景图，再按序直接送入 H3 reference 模式。
- **预演、声音与剪辑**：按 [07](07-animatic-audio.md)/[08](08-editing.md) 制作，核对实际音轨、采用范围和后期安排，保护观众需要的声画信息。
- **审核、修复与交付**：按 [09](09-review-repair.md) 核真实媒体、定位问题并有限返修；[10](10-execution.md)/[11](11-handoff.md) 负责执行与交接。阶段结果以当前实际版本为准。

纯写作可交用户指定的多集。实际生产按项目活动范围推进；随包调度工具每次处理一个 `active_episode`，资源池容量表示本次获准的并发预算，不等于硬件总容量。

## 角色和证据边界

主协调器按阶段读取相关模块与真实输入；写作者先交正文，生成模型只收本镜信息。盲看者只收[独立指令](blind-review.md)、实际媒体与观众可知前情，不收本说明、剧本、人设答案或项目根目录。

子代理产出草稿或观察，由有授权的执行器提交生成。模型 ID、模态和隔离能力须核实；公开规则不规定供应商或“强/中档”搭配。原有有效授权可复用，新增范围或费用超限先确认。

## 工具与迁移

仅在任务需要时读[工具说明](tooling.md)。工具均不提供账号、密钥或已经接通的云服务；示例和 `UNKNOWN` 模板不是通过证据。不为每个镜头运行全部单元测试。

在 skill 根目录生成阶段阅读包：

```bash
python3 tools/production-ops/scripts/execution_control.py reading-pack \
  --skill assets/source.md --routes config/stage-reading-map.v3.json \
  --stage story_original --actor writer-main --scope CURRENT_EPISODE
```

同一执行者仍持有同版、同范围的完整模块正文且上下文有效时，协调器可复用这些正文，只补当前阶段缺少的模块和变化的项目输入。当前阶段的阅读回执仍须核对角色、范围、规则与路线；不能自动确认已读。换执行者、上下文丢失或规则变化时完整投递，盲看保持隔离。`reading-pack` 默认仍返回完整正文，文件访问记录不能证明模型持有上下文。

将 `CURRENT_EPISODE` 换成真实范围。`ISSUED_NOT_ACKNOWLEDGED` 只表示发放，实际读完后才能由可信流程登记确认。盲看者只收 instruction_text，凭据由协调器保管。

字幕/UI 的实际合成与结构检查边界见 [工具说明](tooling.md)；G3 的 `edit_cut_review.details.presentation_review` 必须来自同版真实观察，不能自动填 PASS。

切换版本时保存当前项目配置，更新相应阅读凭据与契约绑定，核对实际适配器采用了新规则。旧接口可读取不等于符合新标准；不能给新成片贴旧报告，也不因此重拍全部合格素材。适用的执行、剪辑、可见性、接续和呈现门禁继续执行。旧首帧模式只供明确采用它的项目维护，不作为 reference 视频的前置门禁。

## 公开包与私人资料

公开目录仅含通用规则、工具、模板和虚构/合成示例。个人模型及本机设置、真实项目经验、旧源文件和压缩包均应在目录外保存。已有项目按自己的配置继续，不用公共模板覆盖实值。分享本 skill 不包含向任何平台发布实际短剧的授权。
