# 4 分镜与视频提示词

阶段 E 写 `shots.json`（机位、镜头规格）和视频提示词时读本文件。SKILL.md 的六条硬规则优先于这里的任何条文；本文只讲怎么落实。起始帧提示词的写法在 3-视觉设定与图片.md §3，审片在 6-审片与剪辑.md。

用 Seedance 等其他模型时，只换 §4 的外壳语法，其余照用。

## 0. 起因：EP001 为什么失败

2026-09-27 EP001 做了 60 镜、5 分钟，机械门全过，但观众看不懂。第 2 镜把五人饭桌戏拆成两人中景，身后全是空椅子，观众以为换了场景；镜头太碎，每镜只说半句话。所以本文的两条总规矩是：

- **一场戏一个空间**：先有主镜头交代全员位置，之后在场的人要么在画里，要么明确在画外某一侧。
- **少而长**：一集 2–3 分钟，15–30 镜。一镜做完一件事，动作和反应在镜内演完。

"人脸要大"仍然成立，但它服从这两条：宁可用三人中近景让脸小一点，也不拆成丢人的双人镜。

## 1. 一场戏怎么拆镜

### 1.1 覆盖法：主镜头 → 过肩/三人 → 少量近景

每场按这个顺序设计，不跳步：

1. **主镜头（1 镜）**：交代全员位置和朝向。全员入画，景别到中景或中全景为止，不用远景（768p 下人太小会糊）。主镜头可以承担一两句台词或开场动作，不要做成只看不演的空镜。
2. **过肩 / 三人镜（主体）**：这一场大部分台词在这里。每个镜头都是从主镜头那个空间里取出来的一块：说话人正脸，听者肩背在前景，第三、第四人在后景或画边。背景里看得见的座位上坐的应该是主镜头里坐在那里的人，不能是空椅子。
3. **近景反应（少量）**：只给关键反应，比如底牌亮出时反派的脸、主角被羞辱时的脸。一场一般 1–2 个。近景里看不到其他人时，视线必须指向那个人在主镜头里所在的方位。

一场的镜数一般 3–6 个。同一个人连续说几句、连续做几件事，合成一个长镜头（H3 最长 15 秒），不拆。只有这几种情况才拆：景别或机位明显变化、要插别人的反应或物件特写、时间跳跃。

### 1.2 在场者记账

每场在 `scene_state.characters` 写全员名单和每人座位/站位（抄视觉设定的平面图）。之后每个镜头写两样：

- `in_frame`：画里有谁，包括前景肩背、后景虚焦的人。
- `off_frame`：画外有谁、在哪一侧（`{"母亲": "screen-right"}`）。

`in_frame` 加 `off_frame` 必须等于在场名单。有人既不在画里也说不清在哪侧，这镜就不过。画外的人在提示词里只写名字和方位，不写外观（写一次外观就等于召唤他入画）。

### 1.3 饭桌戏拆镜示例

场景：五人晚饭。圆桌，镜头从门口看进去。主角林晚坐近处背对门；父亲坐正对面；母亲坐父亲右侧（画面右）；弟弟坐父亲左侧（画面左）；继妹坐林晚左侧（画面左近处）。剧情：继妹当众说林晚偷了钱，父亲逼问，林晚拿出转账记录反击，母亲当场变脸。

| 镜 | 秒 | 景别与构图 | 画里 | 画外 | 内容 |
|---|---|---|---|---|---|
| 1 | 8 | 主镜头，中全景，门口略高机位 | 全部五人 | 无 | 全家夹菜；继妹放下筷子开口："姐，妈钱包里那三千，是你拿的吧？" |
| 2 | 10 | 三人镜：父亲居中正脸，母亲、弟弟分坐两侧，林晚后脑在前景下方 | 父、母、弟、林晚（背） | 继妹 画左近处 | 父亲把碗一放，看着林晚："你说，拿没拿？"母亲低头不语，弟弟偷看 |
| 3 | 9 | 过肩：越过继妹肩膀拍林晚正脸，父亲在后景虚焦 | 林晚、继妹（肩）、父（虚） | 母、弟 画右 | 林晚不慌，掏出手机放到桌上推向父亲："妈的钱，昨晚转给谁了，您自己看。" |
| 4 | 3 | 插入特写：手机屏幕背对镜头，父亲的手拿起手机 | 父亲的手 | 其余全部 | 必拍事实：手机到了父亲手里 |
| 5 | 6 | 三人镜（和镜 2 同一个 `camera_setup`） | 父、母、弟、林晚（背） | 继妹 画左近处 | 父亲看屏幕后猛地抬头看向母亲；母亲的脸一下子白了 |
| 6 | 4 | 近景反应：继妹 | 继妹 | 林晚 画右，其余在她对面 | 继妹笑容僵住，视线从林晚移向母亲 |

六镜 40 秒。镜 2、5 同机位，起始帧逐字带同一段场景锁；除了镜 6，每镜都能看出这是同一张桌子；镜 6 是全场唯一单人近景，视线方向对得上主镜头里的位置。旧拆法会把镜 2 拍成"父亲单人中景 + 身后两把空椅子"，这正是 EP001 的错。

### 1.4 其他拆镜规则

- **对话对象要看得出**：台词镜默认听者入画（同框，或肩背在前景只露背不露脸）。单人台词镜只在前面已经建立了方位、视线能接上时才用，写 `single_reason`，要引用建立镜的镜号和对象方位。
- **视线**：说话人看着对手，不看镜头。对手在画右，就看画右；和 `gaze` 字段、主镜头里的座位一致。看物件、回避视线、独白才写 `gaze_reason`。
- **越轴**：同场同人朝向保持一致（`facing`）。确需越轴时，要么人物在镜内走过去，要么先切回主镜头重新交代位置。
- **动作只落实一次**：上一镜已经拿到手的东西，下一镜从"已经拿着"开始，不再拿一次。唯一允许重演的是打脸、反杀的峰值动作，一集最多一两处，用 2–3 个机位重复同一下，后一镜 `split_reason` 写"冲击重复：S0x"。
- **因果先有来处**：每个事件（登场、摔倒、冲突爆发、闯入）前面要有起因镜；关键物品第一次出现要有来源镜，或者插入特写加一句台词点明。事件镜写 `requires_setup` 指向起因镜。
- **必拍事实**：剧本每场 `[连续性]` 的「必拍：」抄进 `scenes[].must_show`，承担镜写 `must_show_ids`。数量类要把数字和排布写进起始帧提示词。必拍事实没拍出来，只能重拍、改分镜或回剧本，"台词能解释"不算放行理由。承担必拍事实或关键动作的镜头，人物身高不能小于画高 1/6，关键物件长边不能小于画高 1/8，达不到就交给中景或插入镜。
- **节奏下限**：对白镜取用不短于"台词说完 + 0.8 秒"且不短于 2.5 秒；反应镜不短于 1.5 秒；更短的插入镜写 `fast_cut_reason`。
- **台词装不下**：先加秒数（同一个人就写成长镜头），再删次要手势；还装不下回剧本合并台词。换人说话才拆镜。台词只在剧本阶段改。
- **H3 不生成画外人声**：画外说的话，要么拍说话人在镜的镜头，要么另生成一条音源镜，在听者镜上用 `audio_from` 垫音。

### 1.5 长镜头里要有东西在变

一镜 8–15 秒，如果只是同一张脸同一个构图，观众看到的是幻灯片。长镜头里至少有一样在变：

- 一次完整的动作加反应交接（林晚推出手机 → 父亲伸手去拿）；
- 或一次景别变化（前半段中景，第二句台词前缓推到中近景）；一条长镜头最多一次运镜变化，要两次就该拆。
- 以"凝视、等待"为主的镜头，加一个持续的小变化（呼吸起伏、手指慢慢收紧）。

### 1.6 景别

- 景别由"观众必须看清什么"决定。受气段守在三人/过肩中近景，底牌和反击才进近景。
- 切点要带来可见变化：景别、角度、主体至少改一项；同景别同主体相邻两镜等于没切。
- 远景只在需要交代大空间时用（每场最多一镜），不承担台词、表情和关键动作。
- 每集第一镜要有人在动；关键动作可以给一个 2–3 秒插入特写作重音。

## 2. 镜头规格与机位（SKILL.md 规则 2–4）

规划和执行分开：机位、站位、布局全在这一节定死，出图、出视频只照做。`shots_tool.py check` 的 G55、G56 是硬门，0 error 才能出图。

### 2.1 `camera_setups`：每场先定几个固定机位

shots.json 顶层写 `camera_setups`，一场一般 2–4 个机位（主镜头、一两个三人或过肩、需要时一个插入位）。每个机位三项：

- `scene`：属于哪一场。
- `plate`：这个机位专属底板的 refs.json ID（底板怎么做见 3-视觉设定与图片.md §2.4）。
- `lock`：这个机位的**场景锁**，一段英文，写这个机位下看得见的：
  - 每一件固定陈设（桌、椅、门、窗、柜、灯、画），各在画面哪里（screen-left / centre / screen-right，前景 / 后景），什么材质、什么颜色，可数的写数量；
  - 在场每个人坐在哪、站在哪（只写位置，外观和姿态留给每镜）；
  - 墙面、地面、主光源。

`lock` 写完就不再改一个词：**同机位的每一镜，起始帧提示词逐字粘贴这一整段**（G55 逐字比对），并在 `frame_refs` 挂这个机位的 `plate`。场景之所以切镜头不变样，靠的就是这段字和这块底板每镜都一样。

**换机位**：按视觉设定的平面图重算新位置看得见什么，给新机位写它自己的 `lock`。房间里东西的实际位置不变，画面左右跟着机位变：从南往北拍时碗柜在画右，从北往南拍它就在画左。不要求反打机位保留原机位的画面左右关系，也不把原机位看不见的墙硬写进来。

### 2.2 `spec`：每镜九项规格

每镜写 `camera_setup`（指向上面的机位）和 `spec`，九项都要有内容（G56）：

| 项 | 写什么 |
|---|---|
| `shot_size` | 景别：全景 / 中全景 / 中景 / 中近景 / 近景 / 特写 / 插入 |
| `height` | 机位高度：平视约 1.5 m、坐姿平视约 1.2 m、略高、略低；不写就是平视，不自动俯拍 |
| `facing` | 镜头朝哪、拍谁的哪一面；固定机位写"固定"，要运镜写清唯一一次运动和路径 |
| `blocking` | 画里每个人在画面哪侧、前后、坐站、被什么挡；画外在场者在哪侧。和 `in_frame` / `off_frame` 一致 |
| `props` | 道具在哪、谁用哪只手拿、数量 |
| `start_state` | 起点那一刻每人的姿态、视线、左右手 |
| `end_state` | 结束时每人的姿态、视线、左右手、持物；下一镜从这里接 |
| `link` | 和上一镜的关系，三选一，见 §2.3 |
| `invariants` | 这一镜不许变的东西：正好几个人、谁拿什么哪只手、服装、布局、谁不说话 |

左右一律是画面方向；说身体部位才用人物自身方向（"右手持手机"）。

### 2.3 `link` 三种

- `continuous`：同机位，动作接着上一镜演（上一镜结束状态 = 本镜起始状态）。优先考虑能不能写成一个长镜头；必须切开时用 `start_from_prev`。
- `new_angle`：同一场换机位或换景别。只在交代空间、展示关键信息（手机屏幕、证据）、突出反应时用，在这里规划好，不在生成时发挥。起始帧按新机位的 `lock` 和底板重新出。
- `new_scene`：换场。第一镜通常是这一场的主镜头。

### 2.4 `start_from_prev`：末帧接续

写 `start_from_prev: <上一镜>` 的镜，`produce.py frames` 直接截上一镜所选视频的末帧当起始帧，不生成、不花钱，场景不会漂。

- **可以用**：同一个 `camera_setup`、`link` 是 `continuous`、上一镜视频已经审过且末帧没有硬伤。
- **不能用**：换了机位或景别（G55 拦，末帧不能冒充新角度）；上一镜末帧有错（多手、穿模、人不对），错会一路传下去，改为按规格重出起始帧；连着接了三四次、人物或场景开始漂，回到规格和底板重出一次校准。
- 用了 `start_from_prev` 的镜不写 `frame_prompt`，也不查 `lock`；上一镜重拍后，这一镜要重新截帧、重审。

## 3. shots.json 每镜字段

### 3.1 每镜必填

| 字段 | 写什么 |
|---|---|
| `id`、`scene`、`title` | 镜号、所属场、中文短标题 |
| `camera_setup`、`spec` | 机位和九项规格，见 §2 |
| `duty` | 这一镜让观众得到什么（一句话） |
| `script_anchor` | 承载剧本哪几句 |
| `framing` | 景别 + 谁在哪、面朝哪；标明是主镜头 / 三人 / 过肩 / 近景 / 插入 |
| `in_frame`、`off_frame` | 见 §1.2，两者合起来等于在场名单 |
| `facing`、`gaze` | 主体朝向；有台词的镜写看谁、看画面哪一侧 |
| `dialogue[]` | 逐字等于剧本；`speaker`、`text`、`lang`、`emotion`（情绪·强度·语速·音量）；心声、画外音加 `"vo": true` |
| `seconds` | 按动作和台词容量算的整数秒（H3 4–15） |
| `frame_prompt`、`frame_refs` | 英文起始帧提示词（六类信息，见 3-视觉设定与图片.md §3.2）和参考图顺序；`start_from_prev` 的镜不写 |
| `motion` | 中文动作链：起点 → 主动作 → 台词挂在哪一拍 → 终点 |
| `video_body`、`soundscape` | 视频正文和声景，`shots_tool.py build` 拼成三段 |
| `end_state` | 终点画面，和 `spec.end_state` 一致 |

场级必填：`scenes[].axis`（谁固定在画面哪侧、朝哪）、`scene_state.characters`（全员与座位）、`must_show`。

### 3.2 按需才写

- `start_from_prev`：见 §2.4。`frame_parent` 是旧项目的同机位复用写法，有 `camera_setups` 的项目不用。
- `must_show_ids`、`requires_setup` / `setup_for`、`audio_from`、`overlay`、`sfx`：有对应内容时写。
- `single_reason`、`split_reason`、`gaze_reason`、`fast_cut_reason`、`axis_break`：**只在确实偏离默认做法时写**，一句话，引用本镜可核对的事实（镜号、剧本原句、谁在哪）。挪到别的镜也成立的理由就是套话。
- `boundary` 逐人记账、`keyframe`、`multi_person`、`adversarial_preflight`、`planned_action_window` 等旧字段：`spec` 已经覆盖，不再写。

## 4. 视频提示词

起始帧已经把场景、人物、站位定住了。视频提示词**只写这几秒里什么在变、按什么节奏、最后停在哪**，外加一句不变项。不重新描述房间、不复述剧情、不写外貌（身份漂移时只用 refs.json `drift_anchors` 里的短语，每人最多 3 项）。视频一律图生视频，起始帧必须已按 6-审片与剪辑.md 看过原图、`mark` 通过。

### 4.1 H3 三段结构

```text
integrated_multimodal_description: [Shot 1] <项目头部句> <变化：谁、做什么、台词挂在哪一拍> <节奏：先后、停顿、快慢> <结束状态> <不变项句>
overall_soundscape: <环境声、音效、非语言人声；不重复台词> These are the only sounds in the shot.
non_diegetic_music: N/A
```

- 头部句取 `drama.json` 的 `video_prompt_head`，按画风从 styles.md §1 选；头部句里不许有运镜词（handheld、sway、shake、camera）。
- **不变项句**（必备，按本镜 `spec.invariants` 写全）：`The camera position and angle, the people, their clothing, the room layout and who holds what stay exactly as in the first frame; no one else enters, nothing is added, there are no cuts.` 需要一次有目的的运镜时改写这一句，只写那一次运动。
- **结束状态**（必备）：`… remains … until the end of the clip`，写位置、姿态、持物，和 `spec.end_state` 一致。
- 人名用 `the woman (S1)` 这类稳定称呼，同一个人全文不换称呼，不用 he/she 连续指代。不写文件名、镜号、规则号；不写分支（or）和否定式动作，改成正面的可见动作。

### 4.2 示例：S004 看手机后抬头（同机位连续）

规格：机位 ROOM-A 固定平视中景；人物坐在桌后画面中央偏右，右手持手机，左手放桌面；台灯在画左，门在画右后方。起始状态低头看手机；结束状态仍坐着，抬头看门口。`link: continuous`，上一镜末帧审过无误，`start_from_prev: S003`。

```text
integrated_multimodal_description: [Shot 1] <video_prompt_head> The woman (S1) keeps looking down at the phone in her right hand for about one second. Then she slowly raises her head over about two seconds and turns her eyes toward the door at the back of the room on screen-right. Her right hand keeps holding the phone just above the table; her left hand stays flat on the tabletop; she stays seated and does not stand. No one speaks. She remains seated, head raised, eyes on the door on screen-right, phone still in her right hand and left hand on the table, until the end of the clip. The camera position and angle, the woman, her clothing, the table, the lamp and the door stay exactly as in the first frame; no one else enters, nothing is added, there are no cuts; real-time speed.
overall_soundscape: quiet room, a faint hum from the desk lamp, one soft creak of the chair as she lifts her head. These are the only sounds in the shot.
non_diegetic_music: N/A
```

### 4.3 台词

- 写法：`<d>[Chinese] 逐字台词</d>`。`<d>` 里只放语言标签和台词原文；语种标签等于 `dialogue_lang`；省略号改成逗号。
- 每句紧跟在说话人的可见动作后面，只出现一次。说话方式、视线写在 `<d>` 前面：`At about half a second the woman (S1), on-screen, keeping her eyes on the man off screen-right, says in Chinese through gritted teeth, her voice cracking at the top: <d>[Chinese] …</d>`。
- 情绪写成声音质感和重音，不写事件从句（写"因为她的位置被抢"，模型会把抢位置画出来）。句中句后不写 pause、beat、silence，模型会在停顿处补字。
- 画里有第二张正脸时写 `<Other> does not speak; his lips remain completely closed for the whole shot.` 模型会把口型放到画面里最显眼的那张正脸上。
- 最后一句后写：`These are the only words spoken in this shot, each said exactly once; nobody speaks before the first line or after the last.` 无台词镜写 `No one speaks, laughs, shouts or cries out.`
- **心声（`vo: true`）不写进视频**：心声和画外旁白后期配音。视频里这一镜按无台词写，说话人嘴唇闭合，只演表情和动作（`her lips stay closed; her eyes narrow`）。
- 长镜头里的多句台词各挂一拍，两句之间写清人在做什么（`she lowers her eyes to the cup, then looks back toward screen-right and adds:`），过渡只用呼吸、视线、换重心三种之一，不超过 0.5 秒。

**容量**：发声窗口 = 镜长 − 开口前等待 − 不能并行的动作 − 别人说话 − 末尾落点 0.5–1 秒。H3 中文实测约 4 字/秒，5 秒镜约 15 字；日语按 `speech_rates` 估，首批 ASR 出来后用实测校准。放不下按顺序减：删装饰运镜 → 删次要手势 → 加秒数 → 让台词跨到下一镜（剪辑层 L/J-cut）。不许加速、截断、偷删字。

**表演**：每镜最多两个当前景别看得见的信号（眼神 + 呼吸、手 + 重心），强度分三档：弱写 `barely`、中写 `slightly`、强写 `clearly` 并加一个上限（`her mouth stays closed`）。不写 smirk、sneer 这种词，改成肌肉和肢体动作（"一侧嘴角上提，眼睛不笑"）。480P 下 0.5 秒以内的微表情看不出来，峰值镜至少要有一个整体动作（后退半步、猛地站起、把东西拍在桌上）。


### 4.4 动作怎么写

- **一条视频一个主动作。** 动作比镜长短时，用同方向的余势填满（递出后手臂停在前伸位置），不留空让模型倒放；需要往返的动作拆成两镜。
- **节奏写成秒数和先后**：`for about one second`、`over about two seconds`、`then`。不写 `a little`、`briefly` 这类伪量词。
- **物理动作按常识写**（摔、滑、撞、泼、打翻、推倒）：写多快（滑倒从脚离地到着地不到半秒）、往哪倒（顺着惯性）、失控（不屈膝慢慢放下自己）、怎么落地（砸下、反弹、溅水、闷响）、东西落在哪。距离按画面里可数的东西写（`across three tiles`、`one full stride`）。不写就会得到慢吞吞的"坐下"。
- **手和道具**：动的那只手属于谁、拿什么；没动的手写它停在哪。道具用和起始帧一样的短语。
- 画面不出字：手机屏幕背对镜头，招牌、书页是无字表面。

### 4.5 提交前自检

1. 三段齐全，`non_diegetic_music: N/A` 在；`<d>` 里的台词逐字等于剧本，语种标签对。
2. 只写了变化、节奏、结束状态和不变项句；没有重新描述房间和外貌。
3. 起点等于起始帧姿态，一个主动作，结束状态和 `spec.end_state` 一致。
4. 不变项句覆盖了 `spec.invariants`；听者可见脸写了 lips closed；心声镜没有写进 `<d>`。
5. 说话人视线方向和 `gaze`、`spec.blocking` 一致。
6. 物理动作写了速度、方向、落地；位移有可数的距离。
7. 声景末句 `These are the only sounds in the shot.`；同场相邻镜底声一致。

机械门 `shots_tool.py check`（含 G54–G56）跑到 0 error 再提交；warn 逐条判断，不靠堆字消警告。

### 4.6 Seedance 等其他模型

用户指定 Seedance 时，外壳按 Seedance 语法：不用 `<d>` 和三段字段名，台词写成 `S1 says in Chinese: "…"`，2.5 版可按时间段分段；续接上一段实际结果时，上一段视频作参考视频、它的尾帧作参考图，不当首帧用。§4.1–4.4 的写法照用。接新模型前先按 5-生成.md §1 把能力写进决策记录，不套用名字相近模型的语法。

## 5. 常见漏洞与失败定位

模型会钻字面空子：没写死的东西它按最坏情况补。写完按下表扫一遍：

| 模型怎么钻 | 堵法 |
|---|---|
| 多画一个人、同一人画两次、在场的人消失 | 起始帧人数排他句 + 画外在场者方位（3-视觉设定与图片.md §3.2）；视频不变项句写 no one else enters |
| 口型挂到画面里最显眼的正脸上 | 听者背对镜头，或写 lips remain completely closed；写明全程只有谁开口 |
| 裸 left/right，人物对着镜头时读反 | 写 screen-left / screen-right，同句写朝向 |
| 只写"固定"，模型用摇镜代替人物动作 | 不变项句写全 camera position and angle stay；头部句不带运镜词 |
| 物理动作拍成慢动作或坐下 | 按 §4.4 写速度、失控、落地 |
| 一条视频塞几个动作，最难的被丢掉 | 一镜一个主动作；难动作从起点写起 |
| 加笑声、惨叫；停顿处补字 | 声景末句 These are the only sounds；台词中间不写 pause |
| 提示词和起始帧朝向矛盾，模型按起始帧改掉动作 | 写之前先看起始帧，动作方向跟着它 |

生成失败时先定位再改，按顺序查：

1. 起始帧本身是不是已经错了（错图会被视频忠实接住，提示词救不回来；回起始帧或分镜）；
2. 提示词里有没有互相矛盾的指令；
3. 动作和台词在这个秒数里装不装得下；
4. 这个动作模型是不是根本做不到（做不到就换拍法，不继续加限定语）。

重试次数和两次失败后的简化按 6-审片与剪辑.md §2。需要时可以用 `adversary_plan.py` 派攻击子代理找提示词漏洞，这不是必做步骤。改了提示词却没重出，结果写"未验证"。
