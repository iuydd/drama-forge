# 3 视觉设定与图片：设定、参考图、起始帧、画风、目检

阶段 D（视觉设定、refs.json）、F（参考图）、G（起始帧）读本文件。它合并了旧的 3-视觉设定与图片.md、3-视觉设定与图片.md、styles.md 和 SKILL.md 里的 6d、6e 视觉条文。与 SKILL.md 冲突时以 SKILL.md 为准，特别是规则 3 和 5：**切镜头场景内容必须相同；起始帧提示词把画面里每样东西都写到。** 机位（`camera_setups`）和场景锁（`lock`）在分镜阶段定，写法见 4-分镜与视频提示词.md §2；本文件管平面图、底板和起始帧怎么落实它。

通用约束（下文不再重复）：
- 提示词正文一律英文，含 `no text`；画面里不出任何可读文字，字全部后期叠加。
- 模型、档位、分辨率只用 `drama.json` 里用户定下的 `profiles`，不写进提示词正文。
- 参考图、起始帧绑定前必须用看图工具看过原图；文件名不算看过。
- 旧图不覆盖，重出开新 take。

## 1. 视觉设定.md 写什么

文件是 `EPxxx/视觉设定.md`（骨架 `assets/templates/视觉设定.md`）。标题必须是 `## 人物 · <名>`、`## 地点 · <名>`、`## 道具 · <名>`，脚本靠它解析。

### 1.1 全剧共用的一段

- **时代基准**：写一个具体年代或朝代（`1998 年前后的中国县城`、`明代中后期`），不写"古代""架空"。架空世界写它像哪个朝代。家具、窗棂、服装形制都按它写。
- **画风**：`style_preset` 与 `style` 句（见 §5）。
- **全组身高次序**：例如"三上最高，遥比他矮约半个头"，每人再写厘米身高。
- **失效信号**：出现就算错的东西（例：现代插座出现在古装里）。

### 1.2 人物

每个人物分两层写：

- **身份**（换衣、受伤后仍然认得出的东西）：脸型、五官相对关系、发际线与发型剪影、体形、厘米身高、永久特征（痣、疤）。正面、侧面、背面各至少一条可见锚点。自检：遮住本集服装和伤污，这个人还能和别人分开吗？
- **造型**（某段时间的完整外观）：服装从头到脚、发型整理、伤、湿、污。写从哪场生效、到哪场失效。换装、受伤、湿身按变体处理，不改身份。
- **画面代称**：英文正文里用的唯一拼写（`Haruka`），全剧一致。
- **音色**：写进 refs.json 的 `voice`，英文参数串，顺序是"年龄性别、音色、音区、气息、动态范围、音量、语速、句尾习惯、口音、默认情绪"，约 400 字符以内。口音必须和台词语言一致（`native Japanese speaker, natural Tokyo accent`）。不写比喻、表演指导和引号台词。判别法：角色安静地说一句无关的话时还在的特征才写进 `voice`，其余是表演，写进台词的 `emotion`。
- **口吻**：一人称、称谓与敬语层级、句尾习惯，一行。

易混角色至少两个通道不同（发型剪影、服装主色、体形），并排读身份描述，删掉逐字重复的模板句（"九头身长腿"）。人物关系不决定美丑，憋屈期的主角也按主角的吸引力写。

### 1.3 地点：每个场景一张平面图 + 每人座位

这是规则 2 的落地。每个主场景必须写：

```text
平面图：餐厅约 4×5 m，入口在南墙东侧；长方桌南北向放在房间中央，桌面 180×90 cm、高 75 cm；北墙是窗，东墙是碗柜，西墙挂一幅画。
座位：北端 父亲（背对窗）；东侧 母亲（北）、夏樹（南）；西侧 姐姐（北）、弟弟（南）；南端空位（机位常在这里）。
动线：夏樹从南门进 → 沿东侧走到自己座位坐下。
机位与底板：DIN-A = 从南端空位看向北墙（窗在后景），底板 IMG-PLATE-DINING-N；DIN-B = 从北端父亲身后看向南门，底板 IMG-PLATE-DINING-S。分镜里每个 camera_setup 对应这里的一行。
```

- 写清画左画右各是什么，同场各底板要拼得回这张平面图。
- **尺度**：至少一个现实尺寸（门高约 2.1 m、桌面约 75 cm、椅面约 45 cm、护栏约 1 m、台阶一级约 17 cm）。桌子要能坐下座位表里的所有人，写数字前按人数算一遍桌长。
- **空间要说得通**：门后不接门；楼梯一段只有一个方向；窗外景和楼层一致；走廊尽头有门、拐角或楼梯；栅栏、玻璃、崖沿两侧各是什么写死。
- **保养水平**二选一：日常使用（掉漆、水渍、磨白）或持续维护（漆面完整，只在门槛、扶手这些人常碰的地方有磨损）。同一批地点并排看，不要全是同一种"破旧"。
- **状态**：昼夜、停电、下雨这类要跨镜持续的状态才新建底板版本。光、天气必须有剧本来源，不凭提示词惯性加霓虹、雾、逆光。改光时这个地点所有底板一起改。

### 1.4 道具

三条同时满足才单独建道具：有特写或插入镜、跨场出现、少了它剧情推不动。一部剧通常 3–8 件。普通桌椅杯子写进底板，一次性消耗品写进该镜提示词，屏幕内容和特效走后期。

- **身份**：尺度、形制、材料、功能、永久标记。**状态**：谁拿着、哪只手、放在哪、开合、内容物。状态变化不新建道具（打开的匣子仍是同一个匣子）。
- 道具名逐字沿用剧本。
- **形制写死到排除歧义**：剧本说"从线圈本撕下的一页纸"，道具只写 `one single loose sheet of lined paper, no spiral binding, no notebook`。提示词里写"从线圈本撕下"，模型会把线圈画出来。
- 能兑现、能证明的关键道具（令牌、证据、钥匙）还要写：从哪得到、现在谁拿着、触发时观众看到什么、还剩几次。

### 1.5 连续性锁

跨两镜以上、观众看得出、不随剧情变的可见事实，写成一小段英文锁面（颜色 + 材质 + 物体，如 `charcoal grey blazer`），放在 shots.json 顶层 `locks`，逐字带进范围内每条起始帧和参考图提示词（G23）。锁面内部不能改一个词；否定句里出现不算携带。生效范围按事实实际出现的镜头写。没建档但跨镜出现的小物件（杯子、包）也定一句固定短语，每镜逐字复用。

状态变化（受伤、湿衣、停电）写前态、后态、原因场次、生效范围。最后一次明确的状态一直有效，没提伤不等于伤好了。

## 2. refs.json 与参考图提示词

### 2.1 字段

```jsonc
"IMG-HARUKA": {"kind": "identity", "subject": "遥", "name": "遥 全身身份参考",
               "controls": "脸、低马尾、体形", "not_controls": "服装、姿势、表情、背景",
               "voice": "…", "refs": [], "prompt": "…"},
"IMG-HARUKA-FACE": {"kind": "identity", "subject": "遥", "refs": ["IMG-HARUKA"],
               "controls": "脸、发际线、肤质、眼睛", "not_controls": "服装、体形、姿势、背景", "prompt": "…"},
"IMG-PLATE-DINING-N": {"kind": "plate", "location": "餐厅", "refs": [], "prompt": "…"},
"IMG-PLATE-DINING-S": {"kind": "plate", "location": "餐厅", "refs": ["IMG-PLATE-DINING-N"], "prompt": "…"},
"IMG-PROP-NOTE": {"kind": "prop", "subject": "纸条", "prompt": "…"}
```

- 不写 `profile`、`res`，一律读 `drama.json.profiles`。
- `controls` / `not_controls` 写这张图管什么、不管什么。一张图只回答一个问题（身份、造型状态、地理、道具形制、风格），两件事就拆两张。
- 已确认是同一地点的旧底板可以写 `same_place_as` + `same_place_note`（目检结论）代替重出；一场戏确实是两个地点（电话两头）在 shots.json 的 scene 写 `plate_groups`。
- 转面板写 `"layout": "multi_view"`，不直接挂进起始帧；要背面、侧面就裁格另登记（`crop_from`）。
- 实拍照片当身份图时加 `source` 说明；照片里的校名、胸牌先模糊。
- 头肩图 `-FACE` 不写 `voice`。

检查命令：

```bash
python3 $S/shots_tool.py check-refs <项目>   # G18–G20、G34：身份图一个人+厘米身高、底板 No people+画左画右+尺度、道具 no hands、提示词雷同
python3 $S/visual_lint.py <项目>             # V01–V06：转面板误挂、派生图保留句与改写动词、锁面粘词、质量词
```

### 2.2 写法共通点

顺序：用途与主体 → 稳定锚点 → 这一版的差异 → 构图与尺度 → 材质色彩光 → 背景/空场 → 排除。

- 锚点少而准：一个轮廓、一个比例、一个局部特征，胜过十个形容词。
- 不写 `cinematic, 8K, masterpiece` 这类质量词；画风只靠 `style` 句。
- 正文不出现 JSON 键名、IMG ID、文件路径。
- 派生图（头肩图、变体、派生底板）第一句是保留句，改动只用 `change only / replace / remove / add`，不用 `transform / turn into`（会把人整个换掉）。年龄段变体例外，不写 `same face`，只保留肤色和永久特征。
- 身份图只画常规干净状态：素背景、正面、全身、中性表情、`arms relaxed at the sides`，不带以后会消失的饰品和伤。服装句先写形制（双排扣大衣、圆领袍），再写面料、配饰；使用痕迹最多一处。
- 有台词的主要人物必做头肩图 `-FACE`：起始帧是中近景、近景、特写时绑它，中景及更宽绑全身图，两张不同时绑。

### 2.4 底板规则

- **每个机位一块底板**：`camera_setups` 里每个机位的 `plate` 指向一块专属底板，一块底板只服务一个机位。底板提示词里的固定陈设清单要和这个机位的 `lock` 一致：`lock` 写了的每件陈设，底板里在同样的画面位置、同样的材质颜色；底板里多出来的东西，要么补进 `lock`，要么重出底板。先出底板、目检通过，再定稿 `lock` 的措辞。
- **默认空场**：`No people`。写画左画右、至少一个尺度参照。
- **同场底板必须派生**：每场先定主底板，其余方向的底板 `refs: [主底板]`，用上面那种相机操作句。所有同场底板机位高度一致（默认平视约 1.5 m）。各自独立生成的两块底板，材质颜色必然对不上。
- **派生两次失败的后备**：以主底板为参考生成一张左右两格横幅（左格主方向、右格转 180°，同一光源，无字无人），裁出右格登记为派生底板，只作虚焦背景用。
- **固定大件是空间锚点**：裁近只改变哪些部分出画，不能缩放、改形或挪动桌椅门柜来凑人数或景别。源图里桌子已经显小，先修视觉设定和主底板，不在每镜写 `larger` 掩盖。
- **分清场内总数和画内可见数**：场里 5 个人不等于画面里 5 个人，按机位逐一标画内、被挡、画外哪侧。

## 3. 起始帧提示词

### 3.1 参考图

- 默认 2 张（底板 + 一个身份），双人接触镜 3 张，**不超过 3 张**。超了按"链式帧 > 露脸说话人身份 > 底板 > 其他露脸人身份"取前三。只露背影的人不挂身份图。
- **带底板或父帧的起始帧、派生参考图必须用能按参考图编辑的档位**（如 qwen21）。只把参考图当风格用的档位（h3studio krea2 系列，`drama.json` 的 `style_only_profiles` 可覆盖）**不能挂底板**，只出无参考的身份图和道具图；`produce.py` 提交前会拒绝。
- 底板写成"人物所在的真实三维空间"，不写 `as a background`，否则人会像贴在背景板前，站位乱跳、脚下没地。

### 3.2 六类信息（SKILL.md 规则 5）

起始帧只写镜头开始那一刻看得见的画面，按下面六块组织，缺一块不许出图。规格来自本镜 `spec` 和机位 `lock`，不临时发挥；规格不全回分镜补，不自己猜。

| 块 | 写什么 | 来自 |
|---|---|---|
| ① 场景结构 | 本机位 `lock` 整段逐字粘贴（G55 查），不改一个词 | `camera_setups[机位].lock` |
| ② 机位与景别 | 景别、机位高度、朝向、焦段（按画风，见 §5）；静帧不写任何运动词。`start_from_prev` 的镜不写提示词，直接用上一镜末帧 | `spec.shot_size / height / facing` |
| ③ 人物位置与遮挡 | 人数排他句 `Exactly N people, each appears once`；每人名字 + 外观锚点与服装锁、在画面哪侧、前后（以镜头为准）、脚下或身下是什么、被什么挡住（坐在桌后，上身露出桌沿）；画外在场者写名字和在画外哪侧 | `spec.blocking` |
| ④ 姿态、视线、左右手 | 身体朝向、看向谁或画面哪侧、左手右手各在做什么、持物；表情写肌肉状态，不写 `worried` | `spec.start_state`、`spec.props` |
| ⑤ 不可改变项 | 正好几个人、谁拿什么、哪只手；可数陈设 `exactly N` 加同类排他句；光的来源方向；尺度锚点 | `spec.invariants` |
| ⑥ 画面限制 | 不多人、不多肢、不穿模、不加道具、不出字；参考图分工句；版式句 `A single clean full-bleed frame: no borders, no panel dividers, no labels, no text, no watermark.`；最后 `Style: ` + `drama.json.style` 原句 | 固定句 |

- 只写起点：结果才出现的事实（手已握住、门已开）删掉，移到视频提示词。与上一镜相同的部分也写成绝对事实，不写"同上"。
- 左右一律指画面方向（screen-left / screen-right），身体部位才用人物自身方向（`her right hand`）。同一句里写清朝向，避免人物面对镜头时读反。
- 参考图分工句逐张点名：`Picture 1 is the real room they sit in: take walls, table and lamp positions from it; do not copy any person from it. Picture 2 sets only her face and hairline.`

### 3.4 实拍教训（qwen21 已出过的错）

| 现象 | 原因 | 写法 |
|---|---|---|
| 朝北拍多人桌戏，坐着的人被画到桌子前面 | 没说桌子和人谁在前 | 写 `the table edge runs across the lower foreground in front of everyone; all are seated behind it`、`nobody is in front of the table` |
| 挂主底板拍近景，人背后多出第二张桌子 | 模型把底板的桌子当背景又补了一张近处的 | 写 `do not add a second table`，说明画内这张就是底板那张的哪一段；桌子出画就写它在画框下沿以外 |
| 正面机位写"她抓住他的椅背"，画成抓自己身前多出来的一把椅子 | 正面机位看不到被抓的椅背，模型就造一把 | 接触椅背、后领、背后这类动作改用背后插入镜（从身后拍手和椅背），正面镜只拍脸和反应 |
| 让模型"换个角度"出同一场景，出来是另一个房间 | 文字换角度不可靠 | 分镜里先定新机位和它的 `lock`，按 §3.5 做该机位的派生底板，起始帧挂同机位底板 |
| 写"从线圈本撕下的纸"，画出线圈 | 提示词里出现的物件会被画出来 | 道具写死 `one single loose sheet, no spiral binding`，不写来源物 |

通用判断：同一镜同类失败出现两次，先改输入（换底板、换构图、改成插入镜），不继续加词重抽。

### 3.5 转机位（6d）

同一场所有镜头的背景必须读得出是同一个地方。有底板的镜头禁止水平镜像起始帧。

- **只是收紧景别、透视不变**（取桌角、门把手）：在已核验底板内取景，不算转机位。
- **需要新透视**（越过桌子、看到原图背后的墙）：先按平面图做该机位的派生底板并目检"空间说得通"，起始帧挂同机位底板，写"保持 Picture 1 的背景与机位，只加人物"。
- **出帧时不许临时换角度**（SKILL.md 规则 2）。要新角度，回分镜加一个 `camera_setups` 机位：按平面图重算这个机位看得见什么，把固定物件（门、窗、柜、灯、画、桌椅）写成这个机位自己的 `lock`，各在画面哪里、看不见的为什么出画；房间里东西的实际位置不变，画面左右按新机位重排，不把旧机位的画左画右原样复制。再按上一条做派生底板、目检，起始帧挂它。

## 4. 局部编辑与重出

重出或改一处时写四项：目标（哪张图、哪个区域）、变化（看得见、有边界）、保留（逐人点名位置、朝向、持物，脸、服装、固定地理、光向；不写 `everything else` 这类集合词）、影响哪些镜头。每一轮都完整重复保留清单，只改失败的那一项。一次只改一组相关变化。改门窗、身份、道具状态属于改上游事实，先改视觉设定。

身份漂移按这个顺序排查：身份图清不清楚（近景该绑 `-FACE`）→ 删掉职责重叠的参考 → 调参考顺序 → 改分工句 → 最后才动风格句。

## 5. 画风

`drama.json` 写 `style_preset`（七选一）和 `style`（起始帧、身份图、底板共用的一句），全剧锁定，回忆和梦境也不换，需要区分就改色调和光。中途换画风等于整剧重出参考图。视频用 `video_prompt_head`（头句 + 保持句），立项时定下全剧不变。判不出选 `live_modern`，写进决策记录。风格句只写画风质感，不写运镜和粒子、雾、体积光这类特效词。定画风前每个候选各出一张起始帧 + 一条 5 秒视频，看视频里画风保不保得住；没授权试镜就写"未试镜"。

| preset | 适用题材 | 头身比 / 身高 | 识别靠什么 | 起始帧镜头词 | 视频保持句要点 |
|---|---|---|---|---|---|
| `live_modern` 真人都市（默认） | 打脸、职场、校园、豪门、家庭、悬疑 | 成人 7–7.5；高中男 165–180 cm、女 155–165 cm | 面部结构、皮肤 | 焦段 + 浅景深（35/50/85mm） | 皮肤毛孔保持，脸不磨皮、不变形 |
| `live_period` 真人古装 | 权谋、宅斗、宫斗 | 真人比例；身高不含发髻 | 面部结构、服色等级 | 同上 | 绸缎有重量，烛光窗光暖且有来源 |
| `live_xianxia` 真人修仙 | 修仙、宗门、师徒 | 真人比例 | 面部结构、法术主色 | 同上 | 电视剧质感，法术光克制、照亮附近的脸 |
| `anime_cel` 日系动漫 | 校园异能、轻小说、异世界 | 6–7（高中生约 6.5） | 发型剪影、发色、瞳色高光、固定配件 | `flat 2D framing, background painted softly out of focus`，不写焦段、bokeh、cinematic、4k | 始终 2D 细描线平涂，不变 3D 不变照片 |
| `guoman_3d` 3D 国漫 | 大场面修仙、玄幻、续季 | 7–8 | 下颌线、眼型、发型分层 | `virtual camera, 35mm equivalent`，不写 photograph、film grain | 始终风格化 3D，发丝分缕、轮廓光一致 |
| `manhwa` 韩漫 | 复仇重生、霸总、恶女，竖屏 | 约 8 | 发色、瞳色、配饰 | `chest-up portrait framing, softly blurred glowing background` | 细线稿柔渐变，不出对话框和分格线 |
| `cg_realistic` 写实 CG | 科幻、末日、怪物、机甲 | 同真人；非人角色写高度并给人物参照 | 面部结构、材质 | 同真人 | 电影特效质感，重物有重量，不像游戏过场 |

- 画风只改头身比和表面处理，**不改环境尺度**：动漫里护栏仍到腰、门仍比人高约 1.2 倍。
- 画风不改身份事实：不因为难画把五十岁写成二十五岁，也不为好看新加疤痕、异色瞳。某锚点在本画风下画不出来，换一个同样可比较的锚点并记决策记录。
- 非真人画风的视频头句不写 `realistic human behaviour`、handheld。
- 水墨、Q 版借 `anime_cel` 当 preset，`style` 整句换写，决策记录说明借用。
- 题材色调（悬疑、赛博朋克）接在 `style` 的色彩部分，和画风正交，不新增 preset。

### 5.1 系统面板主题

金手指面板、系统提示、圣旨这类画面上的字全部由 `cut.py` 的 `panel` 后期叠加，写在 `drama.json` 的 `overlays.panel`，全剧一种主题。预览用 `cut.py --panel-demo`。

| 主题 | 适用画风 | 外观与入场 |
|---|---|---|
| `tech`（默认） | `live_modern`、`cg_realistic`、现代题材动漫 | 半透明深色玻璃、冷青描边外发光、`SYSTEM` 标题、扫描线；缩放入场、逐字打出、电子"叮" |
| `xianxia` | `live_xianxia`、`guoman_3d`、修仙动漫 | 深褐玻璃、金色描边、符文图标、标题「灵识」；逐字较慢、钟磬声 |
| `scroll` | `live_period` | 宣纸底、两根卷轴、朱印；横向展开、逐字落墨、纸声 |

```jsonc
"overlays": {"panel": {"theme": "tech", "accent": [0, 229, 255], "title": "SYSTEM", "position": "top_left"}}
```

主色不和印章字撞色；位置默认左上，避开右上角 AI 标识和说话人的脸，起始帧给面板那侧留空；每行一件事，最多 3 行，规则解释写成台词。

## 6. 出图后逐张目检

每张都看单张原图，网格只用来找可疑处。目检写具体观察，用 `review_tool.py mark <项目> <EP> <SID> --frame-take N --evidence "…"` 绑定起始帧 sha；"看过无问题"按没做算。

**身份图**：一个人、全身、正面、无字无水印；锚点和视觉设定一致；和同批人物并排看分得开。头肩图和全身图并排看是不是同一人。

**底板**：
- 空场、无字；画左画右和平面图一致。
- 空间说不说得通：楼梯上下对、门后不接门、窗外景和楼层对、走廊有去处。
- 尺寸现实：门、护栏、桌面、椅面对得上现实值。
- 同场底板并排：是不是同一个地方从不同方向看；主光来源、冷暖、灯具开关一致。不是就重出派生的那块。

**起始帧**（每张逐项写）：
1. **人数**：画面里几个人，是否等于提示词；有没有同一人出现两次。
2. **在场者**：本场在场的人是否都在画里，或者能读出在画外哪侧；有没有人凭空消失、只剩空椅子（规则 3）。
3. **位置与前后**：每人在画面哪侧、朝哪；坐着的人在桌子后面还是被画到桌子前面；脚下是不是实地。
4. **手**：数每只手属于谁，有没有多手、手连不到身体。
5. **固定物件**：和底板比，有没有多出第二张桌子、多一把椅子、门窗挪位或增减；桌子尺寸有没有被缩小。
6. **持物与道具**：数量、在谁哪只手、形制对不对（纸条有没有长出线圈）。
7. **尺度**：看得到脚和门框或护栏时量像素比，和期望值比（例：2.1 m 门、172 cm 的人，门/人期望 1.22），偏差超过约 10% 判不过；看不到写"不可量"。
8. **无字**：画面里有没有字、水印、分格线。
9. **接不接得上**：和同场上一镜并排比背景、光、服装锁、道具状态；有没有被整体镜像。

第 5 项另查：`lock` 里写的每件陈设都在、位置对，没有多出来的。任一项不过就 `--retake`；重试次数和两次失败后的简化，按 6-审片与剪辑.md §2（每镜最多重试 2 次）。

## 7. 阶段 D 过关前自检

- 每个场景有平面图、每人座位或站位、主底板和各机位底板的对应关系。
- 每个人物有身份与造型分层、厘米身高、音色、口吻；主要说话人有 `-FACE`。
- 道具形制写死到不会被误画；锁面列全。
- 每个机位有专属底板，底板目检通过，陈设和该机位 `lock` 一致。
- `check-refs` 与 `visual_lint` 跑过。本阶段不派独立 reviewer。
