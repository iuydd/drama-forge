# 04｜人物、对手与世界：让胜利有分量

## 1. 最小主角卡
主角不只是“善良、聪明、很强”。至少写明：

`眼前目标 / 长期愿望 / 不愿接受的生活 / 核心能力 / 对人的习惯 / 独特选择方式 / 底线或价值偏好 / 私人小愿望 / 与世界的矛盾 / 说话特点 / 视觉标识`。

强者可以不需要治愈某个心理创伤；也可以保持性格稳定，改变周围世界。人物弧不是强制“自卑→自信”，还可以是“已有信念→被不同情境检验→把信念落实为制度”。

三个检验问题：
1. 换一个拥有相同能力的人，故事会不会完全一样？会，则增加主角的选择方式。
2. 观众除了羡慕其奖励，还想看其做什么？
3. 不介绍身世，能否通过一个动作认识此人？

喜欢修东西的人先扶正别人的椅子；追求掌控的人在混乱中先划清物品位置；珍惜平等的人把给自己的座位挪给最懂现场的人。不要把例子变成固定人设。

## 2. 配角必须拥有自己的生活
为核心配角填：想要什么、害怕失去什么、知道什么、擅长什么、与主角的交换、可能改变的立场。至少有一项贡献不能被一句主角台词替代。

角色功能可以重叠，避免为了“见证、解释、搞笑、被救、夸主角”各造一个人。低成本短剧优先少量鲜明人物，而非大量姓名。

盟友不应永远错误，专家不应只会震惊，恋人不应只是奖励，弱者不应只是反复被绑架的按钮。群众也可以有分化反应和自己的判断。

## 3. 反派与阻力分开
故事可以没有恶人。阻力可来自自然条件、资源不足、规则惯性、认知差异、时限、互相冲突的正当目标、主角自己的选择或未知事实。

有反派时记录：`目标 / 合理资源 / 信息范围 / 错误判断 / 最佳可行策略 / 败因 / 败后更新`。

“让反派聪明”不是让其凭空知道主角秘密；是让其在自己的信息与利益下采取合理行动。反派发现能力差距后继续原套路送死，需要额外动机，否则改为合作、撤退、博弈或换竞争维度。

单集对手可以快速退场；长期对手需要独特方法与可持续关系，不只是无限亲戚链。

## 4. 世界的五个支点
1. **日常**：普通人怎样生活，什么是真正重要的？
2. **稀缺**：什么资源、权限、信任或知识决定选择？
3. **分配**：谁决定谁能得到，依据是什么？
4. **验证**：什么证据被认为可信，如何传播？
5. **改变**：主角的行为会让哪些规则失效或演化？

首集只展示与当场行动相关的部分。世界百科不是剧本。

现实职业的细节需有可靠依据；不能凭空编造医疗、法律、金融流程并当成现实指南。无时间核实时改成明确架空的机构、规则和技术，避免看似专业但实际错误。

## 5. 三种“知道”
对关键事实区分：观众知道、主角知道、其他角色知道。每次知情变化都必须有来源：目击、证据、可信传话、公告或推断。

`fact_id / 内容 / 真伪 / 生效集 / 知情者 / 来源事件 / 公开范围 / 仍存误解`。

观众知道主角强，对手不知道，可以形成期待；观众不知道的秘密可以形成谜团，但不能回头否认已直接展示的事实。角色误判与作者撒谎不是一回事。

## 6. 连续性不是只有衣服
同时检查：
- 时间：行动能否在给定时段发生，旅程和消息传播是否合理。
- 空间：人和物是否能到达，出入口是否先建立。
- 因果：结果是否由已存在的条件产生。
- 物件：位置、数量、持有者、完好程度是否接续。
- 能力：已学会的技能和有效边界是否保留。
- 心理：立场变化是否有触发事件。
- 社会：公开成就是否进入相关群体的认知。
- 版本：修订之后，旧大纲和新正文是否冲突。

稳定 ID 例如 `CHAR-001`、`LOC-001`、`PROP-001`、`ABILITY-001`、`FACT-001`。称呼可以随关系改变，ID 不变。

## 7. 不依赖羞辱的开局关系
可从被需要、主动交易、遇见同类、专业分歧、旧承诺、平等竞争、陌生人互助、邀请入局开始。

必须写轻视时，让轻视有具体来源和短兑现路径，避免大量侮辱台词。强者的尊严不必靠所有弱者下跪来表现；可以是他不再需要解释、别人尊重其边界、真正懂行的人交出决定权。

## 8. 世界反馈表
每个阶段大事件之后更新：
`受益者怎么做 / 利益受损者怎么做 / 专业组织怎么做 / 不知情者为何不知情 / 新机会 / 新规则或价格 / 主角可拒绝什么`。

这张表是长期爽感的来源：观众不只看见赢，还看见赢过之后的生活真的不一样。

## 追加｜人物知道与公开表态并不相同

隐藏身份与误判戏使用 15 的信息结构。分别记录实际事实、人物信念、公开立场和利益：反派知道真相仍嘴硬，是另一种状态，不是“不知道”。剧中群众按不同证据或利益分批转向，至少给关键转向一个动作后果。新地图的人可以没收到消息，旧地图已经知情的人不能每集重新误判相同事实。
