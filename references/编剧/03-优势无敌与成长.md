# 03｜优势、无敌与成长：保住爽感承诺

本手册不把“角色越痛苦，故事越高级”当成原则。边界帮助观众理解能力，但边界不等于必须伤害主角；轻松无敌和快速成长都是有效的创作方向。

## 1. 六种主角强度模式
| 模式 | 必须兑现 | 主要看点 | 禁止偷换 |
|---|---|---|---|
| 开局无敌 | 尽早证明压倒性能力 | 怎样赢、为何出手、世界反应、私人愿望 | 暗设一层敌人立刻把无敌变废物 |
| 高起点成长 | 很强且还能获得质变 | 新用法、系统组合、影响范围 | 每到新地图清零旧成果 |
| 快速升级 | 进步频繁且观众能看懂 | 可见目标、稀缺奖励、阶段突破 | 只报数字、长期没有实质变强 |
| 专项强者 | 某领域可靠地出色 | 跨领域应用、合作与选择 | 让其在专长内持续犯低级错 |
| 智略/资源优势 | 判断、组织或布局有效 | 证据、前置安排、反制、经营 | 对手集体降智衬托聪明 |
| 普通人成长 | 行动与学习确有积累 | 技能、关系、勇气、自主性 | 没有铺垫突然全能 |

另可选择反英雄、群像、天才隐居、强者重启事业、集体升级、双主角互补等结构。战力曲线与人物情感变化不是同一条线。

## 2. 优势卡
为金手指、超能力、系统、道具、重生知识、身份权限或专业技能建立统一卡片：

1. 核心操作：用普通话讲清“能做什么”。
2. 优勢来源：已解释 / 暂时未知；来源未知不能成为随意添加功能的借口。
3. 可观察证据：观众第一次怎么知道它有效？
4. 适用对象与范围：对什么有效；范围可极大，但必须一致。
5. 主角参与：如何选择目标、方法、组合或时机？
6. 优势独占性：别人为何暂时做不到？身份、发现、积累、权限等，不一定永远独占。
7. 获取与使用条件：如确实存在则填写；允许 `none`，不要硬加扣血、折寿。
8. 稳定边界：不会做什么 / 尚未证实什么。区别“没有能力”与“还没展示”。
9. 成长方向：效率、精度、组合、范围、持续性、可转授性、社会用途。
10. 世界回应：谁受益、谁失去优势、谁会适应或争取合作？
11. 早中后期专属场面：同一规则的不同应用。
12. 漏洞检查：复制资源、无限循环、时间悖论、控制他人、经济崩溃是否应在世界里产生后果？

规则允许强，不允许随剧情需要忽然变。若能力真的能无限供应某物，就接受“该物不再稀缺”，把后续冲突转向分配、运输、用途、选择或别的领域；不要假装所有人仍按旧稀缺规则生活。

## 3. 无敌主角的十种非削弱看点
- **方法悬念**：不是能否赢，而是会用什么意外却已被支持的方法赢。
- **出手尺度**：解决问题后主角想保留什么？例如不破坏家园、不抢走同伴的成长。
- **信息定位**：实力足够，问题是找到真正原因；不能故意藏掉已知信息拖戏。
- **价值选择**：两个都能做到，但主角如何决定优先顺序与责任？
- **生活反差**：惊天能力用于具体日常愿望，有真实后果而非重复段子。
- **世界回响**：胜利改变组织决策、资源路径与公共想象。
- **他人视角**：读懂主角实力的过程不同，但同一人不能不断失忆。
- **建设目标**：毁掉难事很容易，把新的生活建起来更有层次。
- **关系平等**：尊重不能只靠恐惧，亲近不能靠控制。
- **能力审美**：同一力量的精确、优雅、幽默或规模差异。

用户明确要求“没有敌手、轻松碾压”时，可以取消失败概率，保留发现、期待和选择。不要机械添加绑架家人、失忆、能力冷却、神秘更强者等廉价牵制。

## 4. 升级必须改变玩法
每次显著成长至少改变一项：**能做什么、敢选什么、能影响谁、能进入哪里、能与谁合作、能保护什么**。

示例阶梯是功能，不是固定剧情：
`解决个人问题 → 稳定重复该能力 → 两能力组合 → 帮助团队 → 改变资源路径 → 获得制度话语权 → 让其他人也能做到 → 选择最终秩序`。

竞技可以是技术→战术→读局→带队；经营可以是单次成交→复购→供给稳定→品牌信任→行业规则；关系可以是敢表达→建立边界→互信→共同决定。都不需要等级面板。

### 里程碑卡
`旧能力 / 新能力 / 获得原因 / 当集演示 / 新选择 / 仍有效的旧成果 / 下一阶段目标 / 潜在社会后果`。

奖励最好尽快进入行动，而非长期躺在背包。一次小奖励也可立即带来生活变化；大型奖励可分“获得→试用→组合→外溢”持续开发，而不是领奖后忘掉。

## 5. 系统和游戏不是自动写作器
系统信息只显示改变当前决策所需的内容。优先 1 条目标、1 条关键进度、1 条与选择有关的奖励；数字和名称越多，越要证明观众为何需要知道。

说明可复用规则：经验来自何种行为，是否共享，升级如何体现，稀有性依据，复活/失败后果，装备可转移性，榜单更新频率。未涉及的细节可留待后续，不必首集念说明书。

成就分为首创、速度、极限条件、隐藏路线、集体贡献、规则创新等。不可每集都是“全服第一击杀更大的怪”。公告后的世界要有实际变化：公会调整招募、地图开放、交易变化、对手避战或研究新方法。

系统可有个性，但不能承担所有发现、判断、规划、执行和领奖。给主角至少一个系统没替他选择的关键决定。

## 6. 防止通胀与重置
建立能力与资源账本：资产唯一 ID、获得集、功能、数量/状态、拥有者、首次演示集、已知者。数值不必高精度，只要内部一致。

遇到天花板先试横向应用、精细控制、群体贡献、世界改变，不优先增加“更高九十九重境界”。进入新舞台时，旧成绩至少保留资源、方法、声誉或关系中的实质效用。

反派适应是学习，不是开挂追平。给其合理目标和已有资源，允许他在看到证据后求和、合作、迁移竞争领域或退出；不是所有人都要送死。

## 7. 修仙、重生、外挂的专门审查
修仙：每次境界改变至少对应一种可见能力或社会权限；秘笈要展示用法而不是名字长。
重生/穿越：未来知识的精度、历史变化后的可靠性要一致；不把现代常识说成在任意条件下立即可行。
道具：归属、可转移性、损坏、复制、适用对象与视觉标志一致。
超强体质：应改变修炼方式、战斗方法或世界对其的判断，不只提升倍率。
继承身份：身份带来权限与责任，但不能自动让主角获得所有专业能力。

以上检查目的都是让优势更有辨识度、更耐用，不是把爽点一条条削掉。
