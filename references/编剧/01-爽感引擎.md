# 01｜爽感引擎：写观众得到什么，不只写主角有多强

以下为编辑设计方法，不是经实验证明的观众心理定律。先识别观众希望体验的改变，再选题材和手段；不要依据性别、年龄或职业刻板地假定欲望。

## 1. 可扩展的满足感目录
每个条目都要转化为具体行动与可见后果。目录是起点，不是封闭分类。

| 机制 | 观众体验 | 可见兑现 | 常见失败 |
|---|---|---|---|
| 压倒性能力 | 这件难事在我手里很简单 | 专家失败的方法被主角轻松替代 | 只有旁白报战力 |
| 成长质变 | 我真的进入新阶段 | 从只能自保到能带队，解锁全新选择 | 只有等级数字增加 |
| 独占优势 | 只有我掌握这条路 | 别人争资源，主角改变资源来源 | 优势无所不能且毫无个性 |
| 稀缺获得 | 我拿到了值得珍惜的东西 | 物品立即解决一个此前做不到的问题 | 紫光一闪就再不出现 |
| 超额回报 | 我的行动得到惊喜回报 | 完成救援，同时收获新航路的使用权 | 没行动就连续抽大奖 |
| 能力组合 | 我发现了别人没想到的用法 | 两个早已建立的功能形成新策略 | 临场添加隐藏能力 |
| 信息领先 | 我先看懂了局面 | 提前布置在对手行动时兑现 | 主角无依据地全知 |
| 智力制胜 | 看似死局其实有解 | 先展示线索，再让观众看见推理结果 | 藏掉决定性证据后宣布天才 |
| 规则反用 | 我能让强者的规则反过来服务我 | 按对方公开条款反制其目的 | 新条款直到获胜时才出现 |
| 夺回尊严 | 我不必再接受不公评价 | 证据使决定被撤回、应得署名归还 | 羞辱时间远大于回报 |
| 公正清算 | 作恶者承受与行为有关的后果 | 伪造者被自己的证据链暴露 | 无限虐待代替公平感 |
| 身份揭示 | 别人终于认出真正的我 | 认出身份后决策与关系改变 | 亮身份十次但世界不记得 |
| 权威认可 | 懂行的人承认我的分量 | 专家改变操作、让出主导权、引用成果 | 所有人只说“太强了” |
| 公共里程碑 | 我的成就被共同世界记录 | 有公信力的纪录、公告、榜单改变局势 | 广播没有可信依据 |
| 不可替代 | 局面真的需要我 | 大家按主角的方案行动并承担风险 | 每人沦为只会求救的摆设 |
| 被选择与信任 | 我是值得托付的人 | 对方主动交付秘密、责任或合作权 | 没有关系过程就全员追随 |
| 守护 | 我有能力让重要的人安全 | 门终于关上，饭终于热了，伤者能休息 | 配角永远被绑架以刺激主角 |
| 被守护 | 我不必独自承担所有事 | 同伴在关键处接手而不抹去主角贡献 | 天降救援夺走主角的整场行动 |
| 建设与经营 | 我的劳动持续累积 | 灯从一盏变成一条街，孤店变社区 | 只念收入，不展示变化 |
| 秩序恢复 | 混乱终于可以被控制 | 队列开始流动，交易重新可信 | 把所有异议都写成坏人 |
| 掌控与从容 | 我可以选择节奏 | 别人慌乱时主角完成必要动作 | 故意磨蹭、放任可避免伤害 |
| 自由与拒绝 | 我可以不再参加错误的游戏 | 主角放弃别人梦寐以求但束缚自己的资格 | 嘴上说离开，情节始终围着对方转 |
| 关系对等 | 我不是被赏赐的附属品 | 双方都做有代价的选择、能力互补 | 关系价值只由财富或地位决定 |
| 亲密与被理解 | 有人懂我真正需要什么 | 对方记得一个普通但重要的细节 | 靠强迫、误会、羞辱冒充甜 |
| 和解与修复 | 破碎之处终于能接上 | 道歉伴随补偿、行为与边界改变 | 一句“为你好”抹掉全部伤害 |
| 后悔被看见 | 离开我的人明白失去了什么 | 对方看见新生活，主角不再依赖其认可 | 以折磨第三人证明价值 |
| 技艺展示 | 真正的专业值得欣赏 | 可理解的观察、选择、操作、结果 | 行业术语乱堆、专业人士集体无能 |
| 竞技突破 | 我越过了明确的标尺 | 战术改变带来可读的比分或纪录 | 获胜全靠裁判突然改规则 |
| 集体崛起 | 不只我赢，我们都不再受制 | 配角保留独立贡献、成果可共享 | 主角一人做完所有事 |
| 探索发现 | 世界比我想的更有趣 | 发现改变用途、地图或历史理解 | 每次开门只有更大的门 |
| 喜剧反差 | 事情以意外又合理的方式解决 | 庄严机制被日常愿望触发 | 只有网络口癖和滑稽表情 |
| 反讽清醒 | 我看穿虚假评价标准 | 曾被贬低的标准失去约束力 | 旁白说教而没有行动 |
| 舒适富足 | 我终于拥有安全的日常 | 热水、空房间、一顿无须争抢的饭 | 纯炫富清单没有情绪背景 |
| 审美与创造 | 我做出的东西确实美好 | 作品改变空间与旁人的行为 | 只说“惊艳全场” |
| 传承与超越 | 我接住前人的东西并走得更远 | 旧技法解决新问题，后来者得到路径 | 只有师父夸一句天纵奇才 |
| 身份自主 | 我定义自己而非被标签定义 | 主角主动选择名字、职责、共同体 | 换一个更高贵血统才值得尊重 |

可以新增条目：写明欲望、可见结果、与已有类型的差异、可重复派生的冲突。不要为凑“创新”给相同机制改名字。

## 2. 爽点卡：把抽象愿望变成戏
每个重点回报填写：
- `desire`：观众希望发生什么？
- `baseline`：此前困难、稀缺或不公的具体基准是什么？不一定是羞辱。
- `expectation`：观众现在预期会怎样？
- `protagonist_choice`：主角决定做什么，而不是系统替他做什么？
- `distinct_method`：这一部独有的实现方式是什么？
- `proof`：谁都能看懂的结果是什么？
- `witness`：谁有理由看到并理解？可以无人见证，只给观众看。
- `consequence`：资源、关系、地位、自由或下一步选择发生什么变化？
- `afterglow`：用哪个动作让成果被感受，而不是马上被新危机吞掉？

不能把每张卡写成“被骂→开挂→下跪”。不同需求可用“难题→技艺→尊重”“匮乏→建设→安稳”“犹豫→自主选择→自由”。

## 3. 组合而非叠满
选择一个主体验决定故事方向，辅助体验制造层次。推荐组合只是创作选项：

`成长 + 稀缺获得 + 公共认可`；`无敌 + 守护 + 喜剧反差`；`智斗 + 规则反用 + 自由`；`经营 + 集体成长 + 安心`；`技艺 + 关系对等 + 被理解`。

同一部可在不同阶段转换主次，但不能突然背叛核心承诺。用户明确要爽剧时，不把成长全改成漫长受虐；用户要细腻关系时，也不塞进强制榜单和战力压制。

## 4. 认可链：公告不是终点
可信认可常可沿这条链设计：**基准 → 公开证据 → 懂行者识别 → 制度/群体反馈 → 实际待遇变化 → 主角自己的态度**。

不是每次都写满六步。以三层反应替代三十句惊叹：
1. 普通旁观者：手停下、主动让路、把自己的物件交给主角。
2. 专业者/旧对手：复核、承认某个不可伪造细节、调整策略。
3. 组织/世界：开放权限、撤销限制、改变交易条件、保护或争取人才。

游戏公告要有成就难度、公信力、传播范围和奖励；现实认可可用官方榜单、公开作品、合约、议事席位、专业署名或民众自发行动。不能无理由让整座城同时知情。

## 5. 爽感饱和的修复
重复不是简单减少爽，而是换兑现维度。连续三场都靠压倒战力赢，就尝试在下一场展示其新用法、世界回响或生活变化；连续三场都让人羡慕，就让主角做一次不为观众席而做的决定。

拒绝两种极端：所有收益毫无铺垫地白送；为了“合理”让每次快乐都附带更大痛苦。机会可以幸运，重要的是主角如何使用、观众如何看见、世界如何记住。
