# 02｜原创性引擎：改变因果，不只改变名词

本手册的算子、阈值与测试均为编辑启发式，不是全网原创证明。

## 1. 从愿望到规则
先填一句话：**在一个 ______ 的环境里，一个想要 ______ 的人，能通过 ______ 做到别人做不到的事；这让他/她必须持续面对 ______。**

空格不要求一定有超能力。独特职业、关系位置、信息来源、决策权、技艺和社会规则都能成为故事机制。

区分四个层次：
- 包装变化：改名、换时代、换衣服。只能带来外观差异。
- 局部变化：不同职业或道具带来少量新场景。
- 机制变化：主角做事的方法、收益来源或胜负条件改变。
- 系统变化：机制进一步改变群体行为、资源分配、关系和长期发展路径。

优先争取后三层的实际差异；不能用难懂当作新颖。

## 2. 二十种生成算子
每个候选通常选 1–2 种，不必全部交叉相乘。

| 算子 | 操作 | 原创方向示例，不能照抄成固定题库 |
|---|---|---|
| 奖励对象翻转 | 不是奖励常规胜利，而是奖励另一种可解释成就 | 救回被淘汰方案，获得它未实现的功能 |
| 目标翻转 | 大家争得到，主角争摆脱/归还/关闭 | 地位最高的名额其实承担最重义务 |
| 胜负条件重定义 | 改变“赢”的可见判据 | 大家比摧毁，主角比让系统恢复运转 |
| 权限错位 | 弱小身份拥有关键权限，而非更大火力 | 维修权限能绕过贵族的参观权限 |
| 价值错位 | 被忽略之物在主角方法里成为资源 | 失败样本记录了成功品被隐藏的缺陷 |
| 尺度转换 | 同一规则从物件作用到组织，须有中间演示 | 修复流程先救一台机器，再救供应关系 |
| 因果倒读 | 从后果发现先前选择，而非任意预知 | 物品展示最后一次被信任的场景 |
| 使用方式偏移 | 能力不变，用法跨域 | 复制节奏用来组织施工，不是复制招式 |
| 信息归属变化 | 改变谁知道、谁能验证、谁误解 | 大家知道英雄存在，只有对手知道英雄怕出名 |
| 认可渠道变换 | 不是更大广播，而是不同群体有不同反应 | 行业标准被改写，主角名字没有出现 |
| 关系结构变化 | 合作者不是传统师徒、情侣或主仆关系 | 竞争者彼此持有对方通关所需证据 |
| 公私反差 | 外界目标与私人愿望矛盾 | 传奇人物只想把家门口的路修好 |
| 制度外溢 | 主角胜利改变别人的行为规则 | 一次公开验真使骗子必须改变交易方式 |
| 稀缺来源变化 | 不增加宝物数量，而改变稀缺成因 | 真正稀缺的是维护知识而不是原料 |
| 时间机制变化 | 改时间窗口、顺序或保存方式 | 今天的修复可以保留，身份记录却每日刷新 |
| 空间机制变化 | 路线、边界或距离产生冲突 | 地图按信任而非地理距离连接区域 |
| 代际错位 | 经验、身体、权威不落在常见对应位置 | 学徒掌握失传步骤，老师掌握风险判断 |
| 类型功能融合 | 一个类型的方法解决另一个类型的难题 | 用经营的长期信誉解决冒险的临时联盟 |
| 去除习惯拐杖 | 删除系统、误会、嘲讽或隐藏身份之一 | 无人轻视主角，大家争的是其有限选择 |
| 现实微观察放大 | 把具体日常摩擦变成虚构规则 | 谁来维护公共物品决定一个社区的权力 |

每次变换后问：这会改变首集哪个动作？中段哪个冲突？结局哪个选择？回答不出来，变换仅停留在宣传语。

## 3. 新颖性五个测试
**去名词测试**：把“仙尊、星舰、战神、系统”等换成 A/B/C。事件顺序和获胜方法仍与已有候选相同，至少重做一个核心机制。

**换背景测试**：古代换成未来，所有场景无需实质修改，说明背景没有进入因果。给环境至少一个真实影响行动的特征，不必加一堆设定。

**关掉优势测试**：去掉金手指/身份/技艺后，首集仍完全照常发生，说明设定只是贴纸。让它改变决策或可见结果。

**三场专属戏测试**：设计开局、中段、后期各一个依赖独特机制的场面，不能仅为同一招换更大的敌人。

**十集续航测试**：至少构想 10 个不同问题或应用方向；有限篇幅作品按实际集数缩小。若 3 集后只剩报等级，先修引擎再写长篇。

## 4. 控制“新到看不懂”
入口用熟悉愿望，核心只引入一个关键异常，后果逐渐展开。首集不讲完整宇宙史，只讲理解当前选择所需的信息。

对第一条核心规则给：一句简明描述 + 一次行动演示 + 一个结果。未知来源可以保留；用来决定胜负的关键用法不能完全无迹可寻。

“新奇、清晰、可信、可持续”分别评价，不合成伪科学创新指数。清晰不足时先简化表达，不急于删掉真正有价值的机制。

## 5. 去重是两层工作
工具层：统一标签、记录机制指纹、提醒相似文本。
编辑层：对照主角目标、能力用法、冲突结构、高潮兑现和认可方式。工具未报警也要做编辑层。

同题材可以保留，但两部应至少在三项关键维度有实质差异；这是本包默认筛选标准，可按任务调整。续集、外传和主动变体不应因共享世界而被机械剔除，须标注 `variant_of`。

用户提供喜欢的作品时，只抽象其“回报机制、信息安排、节奏和关系张力”。不得保持整条事件链与辨识度高的名场面，仅替换角色名称。涉及现成 IP 的改编，确认用户提供内容和授权范围；不得把改写称为法律保证。

## 6. 反套路也会变套路
不要每次都写“最弱职业其实最强”“垃圾天赋其实神级”“全世界只有我发现漏洞”。这些是可用的入口，不是创新本身。

批量时明确提出一个挑战：**假设所有人一开始都知道主角很厉害，这部剧还靠什么让人继续看？**再提出另一个：**假设没有任何超能力，这个情绪愿望还可以怎样兑现？**不是强迫两种答案都采用，而是扩大候选空间。
