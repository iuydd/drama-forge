# 06｜单集写作：入口清楚，行动有效，回报落地

这里的时间与比例只是草稿标尺，不能当成平台算法或通用留存规律。以用户篇幅、题材、对白实测和表演节奏为准。

## 1. 首屏承诺
第一幅画面或第一句有效对白尽量同时建立“发生了什么异常”和“为什么值得在意”。不强制车祸、背叛、羞辱或惊叫。

可用：可见难题、反常结果、明确愿望、危险中的从容、重要选择、关系反差、可验证秘密、正在兑现的收益。标题承诺的卖点应在首集出现证据，不能只在结尾说“觉醒了”就结束。

人物姓名、世界全称、历史年表和抽象独白不能占满入口。先让观众看懂行动，再补充必须知道的规则。

## 2. 一个可调的 75 秒草稿样式
| 时间 | 功能 | 注意 |
|---|---|---|
| 0–8 秒 | 异常/目标/关系入口 | 这是选项，不必每次 3 秒爆点 |
| 8–22 秒 | 关键条件与主角选择 | 只解释当前选择需要的信息 |
| 22–47 秒 | 行动、变化、结果证据 | 不是一直铺垫到结尾 |
| 47–65 秒 | 回报与余味 | 成果真的发生、他人有实质反应 |
| 65–75 秒 | 结果生出的下一步 | 独立短片可在此正常结束 |

可把回报放在开场，再追踪它的后果；也可先安静后爆发。不要强迫所有集同一节拍。争吵少而清楚的 40 秒可能比塞满术语的 90 秒更有效，但不预设数据结论。

## 3. 场景最小因果
每场至少改变一种状态：知识、资源、关系、局势、角色决定、观众对事情的理解。只传递设定的场景尽量嵌入行动。

可保留有价值的情绪场景，它的变化可能是“终于敢坐下吃饭”，不一定是新反派出现。删除测试的对象是没有叙事或情感作用的重复段落。

场景卡：`地点 / 人物 / 入口状态 / 想做什么 / 什么阻止 / 如何行动 / 可见结果 / 出口状态`。

## 4. 三类悬念分开写
**结果悬念**：能否完成？必须有已建立条件。
**方法悬念**：知道主角会赢，但他会怎么做？适合无敌、智斗。
**意义悬念**：已经看见结果，它到底意味着什么？适合探索、身份和谜团。

还有关系期待、资源期待、社会认可期待；不必每集都制造死亡危险。

## 5. 反转必须有支点
写反转时记录：此前的合理理解 → 已展示但被忽略的线索 → 新行动/事实 → 新理解 → 新后果。

允许隐藏角色身份，不允许隐藏观众必须看到的决定性步骤之后再宣称“原来早安排了”。重要反转应能回看找到支持；伏笔可用行为、物件、反常制度而不全靠解释。

一集 0 次、1 次或数次反转都可能合适。优先因果清晰，不把“每 5 秒一反转”当任务。

## 6. 首集试写流程
先写三个差异开头，各 2–4 句即可：行动入口、关系入口、规则反差入口。比较清晰度、承诺、独特场面和后续可接性，选一版写完整集。

正文之后检查：主角是否主动做过一个决定？核心卖点是否有可见证据？至少一个回报是否到手？结尾是否引出具体下一步？没有这些，换一个更响的标题通常不能修复。

## 7. 结尾优先顺序
优先“兑现后打开新门”：得到了物品，发现新用途；赢得认可，被邀请处理更特殊的问题；关系终于确认，双方决定共同做一件事。

可在真正的动作峰值切出，但下一集需兑现，不用第三者不停进门打断。避免单纯“他究竟是谁”“好戏才刚刚开始”“然而他不知道”这类可套进任何剧本的空钩子。

终集不受每集追更钩子的默认要求限制。观众有权得到完整的结束。

## 8. 时长估算
先建立场景时间轴，再估对白最低时间和不可重叠的动作时间。中文有效发音字数/估计语速、其他语言词数/估计语速都只能做初筛；数字、英文缩写、停顿和情绪会改变发音时间。

工具默认中文约 4 字/秒、其他语言约 2.5 词/秒，仅用于发现明显超载，不是演员或 TTS 的保证值。可用命令参数调整；有配音实测时，以音频时长替代粗估。

不要把能重叠的动作与对白重复相加，也不要把不可重叠的操作都当成零秒。`non_overlapping_action_seconds` 仅填写额外占用时间；双人抢话仍需标记可理解的重叠关系。时长未实测必须为 `estimated`。

## 9. 预告与付费截点
先有真实作品，再从正文提炼预告。不要为了截点把每集的唯一回报剪掉。用户未要求商业转化时，不默认设计强制付费或成瘾机制。

标题、预告和正文必须同一承诺；“第一集直接无敌”不能变成“第十集才获得能力”。A/B 只改一个主要变量，具体评测见 12。

## 追加｜多轮拉扯的单集兑现

一集可以暂不揭开完整身份，但要让观众拿到具体行动结果、证据确认或关系变化。两次“马上要翻盘”的信号之间，必须有新的因果进展。下一集应早处理上一集钩子，而不是把同一个半句话再念一次。多重反转的完整方法见 15；不要误读成“只能一轮反转”。
