# 长篇连载与续季：人物、记忆、连续性

阶段 A、B 在以下情况另读本文件：计划超过一季或续季；集数明显多于默认 6 集；从长篇小说改编（配合 [adaptation.md](adaptation.md)）；续写已有项目的下一集或下一季；做到中段人物和伏笔开始失去连续性。它补 [story-engine.md](story-engine.md) 没展开的纵向部分：人物怎么在几十集里变、观众和剧中人各自记住了什么、一季结束后怎么接下一季。市场侧的"哪些金手指能续、续季怎么切"以 [market-hits.md](market-hits.md) §3、§4.3、§4.7、§5 为准，本文只把它落成写作动作。

本文的规则全部服从 drama-forge 硬约束：开场服从故事（`opening_mode: story_driven`）、成片按时间顺序、每集都要有可核对的兑现（story-engine §5 爽点间隔门）、生成画面不出字。

## 0. 一句话原则

长篇不崩靠三样东西同时成立：人物的选择一直能从他此刻掌握的事实和压力里解释；每集都留下一个不会被复位的状态变化；系列有一个具体到可核对的去处（story-engine §2 终止条件），每一季都在朝它推进一格。三样缺一样，集数越多内容越薄。

## 1. 前史储备与切入时刻

第一集第一拍之前，人物已经形成习惯，关系已经欠下债，世界规则已经在人身上留下后果。作者要知道这些，观众不必先听完人物小传。

### 1.1 前史储备

只储备能解释现在选择的过去：哪件旧事让人物开始依赖现在的策略；哪个承诺、羞耻、损失或受益关系仍在约束他；哪件旧事让两个人对同一行为有不同解释；世界规则在他身上留下了什么可见后果；哪个过去形成的盲区会在当前压力下制造代价。

每一条标一个去向：`作者需要`（只供预测选择，不上屏）、`观众现在要知道`（本场行动离不开它）、`暂时保留`（等它能改变某个选择时再释放）。写在系列简报"人物"一节下的前史表里（格式见 §5 模板）。

前史的释放服从 drama-forge 的顺叙规则：在当下用一个动作、一件物件、一句台词或一行后期字幕让观众反推"之前发生过什么"（磨损的旧工牌、她下意识遮住日志的手），不插回忆镜头。确实需要闪回，按 SKILL.md 6b 标清时间、视角和信息来源，并且在视觉设定里算进额外的旧场景和旧造型成本。

### 1.2 切入时刻

比较几个可能的开场时刻，选满足下面几条最多的一个：

1. 压力已经启动，人物必须马上行动；
2. 人物的惯常策略眼下仍然有效，却即将显出代价；
3. 观众能从一个行为、物件、关系动作或异常结果反推前因；
4. 本集能先完成一个局部行动，而不是只负责介绍世界；
5. 切得更早会变成准备工作，切得更晚会丢掉关键选择。

这是 story-driven 开场的具体做法：旧办法开始付出代价的那一刻就是入口。它还要同时过 premise-novelty §7 B1（前 3 秒不靠字幕就看得懂的冲突画面）和 screenplay §2 的冷开场与单集秒表；三者冲突时以用户指定的 `opening_mode` 和硬约束为准。

合成例：夜班调度员长期私改末班车日志替临时司机掩盖迟到（前史：她曾因如实上报害搭档被解雇，这条"作者需要"，不在开场讲）。开场她正把最后一处时间改平，打印机吐出一张系统里不存在的到站单：旧策略还在执行，代价已经进了同一个画面。

## 2. 人物驱动力与关系相撞

主要人物在 story-engine §7 行动模型之外，按下表记"驱动力"，用来回答"压力变了他会怎么做"：

| 层 | 问题 |
|---|---|
| 意识到的追求 | 他现在明确想改变什么 |
| 被保护的价值 | 即使追求失败，他也不愿失去谁、什么身份、哪种自我看法 |
| 被捍卫的信念 | 他用哪句偏颇但有来历的判断解释世界和自己 |
| 前史成因 | 哪件旧事让这套信念和策略曾经合理 |
| 惯常策略 | 控制、讨好、试探、隐藏、交易、公开还是撤退 |
| 即时代价 | 这套策略正在伤害什么 |
| 改变条件 | 哪个事实、关系后果或自主选择可能让旧策略失效 |

"内在需要"不必等于道德正确：有人要学会信任，有人要承认自己想要权力，有人最终拒绝改变。要求只有一条：行动、后果和选择能互相解释。

同一场戏里的双方各写三句，把"关系紧张"改写成当下能演的压力：

```text
A 想让 B 现在做什么 / A 不愿让 B 看见什么 / A 用什么策略和筹码
B 想让 A 现在做什么 / B 不愿让 A 拿走什么 / B 用什么反制和筹码
```

长篇里配角的份量会涨。market-hits §6 的检查清单要求至少 3 个能单独产出冲突或笑点的配角：给他们也写驱动力前三层，否则他们到中段只能递线索。

## 3. 人物弧线：可追踪的压力测试

人物弧线不是每集加一个"成长点"，也不是性格标签从负面换成正面。每次真正碰到旧策略的事件记一行：

```text
进入策略 → 压力测试 → 仍按旧信念行动 / 试新办法 / 退回旧办法 → 局部结果 → 付出的代价 → 下一次更难的测试
```

六种结果都成立：**确认**（旧策略又奏效，他更信它）、**裂缝**（成功了但代价第一次无法忽视）、**试探**（短暂用新办法但留了退路）、**回撤**（新办法失败，加倍依赖旧办法）、**不可逆选择**（主动承担代价，旧身份或关系回不去了）、**拒绝变化**（看见了别的路仍不走，走向悲剧或反弧线）。

声称人物变了，审查时必须指得出：哪次压力测试、他做了什么选择、得到什么结果、付了什么代价、之后可见的做法有什么不同。只有台词说"我变了"或者情绪更强烈，不算弧线移动。

弧线只在系列简报的"人物跨集进展"表里记一次（§5 模板），不在每集集纲里重写；集纲只写本集的局部结果和它造成的出去压力。不要求每集都移动人物弧线：没移动的集，写清本集是在积累证据、加强信念、推进外部目标，还是让配角承担变化。

爽剧的主角弧线常常很平（一直强、一直对），这正是 story-engine §7 说的"人物一直正确，观众没东西可替他争取"。长篇里至少给主角一次"裂缝"和一次"不可逆选择"，给主反派一次"回撤"。[推断]

## 4. 每集的局部结果与双轨节奏

### 4.1 局部结果

连续剧可以从上一集最后一秒接起，也可以切在最危险的动作中间，但新一集不能只把同一个动作拖到下一个切点。每集至少完成一个能辨认的小戏剧动作：当前目标 → 有能力的阻碍 → 人物选择 → 局部结果 → 状态或代价改变 → 从结果里长出的下一股压力。局部结果不等于主角赢：目标部分达成但暴露了新弱点、失败了却拿到改变下一步的证据、他以为赢了而观众看见代价已经启动、主动放弃原目标、对手成功封路迫使他换策略，都算。结果要追溯到焦点人物的一次选择（story-engine §5）。

集尾可以停在即将发生的动作，但悬念要由本集结果造成。"门外有人"只是新刺激；"她为藏证据反锁了门，门外的人却拿着她刚交出去的钥匙"才接住了本集的选择。

### 4.2 双轨节奏

长篇的张弛用两条轨分别记：**外部压力**（事件密度、对抗强度、时限、空间风险）和**情感负荷**（人物正在处理的损失、羞耻、希望、亲密、恐惧或道德冲突）。

| 外部 / 情感 | 用途 |
|---|---|
| 高 / 高 | 爆发与不可逆选择 |
| 高 / 低 | 熟练执行、冷静追击、程序性危机 |
| 低 / 高 | 等待、照料、隐瞒之后的余震 |
| 低 / 低 | 必要交接，控制篇幅，保留潜在压力 |

集纲附注里写本集两轨落点，并说明和上一集相比为什么升、降或错位。不为画出波浪机械交替；节奏变化来自人物处理后果所需的时间。

drama-forge 默认按 IAA 写，所以"低 / 低"只能是集内的一两场，不能是整集，本集照样要有 story-engine §5 要求的小兑现；呼吸段也不是无事发生：人物在重新解释刚才的事、修补关系、隐藏代价、处理伤势或证据、做下一步决定。成片节奏下限（storyboard-keyframes §7c）对呼吸段同样有效。

跨集的宏观阈值（连续交代集、大兑现间隔、至暗低谷长度、终极对决与收束集数）每写完 5 集回看一次，清单在 review-checklists §S 第 8 条。

## 5. 跨集记忆：只存后续决策要用的

长篇最常见的崩法是摘要越写越长，却漏掉谁知道真相、谁拿着证据、哪笔铺垫没回。跨集记忆只存后续决策要用的东西，模板见 `assets/templates/跨集记忆.md`（超过 12 集或有续季的项目在 `项目开发/` 下建一份；6 集的单季项目用系列简报加各集剧本的 `[连续性]` 段就够）。

每集定稿（剧本通过 reviewer）后只更新变化的部分，并改文件头的「最后更新」到这一集；它落后于已定稿的集时，先补齐再写下一集：

1. **人物**：当前目标、策略、正在被测试的信念、最近一次选择与代价、身体状态；
2. **关系**：权力位置、信任与债、没说出口的交易、最近一次越线；
3. **信息权限**：世界事实、各角色与观众知道 / 误信 / 不知道的差异（story-engine §8 的表，含证据结论边界）；
4. **铺垫台账**：已埋未回、已改义、计划回扣、受影响位置（story-engine §8）；
5. **节奏落点**：上一集两轨落点，下一集要承接还是对比；
6. **装置披露进度**：条款 ID 已披露到哪条、谁知道到哪一步、有没有被误述；
7. **精确交接**：位置、动作、持物、伤势、服装、时间、正在进行的决定或危险（= 上一集剧本 `[连续性]` 段，screenplay §8）。

更新原则：
- 只写变化；没变但下一集必须继承的事实进"精确交接"。
- 已完结、不再影响后面的事压成一句，或移出活跃记忆。
- 伏笔、信息权限和没付的代价，不许因为摘要压缩而丢。
- 开写新一集前先读活跃记忆，再读最近一集剧本核对证据。
- 记忆和剧本冲突时，剧本事实胜出，改记忆。

**绝不能无原因重置的事实**列在 `assets/templates/跨集记忆.md` §8 那张短清单里（伤势、失去的东西、公开过的秘密、断掉的关系、已披露的装置条款）；没建跨集记忆的 6 集单季项目，在系列简报末尾加一节同名短清单。任何一集要让它们回到原状，必须有剧中原因，并先改这张清单（涉及装置条款的同时改系列简报的条款表）。视觉侧的跨集状态（造型、道具版本、伤妆）由视觉设定和 refs.json 负责（visual-assets），本节只管故事状态。

## 6. 多季与续季规划

### 6.1 立项时就按季想

market-hits §4.7：AI 漫剧长青的核心是高频续季，立项就按"每季一个境界或一张地图"切，不按单部剧想。drama-forge 默认 6 集一批是生产批次，不等于一季；续季项目填系列简报模板（`assets/templates/系列简报.md`）"分集走向"下面的 `## 季规划` 节，每季一行，写：

| 季 | 这一季的大循环（机制 + 观众期待的回报） | 境界 / 地图 | 主要对手（反派阵营） | 机制的新限制 | 季末大兑现 | 季末推进的明线 / 暗线各一格 | 续季钩子（交给下一季的赌注） |
|---|---|---|---|---|---|---|---|

"机制的新限制"指这一季金手指多出来的边界或代价（§6.2、story-engine §9 耗尽与换代），没有新限制的季容易变成上一季的重播。先写到第 3 季的一行，后面的季只写方向。一季就是 story-engine §9 的一个大循环：季内小循环在运行，季本身也要有自己的去处和耗尽点。

### 6.2 金手指能不能续

先按 market-hits §3 标长青度。能续的判据只有一条：同一条规则下，每季都能拿到更大的东西。昙花型（隐藏大佬亮身份、一次性爆发）要么按单部规划不承诺续季，要么补一条可升级的进度条：每季揭一层身份，而且每次揭的方式不同（market-hits §4.7 提到相认情节被批复制粘贴）。

### 6.3 长篇不崩三要素落成写作动作

market-hits §4.3 的三要素（世界观能一季一季扩、至少一条跨季情感线或因果线、升级线可以外包）在写作上对应：

- **世界观扩一格**：每季新地图的规则先在上一季末以次要身份出现一次（story-engine §9"把下一个循环埋在这一个里"），新季开头不从零讲设定，D2"规则一场只讲一个"照样有效。
- **跨季线**：在铺垫台账里单独标 `跨季`，写清它预计在哪一季回扣；每季至少让它露一次面，不让观众忘了。
- **升级线外包**：主角封顶后由弟子、族群或搭档承担升级，主角保留"明线升级 + 暗线身世"两条线；外包对象要有自己的驱动力（§2），不能只是替身。

### 6.4 季与季之间的换代

一季收尾就是一次大循环的处置（story-engine §9 三种：收束、改造、移交；不许并接）。新季要接管上一季的紧迫性：可感的时限或到期代价、主角不能退出的理由、观众已经押上的具体的人或物。检查问题："如果主角这一季什么都不做，会怎样？"答案要比上一季更具体、更糟。

打脸对象沿 market-hits §4.2 的梯子升（身边人 → 本地势力 → 宗门官府 → 更高位面），每升一级换地图、换反派阵营；最高层用虚构神系，不碰真实宗教。反派阵营换了，对手卡（story-engine §3）要重写，包括节制理由和"学到了什么"。

### 6.4b 跨集阶段的镜头语言职责

长篇按人物选择、关系或信息权限的实际门槛分阶段（不按固定集数切块），每个阶段在分集卡或导演意图里写一句"镜头语言职责"，例如"规则建立期多用客观中景讲清谁在哪、规则怎么生效；代价累积期多用主观近景和反应镜承接代价"。手持、平行蒙太奇、升格、首尾呼应只有在承担某个剧情节点的注意、时间或关系职责时才用，不先拿标签填满一段集数。这些只是镜头取舍的方向，节奏下限（storyboard-keyframes §7c、G42）、台词镜听者入画（storyboard-keyframes §1）和同一人连续戏合并成长镜头（storyboard-keyframes §7b、G45）照常生效，不因阶段而放宽。

### 6.5 续季首集

续季首集同时服务两批人：追完上一季的老观众和刷到这一季的新观众。[推断]
- 老观众：开头接住上一季的季末钩子，不用虚假悬念化解它（screenplay §8b）。
- 新观众：靠当下的行动和一两句台词就能看懂主角是谁、凭什么、正在受什么气；不用旁白回顾上一季，不插上季片段回放。
- 第一次兑现照样不晚于前半段（premise-novelty §7 B2）。
- 每季开头重新校准角色参考图和风格句，保证跨季形象一致（market-hits §4.7；视觉侧按 visual-assets 和 styles.md 执行，`style_preset` 全系列不换）。

## 7. 续写下一集 / 下一季的流程

1. 读 `项目开发/决策记录.md`、系列简报（装置条款、铺垫台账、不能重置清单、季规划）、跨集记忆（有的话）、上一集剧本的 `[连续性]`。这是 story-engine §10 的三回锚。
2. 核对上一集出去状态和本集进入状态逐项对得上：知识、权力、关系、物理（位置、伤势、服装、持物、时间）、进行中的动作。显式不一致时先改归属或补剧中原因，不静默忽略；字段不冲突但知识、关系、伤势无原因跳变的，同样按缺陷处理。
3. 写集纲那一行，再按 screenplay 写剧本；集尾与下集开头成对写（screenplay §8b）。
4. 剧本通过 reviewer 后更新跨集记忆和铺垫台账。
5. 做到第 3 集以后，按 story-engine §9 的耗尽症状检查一次当前循环；出现两项以上就在下一集处置。

## 8. 完整分集卡（可选）

情绪集纲一集一行够用。长篇或改编项目需要更细的交接时，可以在集纲下方给关键集（首集、季末、换代集、门槛集）加一张分集卡；只写本集独有的事实（story-engine §5）：

| 字段 | 写什么 | 对应集纲格 |
|---|---|---|
| 进入状态 | 知识、权力、关系、物理、进行中的动作；只写影响本集行动的 | 上一集交接事实 |
| 当前压力 / 钩子 | 观众立刻能懂的未稳定局面，要连着本集目标 | 受什么气 |
| 目标与反对 | 谁想在本集结束前让什么改变；反对者的目标和筹码（写成做过或将做的事） | 受什么气、主角行动 |
| 转折 | 一个具体可见动作，谁做了什么 | 主角行动 |
| 局部结果 | 成 / 败 / 转向、状态变化、付出的代价 | 反派失去什么、兑现什么 |
| 信息释放 | 事实 ID、观众之前、可见载体、直接证明什么、仍未证明、观众之后 | 底牌与谁先知道 |
| 装置披露 | 已披露条款、本集新披露、谁知道到哪、有无误述 | 底牌与谁先知道 |
| 出去压力 | 已经开始的决定、危险或问题 | 留下什么新问题 |
| 交接 | 同进入状态五项 | 交接事实 |
| 铺垫 / 兑现引用 | 铺垫 ID | — |
| 未决项 | 还没定的 | — |

## 9. 审查问题与失败征兆

长篇与续季项目的 reviewer 必答问题在 review-checklists §S（7 问，引用系列简报、集纲、跨集记忆和剧本回答），与 §A–C 一起审。

失败征兆：人物小传整段塞进首集台词或旁白；开场从世界起源讲起，人物还没有必须完成的动作；弧线只写"从自私到无私"，没有压力测试和代价；为了每集有反转，人物没有证据地反复改立场；集尾停在动作半途而整集没有结果；跨集摘要很长却漏了谁知道真相、谁拿着证据；道具只证明了时间地点却被摘要升级成证明了作案者；续季开头重讲一遍设定；每季同一种"受辱 → 亮能力 → 众人震惊"；季与季之间反派只是"更大的富二代"。
