## 1. 格式

只维护一份 `EPxxx/剧本.md`：

```markdown
# EP001 集名

## EP001-SC001 内 · 地点 · 时间/天气

动作段落，现在时，一个段落一个行动单位。

角色（可选表演提示）：台词
角色：台词

[SFX] 会改变注意或信息的关键声音
[画面文字] 观众必须读清的文字（后期叠加）
[OS] 画外同场人物的台词    [VO] 主观/叙述声音
[转场] 有叙事意义的转场
[连续性] 由前文动作建立、容易在下游丢失、影响故事的状态；只交接状态，不证明"从未发生"

## EP001-SC002 外 · 地点 · 时间 · 连续
```

规则：
- 场次 ID 是下游分镜、关键帧、视频任务的主键；场内地点或时间一变就新开场次，标头要和场内动作一致（pound 验证里唯一有据可查的改善点，也是它暴露的问题：有标头不等于标头对）。
- 对白行 `角色：台词`；含冒号的动作叙述不要写成对白行。表演提示写可执行策略（"把威胁说成提醒""第一次直呼名字"），再用 `｜` 接一个情绪标签 `情绪·强度·语速·音量`（§4b），例 `鬼塚（拦路要钱｜威胁·中·慢·小）：売上、渡せよ。`；不堆形容词。
- 台词语言按 `drama.json` 的 `dialogue_lang`；创作说明中文。日语台词的金额写万円/円。
- 不写景别、机位、运镜、提示词；空间事实（谁挡出口、谁能看见文字）要写，画面方案由分镜决定。
- **动作行不以"短语＋冒号"开头**：`第二格：一只手把杯子推过去。`、`他写下两个字：军宣。` 在字面上和 `角色：台词` 一模一样，解析器会把它当成对白（说话人"第二格"），进而误报 G11 覆盖、G37 句长，还会让 G10 对照失真。行首冒号改成破折号、逗号或动词：`第二格换成一只手把杯子推过去。` `他写下两个字——军宣。`；句中的冒号不受影响。
- **剧本里不写 HTML 注释**：`<!-- 待确认：…… -->` 含冒号时同样被读成对白。备注、待确认事项、备选实现写进 `项目开发/决策记录.md`；生产关键事实不能只藏在备注里。
- **表演提示只写能和这句台词同时完成的东西**（语气、策略、情绪标签、读音）。独立动作、接触道具、产生新状态的内容拆成单独的动作行——提示里的动作不会进入分镜的动作序列，下游会漏拍。
- **群演概括写**：只承担人数、声势、阻挡的人写"村民甲/乙""围观的学生们"，不点名。点了名的人物在下游就要建身份图、配音色、守连续性；群演一旦有台词、被追踪或以后回归，就从概括里提出来单独建人物。
- 支持的标签只有上面六种，`[VO]` / `[OS]` 必须写成 `[OS] 角色：台词`，全角冒号。各标签的边界：

| 标签 | 用来 | 不用来 |
|---|---|---|
| `[VO]` | 不在现场的主观或叙述声音 | 代替本该可见的行动 |
| `[OS]` | 同场画外人物的台词 | 省掉说话人是谁 |
| `[SFX]` | 改变注意、行动或信息的声音 | 罗列全部环境声 |
| `[画面文字]` | 观众必须读清的载体和精确内容（后期叠加） | 复述一般道具说明 |
| `[连续性]` | 易丢且影响后续的状态变化 | 贴人物设定，或断言镜头外"从未发生" |
| `[转场]` | 有叙事意义的转场 | 写剪辑方案 |

- 剧本里不出现：人物/场景/道具的完整资产说明、镜头表、景别与运镜、图片/视频提示词、模型与任务字段、审查结论、原始素材路径。它们归视觉设定、shots.json、审查文件，通过场次 ID 和短引文引用剧本。
- 格式由 `scripts/screenplay_lint.py <项目> <EP>` 机械检查（场次标头三槽、重复场次 ID、未知标签、半角冒号、注释、行首冒号歧义、缺情绪标签、镜头术语混入）；它只证明"没写错格式"，不证明戏好。

## 1b. 现成剧本的规范化入口

用户或上游交来的现成剧本（别的格式、PDF 粘贴、行业制作稿）要进入本流程时，目标是建立可对照的入口，不是重写：

1. 原文按字节存进 `项目开发/原稿/<EP>-原稿.<ext>`，记下编码和来源；以后任何争议以原稿为准。
2. 按槽位识别，不假定存在行业标准：场景头（场次号、内外、地点、时段，三槽顺序不固定，可能缺槽）、人物行、动作行（`△`/`▲`/`◆` 或无符号段落）、台词行（`角色：台词`、`角色（情绪）：台词`、`角色：（情绪）台词`、`【角色】：台词`）、独白标记（`OS`/`VO`/`（画外音）`/`（内心）`，大小写和括号都要吃；剥掉后能对上本场人物的是同一角色的画外通道，不是新角色）、`【特写】【音效】【字幕】【闪回】` 一类方言指令。缺的槽空着，**不按上下文补时段**——补出来的时段会直接变成整场的布光依据。
3. 只做最小映射：改成 `## EPxxx-SCxxx 内/外 · 地点 · 时段`、`角色（提示）：台词`、六种标签；`【音效】`→`[SFX]`，`【字幕】` 里观众必须读的→`[画面文字]`，人名地名条→后期字幕叠加说明（写决策记录），`【特写】【空镜】` 这类镜头指令删掉并在决策记录里交给分镜。**台词逐字保留**。
4. 原稿的闪回、闪入按 drama-forge 的顺叙规则处理（硬约束 6b）：默认改成当前时空里的物证、台词交代；确需保留的，单独成场并标清时间、视角和信息来源。改动记决策记录。
5. 把"语义变化"单独列表写进决策记录：新增、删除、改写、改了说话人、改了先后、改了因果或态度的句子，以及没映射上的段落。**"只整理格式"却改变了说话人、先后、事实、因果或语气，都算语义改写**，要列出来。
6. 自动模式不等人确认：规范化稿直接写入 `EPxxx/剧本.md`，语义变化表写进 `项目开发/决策记录.md`，由 reviewer 在阶段 C 按原稿核对（review-checklists §C）。规范化不需要补系列简报或新增节拍，不能为填字段补造剧情。

反模式（原稿常见，规范化时顺手修，记决策记录）：小说原文直贴（"他笑得合不拢嘴"类不可拍心理叙述，改成可见行动或删）；PDF 粘贴的断行和全角空格（"灰 雾 降 临"）；场景头、人物行、动作挤成一段；只有"镜头/画面/台词"栏目的空骨架；逐拍编号重号或漏号。

## 2. 从集纲到场景

先锁定不可丢失的事实：进入时人物知道/误信什么；当集目标和阻挡者；集纲那一行的六件事；结尾要交给下一集的知识、关系、物理、行动状态；必须可读的文字、画外声音、关键音效。

一个场景值得存在，是因为它完成至少一项不可替代的工作：目标遭遇有筹码的反对；证据被获取、验证、争夺或毁坏；关系通过行动改变；人物作出带代价的选择；先前后果抵达并封住旧路径。只把卡片内容说一遍的场景，并进真正会转向的场景。

排序前问：人物是否已获得本场要用的知识、道具、权限；对调两场因果会不会毫无损失；退出状态能否成为下一场的进入状态。

单集七功能（su）作为骨架，不是配额：开场扰动 → 即时目标 → 阻碍与行动回合 → 选择与代价 → 局部兑现 → 状态变化 → 前向问题。局部兑现先于前向问题；不把观众应得的信息拖到"下一集再说"。

**冷开场认领**（shuohao hook-open）：钩子不是标签，是第一拍，在运动中给。每集前 3 拍内必须出现可见冲突、异常信息或明确利益危机；主体在动，静物特写留到第二落点。成片严格按时间顺序，钩子只能靠剧本自己在前 3 拍立住。

**单集秒表**（`craft_default`；以 120 秒为例，其他 `target_seconds` 等比缩放；按 §6 估时把剧本切段核对）：

| 时间 | 必须落地 | 自查问法 |
|---|---|---|
| 0–3 秒 | 关掉声音也读得出的冲突或异常；第一句 1 秒内开口（G05） | 只看第一镜，说得出谁在压谁、什么不对吗？ [官方][社区] |
| ≤10 秒 | 本集核心矛盾、在场两人的关系、主角此刻想要什么 | 三件事说得出吗？说不出就砍铺垫，不补旁白 [社区] |
| ≤30 秒 | 第一次小兑现或小反转（一句回击、一件证据、对手一次失手） | 这 30 秒里对手有没有失去一点东西？ [官方][社区] |
| 之后每 20–30 秒 | 一个情绪节点：新信息、新动作冲突或一次押注 | 有没有一段只是在走路、寒暄、复述？ [社区] |
| 约 60%（120 秒集约第 70 秒） | 主角**主动**做出转折动作 | 是他做了什么，还是事情落到他身上？ [社区] |
| 最后 5–10 秒 | 集尾钩子，切在问题上，不切在答案上 | 最后一帧观众在问什么？答案有没有提前漏出去？ [社区] |

只有明确选择 `opening_mode: power_acquisition` 才参考“遇险—能力生效”的开场；不为满足秒表虚构能力。上表是 `commercial_fast` 的节奏参考，非所有题材的硬门；闪回须有清楚的时间与信息标记。

## 2b. 每场的必拍事实

每场写完先列 3–5 条**必拍事实**（短场可以少，但每场至少一条）：去掉台词、只看画面也必须读到的剧情事实，分镜照抄成 `shots.json` 的 `scenes[].must_show`（storyboard-keyframes §2e）。只收五类：

- **数量**：排除法、清点、倒计时依赖的数字和排布，写死在动作行里——`箱子打开：上排五件、下排五件，正好十件。`台词说"十件"，动作行也写十件，两处数字一致。
- **谁做了什么**：因果的经过那一拍，写成可表演的动作——`他笑容停住，双手按住箱盖，慢慢合上，把箱子推回来。`不写"他认输了"。
- **状态**：结果那一拍变成了什么——剑断在地上、袖口破开、支票撕成两半。
- **反派具体损失**：集纲"反派失去"格落到可看的东西上（钱、证据、位置、手下、名声的当场确认），不写"他颜面尽失"。
- **身份**：谁进来了、谁在场，会被认错的写清外观差异。

写法：在该场 `[连续性]` 末尾加一句「必拍：①… ②… ③…」，每条一句、可数可看。写不出必拍事实的场，通常是只在交换信息、局面没变（§3），先改场景。必拍事实写进剧本就不可妥协：后面拍不出来只能重拍、改分镜或回来改这一条，不能靠台词解释放过（production-and-review §5c）。

## 3. 场景发动机

由争取或对抗组织的场景，写正文前在脑子里过一遍工作卡（不落盘）：

```text
场景必要性：删掉后损失哪项选择/证据/关系变化？
进入状态：人物带着什么事实、行动和压力进来？
焦点人物目标：他想让谁在本场作出什么改变？（可执行：在门关闭前拿到钥匙；迫使合伙人签字或公开反对）
反对议程：另一方要什么，用什么筹码阻止？（重新定义问题、交换条件、拿走资源、质疑证据、让公开代价高于私下妥协、与第三人结盟、表面答应但改执行条件）
策略变化：受阻后怎样改策？
方向性转向：哪项事实、权力或决定使原计划失效？转向前人物准备做什么，转向后为什么不能照做？
退出状态：谁取得/失去什么，下一场为何现在必须发生？
```

转折因果句测试（su）：**因为人物掌握了某项信息或承受了某种压力，所以主动采取某项行动；行动造成具体后果，并迫使自己或他人做出下一次选择。**写不出这句话的转折，通常靠作者强推、巧合或降智。

对手停止反应不等于转向；"他没再说话"要以前一动作已迫使他付出具体代价为前提。

氛围、仪式、过渡、消化后果的场不必硬造对手来套工作卡，但仍要让知识、关系、压力或节奏进入下一阶段；删掉后这些都不损失，才是场景必要性问题。场域选人物必须动手做事、空间会限制策略、物件能当筹码的地方，不默认"坐下来聊"。

**反应要承担后果**：值得写的反应至少完成一项——证明话击中了对方、暴露对方早就知道、改变下一步策略、转移现场权力或注意、造成一项连续性事实。重大信息或关系动作之后给受影响的人一个有后果的反应；普通来回不必每句配动作。商业爽剧里主角亮出底牌或证据后，让权力、关系或信息被改变的人当场有可见反应（一个代表性反应或全场状态变化都行），不按群演台词数量制造热闹。

## 3b. 人多的场、主角不在场的场、配角与对手的分量

**人多的场先解决"谁是谁"**。竖屏快节奏观众不回看，认错一次就一路错。按代价从低到高四种办法，可组合：
1. 减人：和本场议程无关的人不出现；
2. 陆续进场：先让一组起冲突，冲突到位下一组才进来，每次进场都是介绍也是加压；
3. 轮换主对手：人必须同时在场时把一场切成前后段，每段只让一个人真正和焦点人物交手，其余人退成反应；
4. 明确递交：切换注意力前，当前说话人先点名或看向下一个人，再把戏交过去。
不靠动作段落逐一点名在场的人。群体围攻、闹剧这类以"乱"为效果的场可以例外，但至少留一条观众跟得住的线。一镜一人的生产约束下，人多的场本来就要拆成很多单人镜，辨识问题会被放大，更要先减人。

**主角不在场的场**：可以整场不给主角，前提是情绪、推进和期待仍挂在主角身上——反派上钩（看的是主角上一场埋的一手）、旁人震惊（震惊的是主角做过的事）、主角将面对的威胁被具体化、主角刚造成的后果落地。删掉后主角处境和观众期待都不变的场，是在替配角讲他自己的故事，短剧篇幅里通常是失血。

**承担主要戏剧功能的配角要有自己的策略**：开场提供核心筹码、提出主要反对或承担选择代价的人物，转折之后仍要有一次相称的行动或反应，不能在主角动手后变成可以被拖走、略过的道具。**对手的筹码不会因为主角完成一个动作就自动归零**：对手此后确实无法继续阻拦，要用前面已建立的空间、力量、权限、公开关系或他自己的选择说清它怎样失效。事务性角色（问路、交易、播报、见证）保持简洁，不为检查表硬加秘密、反转或人物弧。

## 4. 台词：多、快、有用途

以下“多、快、短”仅适用于用户选择 `craft_profile: commercial_fast` 或明确写入项目的口味。general 模式允许沉默、停顿和较长完整句，不用密度代替戏剧作用。

- **多**：人物镜默认每镜一句台词；约每 1–2 个镜头一句对白；被抢、被打、被戳穿当场出声，不"僵住""怔住"。台词秒数占比有下限（写 `drama.json` 的 `dialogue_ratio_min`，默认 0.35）。
- **快**：第一句在 1 秒内开口（G05）；重要信息之后的反应即时入画，不留空拍；同一人连说不超过 3 句，中间要有对方的反应或一个动作。
- **短**：中文单句不超过约 15 字，日语约 20 字（假名加汉字），英语约 10 词；超了就拆成两句，中间插对方的反应或一个动作。一句只说一个意思，不在一句里堆两条理由。同一人连着说的两句放进同一个长镜头（分镜按容量加秒数，上限 `shot_seconds.max`），不为了"一镜一句"拆成两个同人镜头（storyboard-keyframes §7b）；换人说才切到反打。口型镜的单句越长，越容易口型对不上、说不完或 ASR 不过。"短"是为了"多"和"快"服务：句子变短、句数变多，不是少说话。[官方][社区][自测]
- **有用途**：每句先标它在做什么——羞辱、威胁、试探、反击、揭底、押注、兑现、要求、交换、遮掩、划界、验证。"我要让你付出代价"太空；"这份字，你敢签吗？"把冲突落到眼前的动作。
- 商业短剧可以直白、夸张，但每个人不能只会大喊和放狠话：反派要会押注、改口、找替罪的人；主角的反击要接着观众已经看见的底牌说。
- 台词是行动：同一事实"门九点锁"可以是催促、推责、试探、威胁、保护。策略受阻后要换策略、付代价或退出；重复同一句要求只会延长时长。
- 说明量由现场认知决定：人物不为观众复述彼此都知道的事；背景通过争夺、验证、交换、指控、纠正、回避、公开进入。
- 潜台词要有推断依据（避开一个词、称呼改变、先答旁枝、台词与证据矛盾）；没有隐瞒理由的场合直说，不硬写潜台词。AI 生成的表演演不稳微表情（EP001 里"慌转冷静"整镜没生成出来），所以**关键认知必须有一句台词或一个可见物件把它说破**，不能只靠"眼神变了"；潜台词只用在有可见载体（物件、称呼变化、动作停顿）的地方。[社区][自测]
- 人物声音靠注意什么、怎样证明、怎样控制距离、怎样隐藏、压力下怎样变形来区分，不靠口头禅。交换说话者后台词仍成立的，补目标和关系风险。
- 停顿要有对象（"他把钥匙拆下来，却没有递过去"），不写"沉默片刻"。
- **心声的边界**：吵架、对峙、反击、揭穿这类正面冲突，必须用出声的台词在对手面前完成，不能用 `[VO]` 心声代替。心声只在四种情况用：和表面行动形成反差（嘴上答应、心里骂）；揭示外部动作表达不了的抉择；题材本身靠主观叙述（读心、系统提示）；喜剧吐槽。心声不复述画面。（取自 screenwriter-skill、su-ai-short-drama）

## 4b. 表演提示：每句台词的情绪、强度、语速、音量

人物说话要像真人一样有情感。配音和视频模型只会照写的去演，剧本不写情绪，出来就是平读（EP001 配音平，被撞的惊叫和平时说话一个腔调）。所以每句台词都带一个情绪标签，四项写全：

```text
情绪·强度·语速·音量
情绪：一个具体的词——惊慌、愤怒、冷笑、轻蔑、委屈、强装镇定、得意、威胁、哀求、震惊、心虚、决绝
强度：弱 / 中 / 强
语速：慢 / 中 / 快
音量：小 / 中 / 大（"大"= 喊出来）
```

| 情境 | 标签 | 为什么 |
|---|---|---|
| 被撞、被抢当场出声 | `惊慌·强·快·大` | 被打的那一下是喊出来的，不是说出来的 |
| 反派憋屈段压人 | `轻蔑·中·慢·小` | 越有把握越慢、越轻 |
| 主角亮底牌 | `冷静·中·慢·中` | 冷静反杀，语速放慢（video-prompts-h3 §5） |
| 被戳穿 | 心虚、愤怒或克制，按人物策略选择 | 变化须有剧情触发，不规定每集情绪种数 |
| 哭诉 | `委屈·强·慢·小` | 强情绪不等于大音量 |

- 情绪变化由目标和事件触发；克制或持续一种情绪可以成立，不为凑标签强制变情绪。
- 标签是配音的指令：分镜阶段逐字抄进 `shots.json` 的 `dialogue[].emotion`（G31 查有没有），配音按它选情绪参考音频或写 TTS instruct（production-and-review §10）。
- 情绪要和动作、表情一致：`惊慌·强·快·大` 的那一镜，画面是身体往后仰、手乱抓，不是站着不动。
- 语言风格按画风调：修仙文白夹杂、动漫配音更夸张、古装语速慢一档（[styles.md](styles.md) 各节"声音与台词腔调"）。

## 4c. 本地化：台词是母语者日常会说的话

用户看完 EP001 的原话是"说话语调，口音很奇怪，台词也不本地"。台词先要像那个国家、那个年纪、那个身份的人当场会说的话，配音和口型才有可能自然；翻译腔和书面腔的句子，母语配音员也念不顺。

**写法**
- **目标语言直接写，不从中文翻**：先想"这个人此刻想对谁做什么"（§4 用途），再用目标语言的口语写出来；创作说明、表演提示用中文，台词本身不经过中文中转。
- **按人物选口吻**：年龄、性别、身份、地域、和对方的上下级关系，决定一人称、称谓、敬语层级、句尾。同一人物全剧口吻一致，写进视觉设定的人物条目（"口吻：一人称俺，对老师用です/ます，对同学全用常体"）。
- **口语特征要有**：省略主语和助词、语气词和终助词、倒装、半截话、口头确认（"だろ""吧""嘛"）；不写完整主谓宾的书面长句。
- **称谓和敬语层级要对**：对上用敬语、对下和同辈用常体；吵起来会降一级（丁寧语掉成常体）；对陌生人不直呼名字。敬语用错一级，母语观众一听就出戏。
- **专名写读音**：人名、地名、店名、易读错的汉字词（日语「売上」「じいちゃん」、中文多音字）写进表演提示括号的最后一项，例 `夏樹（报账｜平静·弱·中·中｜读音 売上=うりあげ）：売上、三万二千円。`（不写在台词后面，否则会被当成台词）；人名、地名这类全剧反复出现的专名，读音写一次进 `drama.json` 的 `readings`（`{"夏樹": "なつき"}`）。分镜把单句读音抄进 `dialogue[].reading`（G44 查日语台词里的专名有没有读音）。
- **不本地的信号**：句子能逐字译回中文且语序不变；每句都有主语；敬语全剧一个层级；语气词一个都没有；年轻人说"非常感谢您"；吵架时句子反而更完整。

**日语正反例**（男高中生夏樹，对同学、对老师）

| 情境 | 翻译腔（不要） | 母语口语（要） | 为什么 |
|---|---|---|---|
| 拒绝同学借钱箱 | 私はそれをあなたに貸すことはできません。 | 無理。これ、先生に届けんだよ。 | 男高中生对同学不用「私」「あなた」、不用です/ます；「届けるんだ」口语缩成「届けんだ」 |
| 发现对方要撞过来 | あなたは今から私にぶつかるつもりですね。 | 次、ぶつかってくんだろ。 | 省略主语，终助词「だろ」表示"我早知道"；「くるんだろ」缩成「くんだろ」 |
| 对老师说明 | 先生、彼は箱を交換しようとしました。 | 先生、こいつ、箱すり替えようとしてたんです。 | 对老师要用です/ます，但指同学用「こいつ」、省略助词「を」，是学生真实会说的 |
| 惊讶 | 私は驚きました。 | え、マジかよ…… | 惊讶不陈述，直接出声 |
| 一人称 | 私 / 僕 全剧混用 | 对同学「俺」，对老师也不换成「私」（最多收敛成「僕」一次作戏剧转折） | 一人称是人物身份，不能随句漂 |

**中文正反例**（都市爽剧，职场与街头）

| 情境 | 翻译腔 / 书面腔（不要） | 地道口语（要） | 为什么 |
|---|---|---|---|
| 反派压人 | 我认为你没有资格参加这个会议。 | 这会你也配来？ | 口语用反问，省主语，短 |
| 主角亮底牌 | 事实上，客户只承认原作者的签名。 | 客户只认原作者签的字。你划的这个，没用。 | 去掉"事实上"这类书面连接词，拆成两句 |
| 惊慌 | 请你不要这样做！ | 别！别碰它！ | 急的时候不用"请……不要" |
| 同辈称呼 | 你好，李先生。 | 老李、李哥（熟）/ 李总（职场） | 称谓跟关系走，"先生"在中文日常里很少用 |
| 语气词 | 好的，我知道了。 | 行，知道了。/ 得嘞。（北京） | 一句话里有一个语气词或口头应答，才像人说的 |

- 方言和地域口吻只在人物设定里写了才用，一个人物只用一种，不在单句里混方言。
- 古装、修仙的文白比例按 [styles.md](styles.md) 各节"声音与台词腔调"，但同样要口语化到"演员念得出来"。

**配音要跟得上**：台词语言写进 `drama.json` 的 `dialogue_lang`，每句 `dialogue[].lang` 等于它（G44）；视频台词标签 `<d>[Japanese]` 要和台词语言一致；配音的语言参数、克隆参考音频的语言与母语，见 production-and-review §10。

## 4d. 对白手艺：议程、反向条件、权力、打断与长发言

**先写议程，再写句子**。一轮对话开写前，给每个主要说话人在脑子里过一遍（不落盘）：此刻想让对方做什么；最怕对方看见或说出什么；手里有什么筹码；哪件事不能公开说、为什么；认为对方想要什么；先用什么策略、失败后换什么；哪条底线受压才会越过。两人可以表面谈同一件事，实际争不同的结果。

**潜台词三层**：字面说了什么 → 想让对方做什么 → 为什么不能直说（会暴露秘密、失去体面、有第三人在场、还没确认对方知道多少、直说显得没筹码）。现场没有外人、秘密或权力差时，这句就是普通指令，不硬写潜台词。

**每种方法都有反向条件**。对白最常见的坏味道不是方法用得少，是用得到处都是；一段读着别扭又说不出错在哪，先查是不是某个方法用在了它失效的地方：

| 方法 | 失效条件 | 失效后读起来 |
|---|---|---|
| 写潜台词 | 人物没理由隐瞒 | 该说的话被作者按住，人物莫名躲闪 |
| 把说明改成有利益的传递 | 这条信息本来就中立 | 硬派立场，观众看得出争的是假的 |
| 打断 | 被打断的那句带着观众以后拿不到的信息 | 信息断供，后面的推断没依据 |
| 停顿与沉默 | 沉默没有可见对象 | 读不出在权衡什么，只读到空档 |
| 借第三人或公共规则施压 | 观众此前不知道这条规则 | 像临时发明的挡箭牌 |
| 先承认一部分 | 观众还不知道有更大的秘密 | 部分被当成全部，揭露时观众觉得被耍 |
| 区分人物声音 | 差异只落在口头禅上 | 换掉那个词人物就没区别了 |
| 用动作断开长发言 | 发言内部没有转折 | 插入的动作是填充，该做的是缩短 |

**权力不是音量**。现场权力来自：谁能结束谈话或开门、谁持有可验证的证据、谁能把话公开、谁退出成本更低、谁能定义问题、谁愿付更高代价、谁掌握第三人的信任。台词改变权力后要有动作证明：对方交出物件、改称呼、停止解释、转向第三人、撤回条件或离开原位。关系变化不靠"我不再信任你"宣布，靠改称呼、把共同物品变成个人物品、不再替对方撒谎、第一次当着第三人支持或反对。

**打断**要有目的：阻止危险词被说完、抢问题的定义权、保护第三人、暴露自己早知道答案、把私事拉进公开场合；打断后要处理没说完那句的后果。

**同一人连说时的动作行**：中间插的动作要改变策略（操作证据、改变距离或公开范围、暴露言行不一、给出对方必须回应的新事实），不写"看了看、顿了顿"。发言内部没有议程转折就缩短，不拆。这和 §4"短"不冲突：拆句仍按 §4 的字数上限；拆开处放对方反应或一个改变策略的动作，下游分镜在同一个长镜头里按拍承载（storyboard-keyframes §7b）。

**高密度对白场**要有可见锚点支撑权力变化：一份能逐步露出内容的文件、一个会改变公开范围的门/电话/录音、一件所有权正在争夺的物品、一个有时限的现场任务、第三人的进出。听者不是空白——验证、隐藏、拖延、记录、改变站位、让第三人看见，或者不给预期反应；每轮对话承担不同的工作（定义问题、试探知识边界、提条件、交出或拒绝证据、重新定义关系、逼选择、承担后果），连续几轮功能相同就压缩或让对方换策略。

**人物口吻卡**（写进视觉设定的人物条目，和 §4c 的"口吻"一行放在一起）：默认策略；认什么才算证据；最常回避的话题；建立亲近或权威的方式；压力下怎么变形（更正式、更短、更礼貌、更粗暴、开始重复、突然坦白）；对某人的称呼与禁区；绝不会自然说出的表达。它不是口癖表；同一个人对上级、家人、陌生人用不同的策略。

## 5. 动作

- 可表演动词：压住、抽回、避开、递出、擦掉、停下、拆开、锁上、挡住、撕下。不写"眼神复杂、内心挣扎"。
- **常见动作判据**（shuohao/视频模型的生命线）：上船、坐下、递东西、点头、回头、抱紧、站起来、放下杯子、把纸推过去，放心写；用工具挡物、以厘米计的位移、三步以上的双手编排、微表情堆叠、比喻性画面，改写或删掉。剧情信息靠常见动作的组合和时机传达。
- 关键动作先明确起点、接触/操作和结果，再选承载镜头；不强制四拍或四个单人镜。
- **表演写成"接住 → 改变"**：重要回合里，人物先对上一拍对方的行为做出可见反应（夺过、合上、推回、后退、笑容停住），再说台词；台词说完，局面要有一项变了（谁多了筹码、谁退了一步、谁失去了什么）。设计要"笑僵住、慢慢合箱、认输"，就写三个动作行，不写一句"他认输了"——下游只拍得出写出来的动作。一场里人人只开口、没人动手接招，成片会读成轮流说明情况（storyboard-keyframes §8c，G49）。
- 接触动作要让接触关系和结果可读：可用双人同框、身份明确的手部特写，或有意省略接触并用声音和结果证明；不能用两个无关联单人镜假装完成交接。
- 物件要进入行动链：谁持有、它能证明或阻止什么、状态变化、变化后谁必须作新决定。重要物件第一次出现时让人物对它做事。
- 同一物件可以反复出现，但每次要有新工作：换了持有人、露出文字、用途改变、旧承诺被重新解释、人物做了以前不会做的事。不为"丰富"不断引入一次性道具，让观众每场重新学一套证据。
- 空间写对剧情有用的地理：谁挡住出口或控制柜门、关键物件在谁够得着的范围、谁能看见文字谁只听见声音、公开与私密的边界、站位改变后联盟或威胁怎样显形。
- 打戏写清部位、路径和物理后果；重复招式只有在空间、资源、策略或关系持续变化时才保留，不按回合数填充。
- 手机屏幕背对镜头；画面里不出现可读文字，文字走 `[画面文字]` 后期叠加；画外电话声走 `[OS]`，后期配音。

## 5b. 因果交代：新人物、新物件、新事件先有起因

重要变化必须有世界内原因；观众是否提前看到由悬念设计决定。明确区分世界真相、角色所知、观众所知，按 [信息与连续性](scene-state-and-reveal.md) 记录。

- **人物登场**：先写他被听到或看到——`[OS] 老师：何してる！` + `楼梯下方传来上楼的脚步声，夏樹回头。`，下一拍老师才上到楼梯口。
- **物件首次出现**：先让它在动作段里露一次——`鬼塚的运动包拉链半开，露出一个同款金属钱箱的角。`，后面它滑出来观众才明白"原来他早准备了假箱"。
- **关键事件**：先写原因，再写结果——`夏樹往墙边让了一步。` 在前，`鬼塚扑空，冲下台阶。` 在后。
- **事件必须交代起因（硬规则）**：有人登场、东西摔落、冲突爆发、有人受伤、有人闯入，事件之前一定有一拍起因——画面（手碰到杯子、门把手转动）、台词（"你再说一遍？"之后才动手）或声音（上楼的脚步、玻璃碎前的推搡声）至少一种。不能凭空发生；写不出起因的事件，要么补一拍，要么删掉这个事件。起因可以和结果在同一个长镜头里先后发生。
- **关键物品一眼看懂**：关键物品第一次出现时，要么有来源拍（谁拿来的、从哪来的：从包里拿出、从桌上拿起、别人递过来），要么这一拍就是清楚的插入特写，同时有台词点明它是什么（"同じ箱……！？"）。只在远景里出现、没人提、下一场就派上用场的物品，是"凭空出现"。
- `requires_setup` 只列观众必须预先知道的事实；有意后揭示用揭示计划记录，不能机械要求原因先出镜。
- 起因拍写完后在 `[连续性]` 里记一笔：什么东西在哪一拍被交代、谁看见了（观众知道 ≠ 人物知道，story-engine §8）。
- 分镜阶段把起因拍记成 shots.json 的 `setup_for`，结果拍记成 `requires_setup`（storyboard-keyframes §2b，G32 查顺序）。

## 5b2. 金手指的分量与开头因果（用户 2026-09-26 实拍反馈）

- **金手指要有名号、来历、夸张的尺度**：道具或能力出场后，尽快给一个有气势的名字（「镇渊」）和一句来历；时间、代价、威力用夸张量级（「封了两千年」而不是「二十年」、「祖师拿命才钉进去」），让观众一听就知道这东西不简单。
- **量级全剧统一、宁大勿小**：金手指立了「两千年」的量级，相关的前史、债务、传承也要同一量级（先祖、血脉、祖师），不要再出现「二十年前父亲」这种小尺度把它拉回平凡（用户 2026-09-26：「20 太垃圾」）。
- **让权威角色替你介绍**：由长老、师父、反派头目、专家这类有身份的人当场认出并说出名号与来历（一两句、压低声音、带忌惮），比主角自述或旁白更有分量，也顺带抬高主角处境的危险程度。
- **设定改动与后续冲突时，用「知情人隐瞒」接成伏笔**：改大的数字或来历若与后面集数的揭秘冲突，不删后面的线，改成介绍者只说一部分、刻意不提另一部分（在 [连续性] 写明他知情），后面揭开时反而成了反转。
- **开头因果四问**（错误表 E20）：遇险前交代在哪、为什么起冲突；金手指道具被用到前先被看见；动作中的表情身体与处境一致；每个超常结果（飞、治愈、到账）用台词或画面说明机制。开幕雷击可以因此晚几秒，看得懂优先。

## 5b3. 能力规则只讲一次：后面只提醒

外部审查实例：新角色用约 24 秒重新确认观众刚看过的能力，第二集开头又解释一遍；人物轮流说明规则，戏停住了。

- **讲清一次**：能力规则（触发、限制、代价）在画面或台词里讲清之后，本集后面只允许一句话的提醒，而且这句要同时做别的事（威胁、押注、试探），不单纯复述。
- **新角色确认 ≤1 句**：新角色第一次见到能力，用一句反应台词或一个动作确认（「……今の、見えたのか？」），不再从头问一遍规则；需要他知道更多，就让他亲眼看一次新用法，而不是听一遍旧说明。
- **跨集回顾 ≤5 秒**：第二集起的开头只用一个画面或一句话接上一集的能力，总共不超过 5 秒，然后直接进本集的新用法或新代价。
- **新信息才值得再讲**：再次讲能力，只能是规则多了新限制、新代价或新反制（story-engine 的机制循环），这时写的是"新在哪里"，不是"原来是这样"。
- 分镜把承担解释或确认规则的镜标 `explains_ability: true`，G48 按同集总量和第二集起开头窗口提示（storyboard-keyframes §8c）；reviewer 按 review-checklists §C3 第 7 问判。

## 5c. 声音事实：剧本只写故事需要听见或撤掉的声音

剧本拥有逐字台词和承担剧情的声源；整场声音怎么走、逐镜底噪和进出是分镜与视频提示词的事（video-prompts-general §9、edit-and-delivery §5），剧本不替它们混音。写一场前问五件事：

1. 开场观众先听见什么，它怎样建立空间或画外人物的存在（上楼的脚步、门外的说话声）；
2. 哪个声音代表当前秩序、人物习惯或权力（课长敲桌子的笃笃声）；
3. 哪句台词、哪个证据或选择之前要**主动留白**，留白让路给什么；
4. 环境声什么时候撤出、恢复或变远，由哪个可见事件触发；
5. 要不要用一个声音把本场结果带进下一场（sound bridge）。

- 承担证据、威胁、空间或转折的声音写成 `[SFX]` 或 `[OS]`，不能只留在后期想象；没有剧情职责的空调、车流、鸟鸣不必登记。
- 留白要写明对象和恢复条件（"餐具声停下，只剩底噪和一次吞咽"），不等于漏写声音。
- 声音不替表演：身份揭示不默认加冲击音；删掉配乐说明后人物选择不成立，先修场景。多人场的声音可以分层：近的人先停话，远处后知后觉，某个人继续制造噪音掩饰紧张——差异来自立场和距离。
- 失效信号：所有冲突点都用同一种冲击音；sound bridge 提前泄露下一场不该知道的身份或地点；要求一个剧本和视觉设定里都不存在的声源。

## 6. 时长与容量

单集目标 `target_seconds`（默认 120 秒 ≈ 24 个 5 秒镜头）。估算（shuohao 时长引擎，速率按项目标定）：

```text
台词秒数 = 去空白字数 / speech_rates[语言]      （ja 约 5 字/秒，zh 约 4，en 约 2.5 词/秒）
动作秒数 = 动作段落数 × 2.5
粗估区间 = [max(对白秒数, 动作秒数), 对白秒数 + 动作秒数]；明确并行的段取 max，明确串行的段求和，再加必要停顿。
```

粗估用于发现容量风险，未知并发时不能当精确片长。生成后以实测可用段和听审验证。

**长集结构（`target_seconds` ≥150 时启用）**：一集装两个回合，而不是把一个回合拉长。时间约 50% 处必须有一个**中段小钩**：新信息、新威胁，或反转半步；它只负责抬价，不能比集尾更炸，否则集尾会塌。后半回合的施压和反击各升一档（story-engine §9 升级刻度），不复用前半回合的话术；两个回合打的是同一个核心矛盾。场次最多 3 场，第 2、3 场要换空间、换对手或换压力等级，挪到隔壁接着说同一段话不算新的一场。集尾钩子优先用揭示或抉择型（story-engine §5）。（取自 short-drama-factory）

## 7. 巧合、误会、艰难选择的边界

- 巧合有方向：制造问题可以，解决问题不可以；巧合送来的必须是负担；同一条线上第二次巧合就是模式。前面建立过的同楼、同通勤线、同熟人圈里的偶遇是设定，不算巧合。
- 已建立的资源可以改变问题的形状，但不能恰好替人物付款：道具、身份、权限或旁人的出现直接完成了最难的那一步，人物自己的策略和取舍就被掠走了。旁人因主角闯祸进场，他的反应通常让主角更难维持原策略，而不是无条件欣赏、宽恕或刚好送来资源；温情或反常反应要是作品已经建立的世界和语气。
- 误会四判据：人物有理由不解释；观众位置选定（知道真相=悬念，不知道=惊讶）并贯彻；误会必须产生行动；解除时必须有残余。
- 艰难选择只在剧本主动承诺时启用：两个方向都要活着到人物行动，写清各自保住什么、失去什么、为什么不能先后都做。普通决定不硬包装成两难。
- 精确死线只在题面给出可核对数字时使用；时间标记要单调，动作容量要与时间相称（§7b）。

## 7b. 证据、精确死线、有限次数（只在本集以它为发动机时启用）

这三类规则条件启用：本集没有这种结构时不补；本集已经把它当主要看点时，要让观众通过阻力、行动和后果感受到它，不能只让人物把规则念出来。

**可争议证据**（人物的重大判断靠它转向时）：
- 先分清转折依赖证据的哪一层——来源真伪、谁留下的、为什么这么做、事件完整真相。人物只更新被证明的那一层，结论不超出实际展示的范围；真正的戏剧变化通常在下一个动作（撤回指控、改变合作、藏起新发现、升级防备）。
- 至少有一次观众跟得上的状态变化真正改变了推断（让某个解释更可能或更不可能、或暴露当下越不过的证明边界），并因此改变人物下一步。拍照、装袋、编号、登记只有改变了可用性或调查方向才算戏剧节点。
- 一次验证已经改变了本集需要改变的判断就停，不为显得严谨把同一结论依次交给页面、原件、日志、时间戳再确认一遍。
- 结论依赖"原位、封存、没人碰过、时间"这类状态时，按动作顺序查前面有没有人破坏过它；`[连续性]` 只能交接已拍到的状态，证明不了"镜头外没人碰过"。
- 喜剧误会、主观叙事、以歧义为目标的线索不强制加取证程序。

**字面精确死线**（观众能逐项核对的倒计时）：移动、寻找、操作、等待、说话都占时间，每次出现新时间要和其间完成的工作大致相称；时间标记单调（20:59:47 之后的十秒倒数在 20:59:57 左右结束，整点报时后不再出现 20:59:58）；宁可少写一个数字，也不让精确数字互相拆台。"快点""来不及"这类定性压力不升级成分钟、秒数、时间戳或系统通知。来不及时人物可以缩小目标、换熟悉的方法、调用已建立的资源或接受部分失败；临到高潮才冒出此前无迹可循的资源、权限或能力直接抹掉困境，不是换策略。蒙太奇、跳时、主观时间按作品已建立的约定判断，不套现实秒表。

**有限次数/轮次**（题面规定"三次机会""两轮演示"时）：每个单位按结束时的可见结果计数；报数、提请求、拿到授权、开始准备、在边界之后补做，都不算完成。可以故意让某一次失败或只完成一部分，但要让失败本身在这一单位结束时可读。金手指有次数或冷却限制时（系列简报的装置条款），剧本里每次使用都按这条计数。

## 7c. 可替代实现：关键拍生成不出来时换拍法，不删戏

AI 生成管线里，某个兑现只有一种拍法、而这种拍法后来生成不出来（动作太精细、接触读不清、画面必须出字）时，最贵的返工是"只好把这场删了"——删掉后它承担的功能没有别处兑现，前面的铺垫全部空转。这个窗口会关闭：拍法刚写下时换掉几乎零成本，进了身份图、起始帧、视频之后成本陡增。

所以写完剧本、进分镜之前，导演岗对**生成风险高的关键拍**（精细手部动作、双人接触交接、依赖可读文字、大动作路径、依赖微表情的认知变化）在 `项目开发/决策记录.md` 各写一行，三件事分开：

| 字段 | 回答什么 | 常见错误 |
|---|---|---|
| 功能 | 这一拍兑现了什么：谁的什么被证明、谁的处境改变 | 写成"高潮""爽点"，没法判断备选是否等价 |
| 当前拍法 | 现在用什么呈现 | 和功能混写，换拍法就得换功能 |
| 备选拍法 | 换一种呈现、兑现同一功能 | 写成"改温和些"，那是削弱不是替换 |

备选算数的四条：同一个人被证明或改变；下游依赖（后面的兑现、下一集进入状态）仍然成立；代价没有消失；不需要前面没建立过的新事实。**"删掉这场"永远不是备选**；可以把功能移交给另一个已有的拍，并写清那一拍要多承担什么。备选要具体到能直接写成动作行，"酌情处理"等于没写。先按最想要的拍法写，备选只在视频审片确认拍不出来时启用（production-and-review §7 的"关键动作没发生"复现后），不提前把所有高风险处磨平。

例：功能"证明排班员改过记录、且是为保护一个不能公开的人"。当前拍法：她当众摊开排班本，指出涂改的那一行，说出被保护者的名字。备选：她把本子交给指控者本人翻，指控者读到那一行时停住，只念出半句"这是……"——名字由 `[画面文字]` 叠加的那一行交代（AI 表演演不稳"读到后脸色一变"，认知变化要有台词或可见物件说破，§4）。功能不变：改动被证明、动机暴露、她的可信度同时受损。不算备选：改成她私下解释（受影响的人变了、公开的代价没了）。

## 8. 收束与交接

结尾先回答本集承诺的功能是否完成：兑现落地、关系重新定义、认知变化。爽剧的兑现要拍到反派失去了什么、谁当场确认了、什么回到主角手里；反应放在事实落地之后。新问题从兑现里长出来，不是新人物踹门。

已声明不可逆的后果不被后续动作写回；核心阻力的代价在退出状态里至少保留一项实质影响（能力暂时缺口、身体损伤、资源消耗、关系债务、必须处理的后续行动），不在高潮后让系统、能力或局面自动复位。

兑现落下之后逐拍问"它在加深、转义、沉淀，还是重复说明？"：人物放下、拿起、让路、离开的动作已经表明意向，后面再写一次同向决定只会稀释第一次（除非中间有新阻力让第二次付出不同代价）；行动和画面已经完成的意义，不再用一句口号或人生道理翻译它。

`[连续性]` 写精确出去状态：谁在哪里正要做什么；谁知道/不知道什么；谁持有什么、状态如何；伤势、服装、时间是否延续；哪项动作已不可撤回。这一段就是下一集的进入状态和集纲"交接事实"格的来源。

## 8b. 集尾与下集开头成对写

- 本集最后一拍和下一集第一拍当成**一个节拍**来写：写集尾钩子时，同时把下一集开头前 5 秒要发生什么写进 `[连续性]`。[社区]
- 下集先接住上一集未决事实；有叙事必要时允许短回顾或时间跳跃，明确标记并避免重复消耗时长。
- **禁止虚假悬念**：上一集吊着的问题，下一集开头 10 秒内被轻松化解、或被证明根本没事，是 Major。[社区]
- 同一个悬念只吊一次；下一集集尾要吊新问题（钩子型见 story-engine §5，相邻两集不同型）。[社区]
- 连载集先兑现本集承诺，再让新问题从后果中产生；允许切在新问题上。完结集可以闭合，不强行追加钩子。

## 9. 修订纪律（分遍修订、分批续写）

一遍只修一种问题，保护已接受的选择。按顺序：

1. **因果遍**：每个主要动作旁问——因何发生？人物为何此刻选它？对手如何回应？改变了什么？下一动作为何被迫发生？删掉可互换顺序且无后果的重复。
2. **场景遍**：标出每场的目标、反对、策略变化、转向和退出；没有变化的场并入相邻场、让证据/关系/决定在此真正改变，或删掉并把必要信息移进正在发生的冲突。
3. **可表演遍**：圈出只存在于作者说明里的认知和情绪，给关键项选一个载体（行为、证据、空间、关系动作、有意的 `[VO]`）；不为每个形容词补微表情。
4. **具体性遍**："资料"是登记页、录音还是钥匙卡？"威胁"让谁失去什么？"关系破裂"落在哪项承诺、称呼、持物或站位上？只补对辨认、因果、表演或连续性有用的细节。
5. **条件遍**（只在本集启用对应发动机时做）：选择遍（两个方向在行动前都有价值，哪项损失由这次选择新增，§7）、证据遍（证明了什么/没证明什么/还有哪些解释活着，§7b）、死线快查（把时间标记之间的动作顺序读一遍，§7b）。
6. **对白遍**：给每句标用途（§4）；删掉人物彼此都知道的说明；**交换说话人测试**——两人台词对调后情节和关系几乎不变，说明缺的是各自的目标、证据观和关系风险，不是口癖；朗读，检查句子能否在当前动作里说出、提示是否和台词重复、长说明能否被对方打断或要求证明；母语口吻按 §4c 过一遍。
7. **生产事实遍**：必读文字、关键声音、画外台词、转场、连续性是否都有标签（§1）；去掉镜头、模型、资产说明。
8. **扫读遍**：用比正常快得多的速度不回看地扫一遍整集，只答两个问题——有没有需要停下来才想明白的地方（谁说的、刚才那人做了什么、这东西哪来的）；扫完情绪有没有起伏，还是只知道发生了一串事。慢读证明剧本讲得通，扫读才证明观众接收得到。需要停顿的位置记下来再决定改不改；刻意要观众停下思考的段落写明理由保留。
9. **经济性遍**（最后静默做）：扫掉输入没要求的精确数字和记录链、为同一结论叠加的验证、复述动作的标签或台词、兑现后多个同方向的决定或口号。删的是冗余展示，不是选择、证据、时限或连续性本身；自检让剧本长出了输入没要求的机关，撤掉机关，不替它找理由。

- **改一拍，连读三拍**：改过的位置前后各一拍一起重读，检查空间、持物、知情状态没有跳变。
- 用户原文优先；去 AI 味是定点修订，不抹平作者个性；方言、笨拙、重复、长句只要是人物选择就保留。
- 修订结束列出语义变化、未改部分和受影响的下游（shots.json 里引用了哪些场、哪些台词），写进决策记录；writer 不给自己签发通过。
- reviewer 的审查按 [review-checklists.md](review-checklists.md)（§0 输出格式与分级、§C 剧本审查问题）写 `审查/<EP>-审查.md`；writer 改完对 `keep:` 清单做字面比对。
- 同一缺陷两轮没过，升级为改上游（集纲/简报）或接受并记录未决，不无限循环。

**长单集分批续写**：一集因为上下文限制要分几批写时，在当前会话上下文里维护一份最小交接摘要（不落盘、不当第二份剧本）：集号和最后完成的场次 ID；上一场结束时仍影响下一场的地点、在场人物、知情、关系、伤势、持物和风险；已铺垫未兑现的事；下一场已定的功能和退出状态；本批还没解决、会改变写法的创作分叉（按自动决策定下并记决策记录）。续写前先重读 `剧本.md` 最后一个完成场及相邻上下文，摘要与正文冲突以正文为准；整集写完后丢弃摘要。这是 story-engine §10"三回锚"在单集内的版本。

## 10. 门与失败征兆

机械检查：`scripts/screenplay_lint.py <项目> <EP>`（格式，§1）；`shots_tool.py check` 的 G16（粗估时长区间与目标对照）、G37（单句长度）、G10/G11（台词逐字对照与覆盖）；分镜阶段的 G46（每条必拍事实有镜承担，§2b）、G48（能力规则重复解释，§5b3）、G49（对白镜只说不做）也会追到剧本：必拍事实写不出、能力讲了三遍、一场只有人轮流说话，先回剧本改。密度、连说和快速开口仅在 commercial_fast 或项目明确配置时提示，不作为通用创作规则。

reviewer 判的内容（因果可见、情绪标签、母语审读、事件起因、关键物品、秒表核对、集间接缝、单句长度、场景发动机、对白、规范化核对等）集中在 [review-checklists.md](review-checklists.md) §C，按那里逐条引用证据回答，严重程度也按那里定。

写作者交稿前的自查失败征兆：场里没有「必拍：」或必拍事实与台词数字对不上（台词说十件、动作行写了十一件）；已讲清的能力规则被新角色或下一集开头再讲一遍；台词能逐字译回中文且语序不变、日语男高中生用「私」和です/ます跟同学说话；事件没有起因就发生；人物凭空出现在场内、物件凭空出现在手里或脚边；全场台词一个情绪；被撞只写"他愣住"；人物轮流复述背景；每句直说真实意图且没有关系理由；一方持续发问另一方持续完整回答；对方已反制角色却重复原要求；台词很狠但没让任何人改变行动；每句后配无功能的表情动作；受刺激却不出声；解除误会后一切照旧；结尾用省略一句话制造假悬念；下一集重置上一集的决定和代价；多人场靠动作段落逐一点名在场者、观众仍分不清谁和谁交手；主角缺席的场替配角讲他自己的故事；对手开场的筹码在主角做完一个动作后无因归零；精确死线只能靠没说明的瞬间完成；兑现后用口号解释已经演清的意义；动作行以"短语："开头被读成对白；剧本里混入镜头、提示词或资产全集。
