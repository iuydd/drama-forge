## 10｜执行与恢复：一个提交所有者，一份有效版本，一本任务账

先读 PROJECT_START、当前范围、任务账、真实通道/配额和授权，核对加载的 Skill、方案及最终请求；文件更新不证明旧会话或 worker 已刷新。工具存在不等于接通或可靠；复用样片，只校准本次需要的声线、字数、多人、接触或换角度能力，报告通过数/总数，不凭一例推广。

### 用真实证据区分状态

以下语义映射到现有字段，不另造状态机：

| 当前情况 | 必须保留的依据 | 允许下一步 |
|---|---|---|
| 待生成/返修 | logical_job_id、task_type；返修含repair_of | 依赖、版本、授权和配额满足后提交 |
| 等代表镜验证 | 任务ID、原因、验证镜与放行条件 | 实际验证通过才恢复，跳过不算完成 |
| 已领取、提交未知 | attempt_id、请求指纹、发送意图 | 记SUBMISSION_UNKNOWN，只对账不重发 |
| 远端接受/运行 | remote_task_id、服务状态、费用占用 | 查询原任务，收回或按授权申请取消 |
| 请求重复 | 原任务关联及查询结果 | 查原任务，不换ID绕过拒绝 |
| 已取回 | 文件、hash、原任务/请求/版本 | 审核，不直接采用 |
| 旧版候选/已撤回 | 来源及当前采用资格 | 按[09](../references/09-review-repair.md#r09)处理，不自动替换新版 |

名称和后缀只供显示，不据此分类、跳过或认定完成。提交前查 ID 唯一、类型有效、返修来源与依赖存在，缺失或未知报错，不静默 continue。确定性约束复用入口断言；语义猜测、台词容量估计只预警，已编码且确定的状态矛盾可拦截。锁、STOP、资源和子进程由运行期控制，实际声画按 [07](../references/07-animatic-audio.md)–[09](../references/09-review-repair.md) 验收，不另开门禁。每批对账完成、失败、暂缓和未知；未完成镜头留队列，不报整集完成。替代任务关联原逻辑镜头，次数按 09 累计。

### 同范围只有一个提交所有者

同项目、同生产范围只有一个活动提交批次，内部按配额并行。所有入口和 worker 共用跨进程独占锁，启动 worker 前原子取得，覆盖全部提交子进程存活期。“先查再启动”、进程内锁或锁文件存在不能替代执行权；不以删锁、路径别名、工作目录或批次名绕过。单机可用系统文件锁，多主机须共享协调器。

STOP 是停止请求，锁是执行权，远端任务另记状态。接收 STOP 后本轮持续停止，删除标记不能恢复提交；已开始的请求仍可能到达服务器，须记未知/在途，不声称 STOP 后零请求。

重启、换方案或接管旧脚本时依次执行：

1. **停止领取。**持久化停止状态，覆盖提交和重试入口，停掉会拉起旧进程的调度器，不提前撤 STOP。
2. **核实本地退出。**按 PID、启动时间、运行标识与子进程归属核对实际句柄或结构化信息。终端关闭、日志静止、主进程退出、PID 文件、心跳超时或 `ps | grep` 空匹配均不证明全退；编码、转义、截断、权限或解析异常记未核实。终止前防 PID 复用并确认归属；未接锁的旧程序另查，新版持锁不证明它已停。
3. **对账远端。**核对已领取请求、任务号、取消与费用；未知不重发，已知只查回。同范围旧远端任务先收尾，不与替代批次重叠。
4. **独占接管。**原子取得执行权；锁占用或旧提交者状态不明就拒绝启动。上述确认完成后才重置对应 STOP。
5. **冻结当前请求。**锁内读取生效方案，冻结批次/方案版本、最终 prompt hash、有序资产 hash 和完整请求。每次提交前查停止、版本及依赖，再从账本原子领取。旧 hash 正确不代表版本仍有效，不用旧进程缓存 prompt 或原地改运行中请求。

记录停止时间、退出依据、在途对账和新所有者/版本。批次结束后的验证由同一执行器或持久化条件承接，不另开竞争批次；结束不等于通过，失败/未知继续暂缓。无持久化调度就记待办，不承诺自动续跑。

### 提交、收回和采用分别记账

区分 logical_job_id / attempt_id / remote_task_id，同 attempt 只有一个有效执行者。发送前持久化精确请求、输入内容 hash、参数、授权/费用上限、输出位置和提交意图；原子领取后发送，立即记录返回的任务号。路径相同不证明内容未变。恢复只取回原结果；获准的新候选须新建关联 attempt，不重置原链次数或改无关 prompt 骗过复用。下载失败只重下；未核实供应商幂等支持，不声称网络侧恰好一次。

本地退出不取消远端任务。取消不支持或未成功时保留状态和费用，只查询/取回并收尾。成功结果按原任务号存为独立旧版候选，绑定原批次、尝试和请求；失败如实记账。晚到下载/回调不能写新批次路径、覆盖同镜文件或更新采用指针。未知占位不是空槽，取消须有可信终止证据才释放在途资源。

旧 prompt 产物不自动作废或通过；复用、暂留、设计变更、撤回及下游失效统一按 [09](../references/09-review-repair.md#r09) 留证处理，下载完成不等于验收。

原件不可变，新候选/重剪另版本；同内容核实后复用，不同内容不覆盖。渲染和下载先写独立临时路径，完整性、流/时长检查通过后原子且无覆盖地保存；隔离中断残件，不凭文件存在或大小非零记完成。归档先冻结显式清单，核对仍被引用的输入；完成依赖或更新可追溯路径后再移，逐项核对目标、数量和 hash，不依赖 shell 隐式拆分，零项移动不报成功。渲染输入按 [08](../references/08-editing.md#r08) 冻结，变化须重对账；同版 G4 通过后，主协调器才更新交付指针，不能只改 project-state 留旧审核。

### 配额与费用控制批次内部并发

生成、ASR、编码和审核子进程均绑定任务所有者、启动身份及可核实的进程组/子树。正常结束、失败、超时或代理中断时，停止派生、终止所属进程并等待退出后才释放资源；必要时按宿主机制升级终止。代理停止不证明外部进程已退，不按进程名批量误杀；提交锁不能代替子进程清理。

优先用本机满足质量要求的 GPU/硬件加速，记录实际后端、设备、精度和并发，不以“已安装”代替核实。首次与差异复查沿用已核实的资源策略，不为第二引擎暗退重型 CPU 全量处理。后端不支持或质量不符时，CPU 回退须说明原因并限资源，超出已有资源/费用授权再确认；普通 CPU 解码不等于整条任务未加速。

ready 队列同时受依赖、账户在途、提交/查询速率、共享显存/CPU/内存/IO、费用和权限限制；预占全部资源后提交，真实完成后释放补位。图像、视频、超分、ASR 不重复算满共享硬件，正式资产单写。并发按实测与当前预算，不从一个槽猜多个槽或用满硬件上限；OOM、限流、积压只调并发/退避，不降画质，也不为填槽多做候选或越范围制作。

费用绑定任务/尝试、通道、数量/秒数、币种、范围、预估与上限，涵盖校准、配音、超分和审核 API。按实际计费粒度估算，预估不等于消费授权。已付、预占、待结、未知分开；按通道结算规则，以任务号或 request_id 去重核对供应商账单，不逐轮累加重复报告。失败、拒收、取消、超时或未产出不等于免费/退款；无结算证据保留未核实，不自动清零费用或预占。单次免计费不推广为通则，历史金额及更正以对应结算证据为准，更正后替代旧合计。新增费用或重试超出有效授权再确认。

### 项目执行器的验收与本包边界

生成或修改执行器时离线验证下列反例；不作为每镜新增工序，也不代表本包已实现全部机制：

| 不变量 | 必测反例 |
|---|---|
| 任务不丢 | 普通名以R结尾、返修名无R仍正确分类；类型缺失报错；漏任务/产物可对账；暂缓不计完成 |
| 单一提交者 | 双启动仅一个可提交；残留子进程阻止接管；中文路径匹配失败不放行；接收STOP后删标记不恢复 |
| 只交当前版本 | 拦旧prompt worker；验证失败不放行；无回执只对账；重复拒绝不换ID重发 |
| 结果不污染采用 | 旧结果晚到不覆盖；撤回素材不自动重选；新尝试不重置次数 |
| 事实传到实际请求 | 起始人物/持物等事实不能从结束快照消失；视频同时包含起始状态与获准动作；屏幕画内人物不混入现场人数 |
| 采用证据完整 | 有台词但未听音不能因ASR相似而通过；整镜重生成后仅复查修改目标、旧版局部正确或缺当前全场观察均不能批准 |

`job_ledger.py` 提供同账本原子领取和批次停止记录，`trusted_runtime.py` 校验冻结请求；项目进程树、项目级锁和当前版本指针仍由执行器管理。须从项目真正使用的提交与采用入口验证这些反例；自写脚本也要消费同一事实与检查结果，不能只验证包内另一路工具。改 Skill 不证明旧进程已退、互斥已测或漏片已补。

### 环境与授权

服务地址和凭证仅由受信执行器从项目指定环境变量或安全凭证服务读取；缺失即阻塞，不猜端口、硬编码、搜日志找密钥或打印值，子代理不继承凭证。无人值守只用已授权无交互工具；遇新权限、密码、安装或系统弹窗就记录并暂停，不绕过控制。没有执行器就交方案和待办，不承诺聊天结束后运行。
