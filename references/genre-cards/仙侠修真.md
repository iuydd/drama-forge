# 仙侠修真

本卡汇总工艺做法，市场结论以 [market-hits.md](../market-hits.md) §4 为准，最爽的场面与用烂的写法以 [premise-novelty.md](../premise-novelty.md) §8 为准；这里只摘要并落成写作动作，不重复维护数字。

## 观众为什么爽

在一套可以学习的力量规则里，看人怎样用规则解决人的问题。境界和法术只是压力的度量衡，真正的戏在师承、宗门位置、天赋差、寿数和情义债。力量没有代价，本题材只剩特效清单；有代价，观众才会为一次出手屏息。长线的爽来自一条看得见的进度条：图录收录数、第几世、数值倍数、外物能强化的材料等级（market-hits §3 长青型）。

## 压力来源与反派手段

力量要花钱：寿元、根基、心魔、反噬、材料稀缺。等级制度决定谁拿得到资源；承诺和因果有约束力，说出去的话追得回来；对手同样在修炼，差距会自己变。发动机：想要的东西被规则挡在外面 + 突破规则要付看得见的代价 + 有人正在用同样的规则追上来。

对手要会学习：封锁资源、断补给路线、抢先突破、把主角的靠山调开；不许只会说"区区炼气期也敢"（premise-novelty §8）。打脸对象沿梯子升：身边人 → 本地势力 → 宗门 / 官府 / 圣地 → 更高位面，每升一级换地图、换反派阵营，至少写出 4 级；最高层是虚构的天道、仙庭、古神（market-hits §4.2）。

## 主角策略与信息权限

以巧破力、借势、以小代价换时间、藏住真正的底牌、把私怨挂到门规上处理。信息权限：谁知道这门功法的来历、谁看得出真实境界、谁能识破伪装、谁在替主角遮掩。金手指按 story-engine §4 写条款级契约（来源、功能、边界、成本、反制、升级条件、滥用后果），第一次展示功能、第二次加限制、第三次让主角想出新用法。

## 兑现落在哪

力量差被具体改写：一次越阶、一件法器易主、一道禁制被破、一条门规为你改口、名录上的名字挪了位置。节拍（market-hits §4.1）：一集一次小兑现（斩一只妖、强化一株药、数值跳一格），第一次不晚于 EP001 第 60 秒，可以只有观众看见但画面上必须看得见；3–5 集一次公开打脸，由之前看不起主角的人亲眼见证；一季一次大境界突破加一次身世揭露。越级战赢在布局和代价，赢完付可见代价（premise-novelty §8）。本题材独有的情绪落点是长生尺度下的告别：同门老去，凡人朋友的一生只是主角的一段修行，比爽点更耐用。

## 常用场面颗粒

拜师与逐出的动作、丹药瓶与空瓶、剑与剑鞘的归属、玉简与传讯、山门界碑、比试台上划出的线、经脉受损后握不住东西、跪拜与还礼、门派名录、断掉的信物、封起来的洞府、数得清的灵石、测力石裂开。规则要有可观察的限制：多久能用一次、用完之后做不了什么。数值面板、计数器、图录点亮走后期叠加（styles.md §12，`overlays.panel` 用 `xianxia` 或 `scroll` 主题），生成画面不出字。

## 集尾钩子取向

market-hits §4.4 的三类：胜负未分（战斗停在半空）、真相揭一半（回放没放完、身份差一步、证据出现没打开）、更强的人登场（系统发新任务、上一级反派露脸，须已铺垫）。对应 story-engine §5 的危机 / 揭示 / 闯入型；相邻集不同型，最后 5 秒停在"下一秒就要发生"。代价开始生效（反噬、寿元、心魔浮现）和信物出现在不该出现的人手里也好用。不成立：又冒出一个更高境界的人宣布"你完了"而此前没有任何铺垫。

## 前中后期与续季打法

- **前期**：把规则边界和代价演示给观众看，同时让主角欠下一笔情义或因果。
- **中期**：境界差被反复重估，资源争夺升级成立场选择；主角的取巧手段开始损伤根基或名声。
- **后期**：把最初那条规则用在他最不愿意用的人身上，逼出一次不可撤回的选择；飞升、留下、断情、认输都是可选结局气质。
- **续季**：立项就按"每季一个境界或一张地图"切（market-hits §4.7），季规划、跨季线和季间换代见 series-long-form §6；长篇不崩三要素（世界观一季一季扩、至少一条跨季情感线或因果线、升级线可外包给弟子或族群）见 market-hits §4.3。慢爽（一世一大爽）要有贯穿多世的明确仇人，不适合当冷启动模板。

## 制作难点（AI 生成）

- 画风默认 `guoman_3d`，不选 2D 平涂（market-hits §4.6、styles.md §1）；要像电视剧才选 `live_xianxia`。
- **好拍**（market-hits §4.8）：审判 / 回放结构（固定场景 + 大量反应镜）；面板与图录点亮（后期）；形态进化（每个形态一张参考图）；一击秒杀（蓄力、光效、倒地三个短镜）；群体下跪或震惊的静态反应镜（按具名个体单人镜出）；山门云海空镜；现代场景里的修仙大佬。
- **难拍**：长时间来回过招（拆成短镜，用反应镜穿插，节奏下限照守）；多人同框群战（拆成少人镜 + 接触同框，每镜写死 exactly N，对话镜听者入画，SKILL.md 3、11c）；萌宝细腻表情和口型；持物连续性（巨剑、盆、令牌每镜重申，视觉设定写持物锚点）；跨季人物一致（每季开头重校参考图与风格句）。
- 特效是成本黑洞：把力量差落到可复用的画面语言（位置、界线、持物、损伤状态、旁人退让的距离），飞行、群战、天地异象只做少数几次，其余用余波（碎裂的地面、被吹开的门、旁人的伤）。境界若绑定造型、发色或衣饰，台阶数立项定死；法器丹药按道具管理版本和消耗。
- 光效要照亮附近的脸和表面，比例和尺度按世界设定核对（SKILL.md 6e）。

## 市场对标与禁区

- 长青组合：修仙 × 系统 / 图录 / 轮回；修仙 × 废柴 + 一件外物；觉醒 / 血脉 / 数值进化；萌宝团宠 + 满级靠山（market-hits §1.1、§3）。中等：反差 / 倒练 / 装怂（3D 才做得长）、收徒 / 开局封顶。昙花一现：隐藏大佬下山归来（10 部 0 部长青）、一日连破七境式一次性爆发、借大 IP 角色兑现。
- 首发红果，形态 3D 漫（market-hits §2）。
- 禁区（market-hits §4.5）：不碰真实宗教神佛本尊，不挑衅真实信仰；不用明星脸；不做未授权网文 IP 改编；合规检查在写剧本时就做。
- 开头 1 分钟结构与检查清单见 market-hits §6。

## 禁止漂移

设定名词堆砌代替冲突；境界数字自动等于胜负；为救场临时改写规则；把突破 / 渡劫当成不需要选择的万能解法；凡人角色只作衬托境界的背景；premise-novelty §8 列的用烂写法（废柴退婚三年之约照搬、出场满级挥手秒杀、围观弟子齐声"这不可能"、每集亮令牌、丹药法宝凭空出现、越级战无代价、师尊只负责夸）。
