## 1. 镜头单位：对话看得见对象、接触动作双人同框

- **对话对象与空间关系可辨（2026-09-27 维护修订，E33）**：默认两人同框或听者肩背在前景（只露背不露脸，避免 E3 把同一人画两次）；多人镜写 `exactly N`、每人一次。已有建立镜、视线和切回承接能明确对象时，可拍单人对白；`single_reason` 引用建立镜号、剧本原句、对象方位和本镜用途，不能只写“突出情绪”。只有主角看得见的角色也要先建立存在和方位，不能凭设定省略。自言自语、对全场喊话同样写具体理由；无对白反应镜可以单人。reviewer 和预演按前后镜核对象，读成对空气说话就退回同框。G53 保持原检查：理由缺失、少于 10 字或两镜复用同一句报 error；理由的真实性由审查判断。多人镜 `in_frame` 人数要等于 exactly N，且在 `scene_state` 名单内。
- **连续性不等于全场串行（2026-09-27 维护修订，E33②）**：默认由经核验的同机位底板、身份图和 `scene_state` 生成各镜起始帧；同机位可用通过的 `frame_parent` 派生，保持原有 G40 与参考图准入。逐镜核站位、视线、光与道具，不能声称参考图自动保证连续。只有确需继承动作终态时才取上一镜已通过视频的出点帧作 Picture 1（保存为 `CHAIN-<镜号>.png`，记来源镜、take、秒数和 sha）；逐人写新机位下的位置朝向，不用“same positions”带过。G2 前先用底板或父起始帧完成可审预演，不要求所有首帧等待尚未生成的视频；后续改用实际出点帧时，重新目检并重跑受影响的预演，再提交后续视频，不借链式需求跳过 G2。已声明的父帧或视频链依赖照常失效传播；没有依赖的镜只重核受影响的场景状态与相邻连续性。
- **接触关系必须可读**：双人同框、身份明确的手部特写，或有证据的省略均可；写明谁将什么交给谁、接触前后归属。选择双人构图时写 `multi_person` 及原因。
- **脸要达到用途所需的可读性**：关键口型与细微表情优先近景；远景可承担画外对白，不要求所有脸达到统一比例。
- 表情承担关键信息时保证其载体可见；遮眼可以是造型或叙事选择，须换用可读的姿态/声音。
- 每镜一个主要叙事职责；允许保持、观察和沉默，不强制每镜发生情绪转变。
- 片长结合对白、动作并发关系及项目所选模型支持时长决定；平台限制查当前配置，不把 5–8 秒视为通用上限。**同一个人连续做事、连续说两句，放在同一个长镜头里完成**（§7b），时长按内容定，上限 `shot_seconds.max`（H3 可到 15 秒）。
- 复杂度预算：人数、接触、运镜叠加主体运动、口型与长对白、必须可读文字、状态转换、节拍数——超标先减负（减少同时动作、把文字移到后期、加强参考）；确实要拆时优先拆出插入镜（手、脚、物件），拆成同一人的两个镜头要写 `split_reason`（G45）。
- **说话人看着说话对象**（§4 视线）：对话镜里说话人默认看对手，不看镜头；看镜头、看物件、回避视线都要有剧情理由（G43）。

## 2. 从剧本到镜头：动作只落实一次

**底板方向服务剧情危险**：分镜前先把剧本里的空间事实列出来（"夏樹身后是往下的台阶""鬼塚在楼下、夏樹在楼上"），选底板和机位时逐条核对画面能不能读出来；底板读不出（例如底板里身后的台阶是往上走的），先重出底板或换机位，不带着错的空间拍。危险要在画面里存在，观众才会紧张（EP001 S05 后仰要摔下楼，底板里身后却是往上的台阶，危险消失）。

先做**动作落实表**：来源动作｜主要落实镜头｜动作前事实｜动作后事实｜其他镜头作用。每个来源动作只有一个主要落实镜头，其他镜头只加反应、细节或新理解。上一镜终点是"右手刚开始伸出"，下一镜才完成取物；上一镜已经取到，下一镜就从"已经持有"开始，不再拿一次（AI 视频最常在下一镜开头把上一镜的动作重演一遍）。

剧本每场每句对白都要有镜头承载（G11）；多句台词按语义闭合点拆镜（同一人连说合并成长镜头，§7b），每个台词镜都按 §1 确保说话对象可辨，默认让听者入画。

- 动作落实表是责任清单，不是"一段一镜"：连续表演守得住原意时几段剧本可以合在一镜，揭示、反应、证据细节很重要时一段剧本也可以由几镜承担。
- 同一段剧本出现在两镜里，只在第二次带来新的观众体验时成立（新增反应、此前保留的证据、对前镜的新理解）；例：前一镜交代"谁摊开了手"，后一镜才让观众看清掌心的证物——物理状态没变、信息变了，也是有效的镜头职责。
- 剧本里不改剧情的动作不能为了"画面有动作"被改掉（剧本写"握着牌不递"，分镜不能改成递出去）。
- **冲击重复是唯一合法的重演**：爽剧打脸、反杀的峰值动作可以用 2–3 个不同机位重复同一下（例：耳光先中景、再特写、再反应者的脸）。条件：每个重复镜都从同一个"动作前"走到同一个"动作后"，状态只变一次；下一个非重复镜从"动作后"开始；每集只用在一到两个峰值。重复镜在 `split_reason` 写 `冲击重复：<被重复的镜号>`，G27/G45 看到这个前缀就不按跳切和该合并处理。（取自 zenstory-ai/drama-skills）

## 2b. 因果交代：新人物、新物件、新事件先有来处

观众只看得到画面和字幕。一个人突然站在主角身后、一个空箱突然出现在老师脚边、一场火突然烧起来，观众不会自己补"他是刚才从楼下上来的"——只会觉得"这人哪来的"。EP001 的空箱凭空出现在老师身后，就是因为前面没有一镜交代它从运动包里来。

**规则**：世界内因果不能缺失，观众获知顺序可以设计；`requires_setup` 只用于必须提前披露的依赖。隐藏道具或身份记揭示计划，不提前泄密。见 [信息与连续性](scene-state-and-reveal.md)。

| 要出现的 | 起因（铺垫）写法 | 例 |
|---|---|---|
| 人物登场 | 先听到（脚步、喊声、开门声 `[OS]`），或先看到（远处入画、影子、镜子里） | 老师上楼之前：一镜楼梯下方传来「何してる！」和上楼的脚步声，主角回头看向楼梯下方 |
| 物件第一次出现 | 先让它在画面里露一次（包里露出箱角、桌上放着、人物拿着），或台词点到 | 空箱滑出前：鬼塚的运动包拉链半开，露出一个同款金属箱的角（插入镜） |
| 事件发生 | 先给原因（有人碰到、条件满足、倒计时），再给结果 | 灯灭之前：一镜手按下开关，或先听到电闸跳闸声 |
| 状态改变 | 前一镜交代原因 | 衣服湿了之前：一镜被泼水；伤之前：一镜被撞 |

**在 shots.json 里记账**（可选字段，写了就被 G32 检查）：

```jsonc
{"id": "EP001-S14", "setup_for": ["空箱"],            // 本镜为哪些物件/人物/事件铺垫：包里露出箱角
 ...},
{"id": "EP001-S16", "requires_setup": ["空箱"],        // 本镜要求前面已经铺垫过的东西：空箱滑出
 ...},
{"id": "EP001-S19", "requires_setup": ["老师", "EP001-S18"],   // 可写名字（在前面某镜的 setup_for 里）或直接写铺垫镜 ID
 ...}
```

- `setup_for`：字符串列表，本镜交代了哪些东西的来处（人物名、物件名、事件短名）。
- `requires_setup`：字符串列表，本镜第一次让观众看到的人物/物件/事件；每项要么是前面某镜 `setup_for` 里的名字，要么直接是铺垫镜的 ID。
- G32（warn）：`requires_setup` 里的名字在任何镜的 `setup_for` 都没有，或只出现在本镜之后；写成镜头 ID 的，该镜不存在或排在本镜之后。
- 写作时在动作落实表后面加一列"起因镜"：每个新人物、新物件、新事件第一次出现的镜号，以及它的起因镜号。填不出起因镜的，回剧本补一拍（screenplay §5b），不在分镜里硬塞。

## 2c. 一眼看懂：关键物品的来源、事件的起因经过结果

`setup_for` / `requires_setup`（§2b）管"有没有铺垫"；这一节管"观众只看画面和字幕，能不能一眼看懂"。EP001 复盘：空箱突然出现在老师脚边、包崩开的那一下被剪掉，观众不知道箱子从哪来。

- **关键物品第一次出现**（能证明、能阻止、能兑现的东西：空箱、合同、令牌、账本），二选一：
  1. **来源镜**：画面里看得到谁拿来的、从哪来的——从包里滑出、从抽屉里拿出、别人递过来（递物按 §9 双人同框）；
  2. **插入特写 + 台词点明**：`kind: object/insert` 的特写，物件占画面主体、至少 1.5 秒（§7c），同一镜或紧接的一镜里有一句台词说出它是什么（「同じ箱……！？中、空っぽだ」）。
  只在远景角落出现、没人提、下一场却成了关键证据的，算"凭空出现"。
- **关键事件三拍都要有**：起因（谁做了什么、什么条件满足了）→ 经过（动作本身，至少一镜看得清）→ 结果（状态变了：谁倒了、东西碎了、谁拿到了）。三拍可以落在同一个长镜头里，也可以分镜，但每一拍都要有画面或台词；只有结果没有起因（人突然摔倒）、只有起因没有结果（推了一下就切走），都算没交代。
- **事件起因是硬规则**：有人登场、东西摔落、冲突爆发、有人受伤、有人闯入——事件镜在 shots.json 写 `requires_setup`，指向起因镜的 ID（起因在本镜里先发生就写本镜 ID），或写一个起因名、由前面的起因镜 `setup_for` 铺垫。`title`/`duty` 里写了这类事件却没有 `requires_setup` 也没有 `setup_for` 的镜，G32 会提示。起因可以是画面、台词或声音（上楼的脚步声也算），不许凭空发生（screenplay §5b）。
- **写完自问**（reviewer 按 review-checklists §E1 同样要答）：只看画面加字幕，每个关键物品、每个新出场的人物从哪来？每个事件为什么发生、起因在哪一镜？答不出的，回剧本补一拍，或在分镜里补来源镜 / 插入特写。

## 2d. 关键场次先比导演方案

只有导演选择会明显改变观众体验的场次才做：主要人物亮相、身份或证据揭示、关系反转、高潮与集尾钩子、复杂多人调度、延迟信息的悬念场。普通场次直接写镜头，不加表单。

director 在写正式镜头前，比较两到三个**真正不同**的方案。至少改变下面一项才算不同，只换景别名称不算：
- **表演中心**：延迟证据特写，让停顿、撤步、旁观者让路完成权力变化；
- **证据中心**：先给局部，再给听者反应，最后让观众确认；
- **视角错位**：揭示前后换观众所站的一侧，原来的观察者变成被观察者；
- **空间中心**：用入口、距离、阻挡、通道归属完成转向；
- **声音中心**：画外声、环境声撤出或留白先改变权力，再决定何时给画面确认。

每个方案回答同一组问题：观众何时知道什么、站在谁一边、谁拥有表演空间、最强的一格画面和最后的落点、可能丢掉的空间/反应/信息、和本剧画风与模型能力是否相容。整场还要看七件事是否共同承担同一个转向：戏剧转向（什么关系、信息或选择不可逆地变了）、观众立场从哪到哪、空间压力、视觉推进、摄影节奏、反应落点、声音策略（主导声源、何时留白、声音桥）。

两个方案在知情时机、对齐对象、表演空间、最强画面和落点上都一样，就是同一个方案。不固定方案数、宫格或镜头数。director 选定一个，把理由和放弃的方案各一句写进 `项目开发/决策记录.md`，再把选中的观看位置、信息时机、空间和声音策略写进正式镜头；未选的方案不留在 shots.json 里。剧本的开场与顺叙规则（SKILL.md 硬约束 6b）、画面不出字、对话对象可辨与接触关系可读（§1）照常适用，方案比较不能绕过它们。

## 2e. 必拍事实 must_show：剧情事实不可妥协

外部审查实例：台词说"十件"，箱内却是上排六件、下排五件，共十一件，"九假一真"的排除法直接失效；审片记录已经数出十一件，却以"观众三秒数不出来、剧情靠台词立住"放行。另一场设计要"笑僵住、慢慢合箱、认输"，成片里箱子一开始就关着，人物只在微笑动嘴。两处都是剧情事实没拍出来，不是画质问题。

**每场写 3–5 条必拍事实**（短场可以少，但每场至少一条）：观众不看台词、只看画面也必须读到的剧情事实。只收下面五类，背景里多一个普通摆件不算：

| kind | 写什么 | 例 |
|---|---|---|
| `count` | 数量与排布（排除法、计数、倒计时依赖它） | 箱内正好十件，上排五件、下排五件 |
| `action` | 谁对谁做了什么（因果的"经过"那一拍） | 反派把箱盖慢慢合上，推回主角面前 |
| `state` | 状态变成了什么（结果那一拍） | 断剑落在地上，主角袖口破开 |
| `loss` | 反派具体失去了什么（集纲"反派失去"格落到画面） | 三百万的支票被撕成两半 |
| `identity` | 谁是谁、谁在场（认错人会让整场读反） | 进门的是穿灰西装的课长，不是保安 |

- 写在 `shots.json` 的 `scenes[].must_show`：`{"id": "MS1", "fact": "箱内正好十件，上五下五", "shots": ["EP002-S05"], "kind": "count"}`；承担它的镜写 `"must_show_ids": ["MS1"]`（一镜可以承担几条，一条也可以由几镜分担）。`fact` 写成可数、可看的事实，不写"气氛紧张"。
- 来源：剧本每场 `[连续性]` 末尾的「必拍：」清单（screenplay §2b），加上集纲的"反派失去"和"兑现"两格。分镜不另外发明必拍事实；剧本没写的先回 C 补。
- **机械门**：scene 有 must_show 但没有任何镜的 `must_show_ids` 覆盖，或 `shots` 指向不存在的镜，报 G46 error；承担镜全部被删出 `cut_order` 也报 G46 error（删镜删掉了因果证据）；`kind: count` 的承担镜 `frame_prompt` 没写出事实里的数字，报 G47 warn。
- **不可妥协**：必拍事实在起始帧、视频、成片任何一层没成立，只能重拍、改分镜或回剧本改事实，不能靠"台词能解释""观众数不出来""延长镜头""补一句旁白或字幕"放行（production-and-review §5c）。

## 3. 轴线三行记账与左右唯一读法

每场在 `scenes[].axis` 写三行：

```text
轴线：遥 ↔ 三上（两人连线）
working side：摄影机常驻窗一侧
屏幕方向：遥固定占画面左、面朝画右；三上固定占画面右、面朝画左
```

- 左右按 video-prompts-general §2 的唯一口径：先用实物参照，不得已写 `screen-left` 并同句写人物朝向；禁止裸 left/right 和 `to his left` 一类人物相对方位；身体部位写 his left hand。
- 三人以上的场，"屏幕方向"一行逐人写全（含只有主角看得见的角色），与 `scene_state.characters` 一致（E34）。
- 越轴那一镜标 `axis_break` 并写理由，之后重新声明 working side。越轴本身不是错，没有动机又让空间读不懂才是；合法手段有：人物在同一镜内穿过轴线、中性过渡镜、用新的宽镜头重新建立方位，或导演有意制造主观错乱。
- 轴线要写成两个可命名锚点的连线；写 `<working side>` 这类占位等于没写。判据：换一个人来拍下一镜，只读这三行能不能把机位放对。
- 遥的镜头用窗一侧底板，三上的镜头用投影一侧底板；底板要写清画左画右各是什么（G19）。

## 4. 正反打配对

（单人正反打只用于不说话的反应镜或 §1 允许的单人台词镜。）单人正反打时，两人的空间关系只剩三条线索：屏幕位置、视线方向、机位高度。任何一条对不上，观众会读成两人在看同一个画外第三者。

- A 镜甲在画面左看向右，B 镜乙就在画面右看向左（`facing` 互补，G25）。
- 机位高度按身高差对应：拍高的一方略仰、拍矮的一方略俯；势均力敌用对称的高度与景别，不对称要有理由（压迫感）。
- 过肩镜：前景一个虚焦的肩或后脑（不露脸）可以作为第二人。正文写明前景是谁、他和画中人在发型服装上的区别、占画多少，并写 `exactly two people, each appears once`；前景人只挂他自己的身份图或不挂，绝不挂画中人的头肩图（E3：挂了会把画中人画两次）。同一镜两次多画人，改成两人并排一左一右。出拳用过肩镜。
- 同场同人朝向一致（G08）。
- **视线（G43）**：对话镜里说话人默认看着对手。正反打时视线方向和对手在画面上的位置一致——对手在画右，就看画右（`eyes on the tall boy off screen-right`），眼神略偏离镜头、不看镜头。说话镜在 shots.json 写 `gaze: {"target": "三上", "direction": "left"}`（direction 用画面方向 left / right，另有 camera / down / up）；`direction` 要和本镜 `facing` 一致，和对手在本场的 `facing` 相反（对手面朝画右、在画左，说话人就看画左）。独白、回避视线、盯着物件说话、直面观众是剧情需要时写 `gaze_reason`。起始帧提示词和视频提示词都要写出视线方向和对象（`eyes on the woman off screen-left`；视频里 `keeps looking toward screen left at the woman`），G43 会对账；风格句里的 `nobody looks at the camera` 保留。
- **同机位镜复用同一套起始帧写法**：正反打来回切时，同一场里人物、朝向、景别、机位高度都相同的镜头算同一机位。第二次及以后出现时，直接复用该机位第一次通过的镜的 `frame_prompt` 和 `frame_refs`，只改变化的那一项（表情、手、持物），不从头重写——每次重写都会让人物、背景、光一点点漂。与 §6"回溯、重复类镜头复刻原镜"同一个道理。同时写 `frame_parent: <原镜 ID>`（用父镜通过的起始帧图生图），写法见 [pipeline-contract.md](pipeline-contract.md) §4、G40。[社区][自测]

## 5. 起点 → 主动作 → 终点（边界链）

每镜优先一个可辨主动作；简单动作可一拍，复杂动作才拆起手、接触和收势。不为凑 2–3 拍添加无用动作。起始帧对应这段素材实际的开始状态。

每镜写一条可见状态链，终点必须能直接当下一镜的起点：

```jsonc
"boundary": {
  "start": {"position": "长桌桌角", "facing": "left", "gaze": "画左的三上", "hands": "右手握笔", "held": "笔", "state": "面无表情"},
  "end":   {"position": "长桌桌角", "facing": "left", "gaze": "画左的三上", "hands": "右手离开桌上的笔", "held": "无", "state": "下巴微抬"}
}
```

- 六个子项写**绝对事实**，不写"同上""保持不变""与上一镜相同"（G24）——图片模型逐张独立生成，看不到上一镜。
- 同场同主体的相邻镜头，前一镜 `end` 与后一镜 `start` 逐项比对（G26）；不一致就是镜外瞬移或道具凭空换手，要么补一镜要么改边界。
- 交接跨镜：物件在甲镜朝乙所在的屏幕一侧出画，在乙镜从对侧入画；写清谁→谁、怎么接、落在哪。
- 状态链"未知 ≠ 恢复默认"：湿发、伤、拿在手里的东西一直有效，直到剧本明确改变。
- 边界除了逐人姿态，还要写本镜依赖的**身体—物件—空间关系**（拄拐、被铐、背着人、抱着钱箱，visual-assets §5b）：镜内不变时起点终点都保留；要改变时，过程和终点必须有剧本依据。
- **争夺中的动态物件**（球、车、武器、证物、接力物）要把控制者、运动方向、所在区域带过切点：下一镜从上一镜结束的位置和方向继续，除非明确跳时或省略；比分、计时这类信息只在改变人物选择时出现，而且走后期叠加。
- 相对时间词（"后半段""最后 10 秒"）约束的是事件第一次被看见或听见的时刻：先用本集目标时长换成秒数边界再排镜，不因前置动作已完成就提前放出。

## 5b. 尾帧：什么时候可以有、换来什么代价

默认每镜只冻结一张起始帧。只有当前 `profiles` 的视频模型支持尾帧、而且这一镜的职责落在"收尾那一下"（坐定、落点、递交完成）时，才另写一张尾帧；尾帧提示词写法见 image-prompts.md §3.8。当前流水线没有尾帧字段时，按 video-prompts-general §7 把落点拆成下一镜的起始帧。

- **尾帧是 `boundary.end` 的投影，不是第二个终点**：它可以决定这一格怎么构图、光怎么落，不能决定人在哪、手里有什么、看着谁；和 `boundary.end` 不一致时错的是尾帧。
- **两帧各守各的边界**：起始帧不写终点才出现的事实，尾帧不写起点已经消耗掉的事实，两张不互相借用。
- **交出一对首尾帧，等于把中间的运动交给模型插值**：本镜存在的理由那个动作，不能只靠插值兑现——两端之间没有任何东西保证它发生；要么拆镜，要么让它落在其中一端。首尾帧适合"状态变化清楚、路径无所谓"的镜头（转身、坐下、递交完成），不适合"路径本身就是戏"的镜头。
- 视频提示词仍要写中间必须发生什么（动作顺序、台词落点、运镜），审片仍对照 `boundary.end` 判到没到，不拿尾帧自证。
- 起终状态相同，或变化发生在画外，就不需要尾帧。

## 6. 冻结关键帧配方

`keyframe`（中文）和 `frame_prompt`（英文）描述同一格画面，按顺序写：目的 → 焦点主体 → 画框（景别、机位高度、轴线哪侧）→ 在场名单（画内正好几人、逐人位置朝向；在场不入画的人在画外哪侧，video-prompts-general §2b）→ 地理（前中后景、入口方向、每人脚下或身下的实物、栏杆门崖沿的哪一侧）→ 边界投影（起点的位置、朝向、视线、手、持物）→ 表演瞬间（当前景别读得出的载体：视线、呼吸、姿态、持物方式，不写"愤怒"）→ 光（来源方向 + 受光结果）→ 文字（无）→ 排除（最多两句点名否定，§2b）。

- **首帧匹配本镜起点**：不能把尚未发生的结果画进去；“微笑转愤怒”的首帧可以微笑，承接上一镜已发生的动作也可以从中段开始。
- **首帧只写起点**：先与终点做差集，删掉本镜结果里才出现的事实（手已握住、门已开、字已亮）；出现"先、再、随后、最终"、表情从 A 到 B、推拉摇移、进出转身，都移到 motion。判据：一个静物摄影师能否一次拍下全部描述。
- **底板保留空间事实，允许改机位**：锁定门窗、楼梯上下、出口、尺度与主光的世界位置；镜头构图按本镜改变，不能只保留材质光线而丢失几何关系。
- **回溯、重复类镜头复刻原镜**：时间倒回、梦境重演、"一模一样地再来一次"的镜头，与原镜同机位、同景别、同姿势、同持物（直接复用原镜 `frame_prompt` 和底板，只改变化的那一项），观众才看得出"回到了那一刻"。同时写 `frame_parent: <原镜 ID>`，写法见 [pipeline-contract.md](pipeline-contract.md) §4、G40。
- 每个人都写身体朝向；印章字要放的一侧留空（构图偏另一侧，脑后留出空位）。
- 可渲染检查：每人位置与间距、前中后景、视觉重点、景别、机位、光源方向、每人姿态朝向手部持物——接手的人能否照着画出来而不用自己发明事实。
- 长短不设上限也不设目标，封闭清单（video-prompts-general §2b 表中适用于静帧的各行）一行不能少；起始帧提示词的顺序只有一套，就是 video-prompts-general §2b 二b 的静帧清单：镜头句（景别、机位高度、焦段，不写运动词）→ 人数排他句 → 逐人（名字 + drift_anchors、三方向位置、朝向、支撑、手、持物、表情档）→ 陈设清点与门窗开度 → 光句与不对称锚点 → 尺度锚点 → 参考图分工 → The scene is set … → 无字句与版式句 → Style: …；本文件其他地方的顺序以此为准，镜头句固定放第一句（§6b 正例和实战项目都是这样写的，顺序固定比长短更要紧；有 `frame_parent` 时，`The same shot as Picture 1…` 保留句放在镜头句之前）[社区][自测]（单人镜含单人固定句，多人镜写 `multi_person`、`exactly N` 和逐人位置朝向；都含 no text）。
- **陈设与门窗**：画内每类可数陈设写 `exactly N` 加三方向位置（左右、以镜头为准的前后、高度），末尾写同类排他句；门窗抽屉写可量开度；全部从 `scene_state` 的 `set`、`fixtures` 逐字翻译，同场各镜同一句（video-prompts-general §2b 陈设清点、位置、全程不变量三行，G54 L11–L13）。
- **尺度锚点**：中景、全景、全身、双人镜的起始帧必须写人物与一个环境参照物的关系（`the handrail reaches his waist`、`the door frame is about a head taller than him`、`each step is about ankle height`），多人同框写相对身高；参照值见 [visual-assets.md](visual-assets.md) §12，G34 查写了没有。
- 视觉依据在成稿后回填：从关键帧正文读出这一格里谁需要被认出；每个露脸入画的人 1 个人物条目（画外另注），前景只露背、肩、后脑的人不挂身份图（E3）。

## 6b. 提示词详细准确：逐项写全

以下每项都要写到。只有与参考图完全重复的外观描述可以省；第 0、3、4、5、5b 项不省——参考图不管人数、站位、朝向、支撑和归属。画外在场者默认不写（只记 `scene_state`），需要防他闯入时按第 0 项只写名字和方位、不写外观（video-prompts-general §2b 画外在场者一行）。

| 项 | 写什么 | 例 |
|---|---|---|
| 0 在场名单 | 画内正好几人、每人一次、各是谁；需要防闯入的画外在场者只写名字和哪侧；本场没有别人时写空无一人 | `Exactly two people, each appears once: Ren on screen-left, Mika on screen-right. Master Yan stands off screen-right and stays out of frame.` |
| 1 主体 | 谁、年龄体形、身高、服装锁 | `a slim Japanese high-school boy about 168 cm tall, mushroom haircut, white short-sleeved school shirt` |
| 2 动作（起点姿态） | 首帧那一刻身体在做什么（停在动作之前） | `standing still, weight on both feet, just about to turn his head` |
| 3 位置 | 在画面左右哪侧、前景中景后景、离参照物多远；脚下或身下是什么实物；有栏杆、门、玻璃、崖沿时在哪一侧 | `on screen-left in the midground, one step in front of the top stair`；`outside the bars, in the corridor` |
| 4 朝向 | 身体和脸朝哪（画面左右）、视线看哪 | `body turned three-quarters toward screen-right, eyes on the tall boy off screen-right` |
| 5 持物 | 握持四要素：哪只手、握法（握柄 / 拇指食指捏住 / 掌心平按）、拇指在哪一侧、物件和手掌或躯干比多大；不表演的手也交代放在哪（插兜、垂在身侧、在画框下沿以外）[社区] | `his right hand grips the handle of the metal cash box from below, thumb on the near side, the box about 30 cm wide, as wide as his torso; his left hand rests flat on the lid` |
| 5b 数量与归属 | 关键道具写 `one single` 或 `exactly N`、在谁哪只手或放在哪个实物上；已被拿走的不在原处再画一件；每只可见的手都连着看得见的身体，或写明从画框哪条边伸入 | `one single rusty sword in Gu's right hand; the crack in the rock behind him is empty` |
| 6 表情 | 可见的肌肉状态（不写形容词） | `lips pressed tight, brows drawn together, eyes clearly visible under the fringe` |
| 7 光 | 主光来源、方向、色温，再补一句画面上的受光结果：哪侧亮、哪侧暗、眼睛能否看清 [社区] | `soft daylight from the corridor windows on screen-right; the right side of his face is brighter, the left cheek falls into soft shadow, both eyes still readable` |
| 8 镜头 | 景别、机位高度、焦段（焦段类词按画风换，见下） | `medium shot at eye level, 35mm, shallow depth of field` |
| 9 环境与尺度 | 背景里有什么、空间方向、尺度锚点 | `behind him the stairs go down to the floor below; the metal handrail reaches his waist` |
| 10 环境动态（可选） | 自然存在或承担情节的环境变化；无需为了有动态添加人或物 | 风确实吹动门帘时才描述 |

补充说明：
- **手**：每人看得见的手最多两只，而且都要有事可做；写手"在做什么、握着什么"，比写"五根手指"更能让模型画对（物件本身给手指定了形状）。[社区]
- **光**：只写光位时模型常把亮面放错侧，补上受光结果更稳（小样本图片对照，未测视频）；身份图、底板的均匀照明只为看清形制，不是本镜的打光方案。同一场维持光源关系，亮度小偏差交给剪辑调色。[社区]
- **镜头词按画风换**（第 8 项）：真人与 `cg_realistic` 用焦段和浅景深（`35mm / 50mm / 85mm, shallow depth of field`）；`anime_cel` 不写焦段、bokeh、cinematic lighting、volumetric、4k，改写成 `medium shot at eye level, flat 2D framing, background painted softly out of focus`；`manhwa` 写 `chest-up portrait framing, softly blurred glowing background`；`guoman_3d` 可写 `virtual camera, 35mm equivalent`，但不写 photograph、film grain。摄影和渲染类词会把 2D 画面往 3D、真人方向拉（[styles.md](styles.md)）。[社区]

**反例**（EP001 实际写法的简化）：

```text
The boy stands on the stairs holding the cash box, worried. The scene is set in a school stairwell. Keep the stairwell exactly as it is.
```

问题：没写身高和尺度（出图后人和护栏一样高）；没写画面哪侧、朝哪；"on the stairs"没说楼梯往上还是往下（出图台阶方向与剧情相反）；`worried` 是形容词；"keep … exactly"让模型为保底板把人缩小；没有光和镜头。

**正例**（不说话的反应镜；台词镜默认用 §9 双人模板，单人对白按 §1 提供并核验空间关系）：

```text
Medium shot at eye level, 35mm, shallow depth of field. A slim Japanese high-school boy about 168 cm tall with a mushroom haircut, white short-sleeved school shirt, stands on screen-left in the midground, one step in front of the top of a staircase that goes down to the floor below behind him; the metal handrail beside him reaches his waist. His body is turned three-quarters toward screen-right, eyes on the tall boy off screen-right, eyes clearly visible under the fringe. He hugs a metal cash box about 30 cm wide against his chest with both arms, lips pressed tight, brows drawn together. Flat white daylight from the corridor windows on screen-right; the right side of his face is brighter, both eyes still readable. Picture 1 anchors the stairwell geometry, descending stairs, materials and world-space window position; camera framing follows this description. Picture 2 sets only his identity. Only one person in the frame; the tall boy stands off screen-right, out of frame, and the stairwell is otherwise empty. Style: …, no text.
```

提交前自问三句：①只看提示词，能不能画出一张位置、朝向、持物、尺度都确定的图？②有没有哪一项靠形容词（worried、epic、beautiful）？③空间方向（上楼/下楼、画左/画右）有没有写死？

**道具布局镜：数量和排布写进起始帧**（承担 `kind: count` 必拍事实的镜，以及排除法、摆阵、清点这类镜）：
- `frame_prompt` 里把数量和排布写成绝对事实：`exactly ten small lacquer boxes in two rows, five on the top row and five on the bottom row, evenly spaced`；不写 "several / a row of"。数量超过 6 的分成几组写（每排几个），模型对"分组 + 每组数量"比对总数更稳。[推断]
- 写清尺度：每件多大、和手掌或箱体比多大（`each box about the size of a palm, the case about 60 cm wide`），否则模型会多塞或缩小。
- **起始帧目检逐个数**：用看图工具放大那块区域，按排逐个数，结果写进目检记录（`计数：上 5 / 下 5 = 10 ✓`）；数不对就 `--retake` 或改构图（减少件数、分成两个插入镜），不带着错数进视频。视频接触表的第一格和最后一格再各数一次，防止运动中多出或少掉。

**物件按真实比例生成**（人和物件同框的每一镜都适用）：图片和视频模型会按"重要性"缩放物件——剧情道具被画大（手机像平板、匕首像短剑、戒指像手镯），背景小物被画小，同一件东西跨镜忽大忽小。写法：
- 每个和人同框的关键物件写两样：真实尺寸（厘米）加一个身体部位对照。例：`a smartphone about 15 cm long, a little shorter than her hand from wrist to fingertip`；`a folding knife with a blade about 8 cm long, about the length of his index finger`。对照只写一个，写最近、最常入画的那个身体部位。
- 常用人体参照（成年人）：头高约 23 cm，手掌宽约 8–9 cm，手从腕到指尖约 18–19 cm，食指约 7–8 cm，前臂约 25–28 cm，肩宽约 40–45 cm，腰高约 100 cm。儿童、角色设定身高不同时按比例换算，不照搬成人数。
- 家具和门窗类大件按 [image-prompts.md](image-prompts.md) 底板的尺度规则走；这里管的是人手里、身上、身边的物件。
- 同一件物件全集用同一句尺寸短语（L26 的固定短语）；视频正文里再写一次，模型不会从起始帧记住尺寸。
- 目检时把物件和最近的身体部位对着量：手机不能比脸长，钥匙不能比手掌长，茶杯口不能比脸宽。比例明显不对就重出，不带进视频。

**跨镜出现但未建档的小物件用轻量锁**：笔、杯子、外套、包这类没进道具建档、但在两个以上镜头出现的物件，第一次出现时定一句英文短语（颜色 + 材质 + 尺寸），此后每镜的 `frame_prompt` 和视频正文逐字复用同一句，并在阶段报告里列出这些物件。不定短语的话，模型每镜各画一个版本。（取自 zenstory-ai/drama-skills）

**删句测试**（只对静帧清单以外的句子做；清单行和必备句不参与，video-prompts-general §2b 二b）：删掉任意一句，如果画面没有因此变得更不确定，那句就是多的（连接词、铺垫、换个说法重说一遍）。一件事只说一次。与上一镜相同的部分也要写成绝对事实，不写"同上""与上一镜相同"（G24；图片模型逐张独立生成，看不到上一镜）。

**收尾固定一句版式声明**：`A single clean full-bleed frame: no borders, no panel dividers, no labels, no text, no watermark.` 起始帧挂着身份板、转面板裁格或白底道具图时，模型会模仿参考图里的分隔线和多格版式，这句用正面描述先封住版式；它只管版式，不替代 V01 目检。（取自 shuohao-skills）

## 6c. 写完回填参考图、反向核对起点

**frame_refs 按成稿正文回填**：起始帧提示词写完后，才知道这一格里到底有谁、有什么。从成稿正文读出需要认出身份、造型或地理的人物、地点、道具，再选 `frame_refs`：
- 后景里只露一双模糊眼睛、但观众要认出是谁的人，也在列；画外人声、认不出身份的局部不在列。
- `controls` 只写这一格承担得起的范围：手背特写不需要全身造型，只露屏幕和一根手指的镜头不需要体形；上一镜绑过的参考不因为"人还在这场戏里"就顺延到下一镜。
- **按画面内容逐项清点，不是只挂"这一场的底板"**：这一帧里看得见的每个人物、每件叙事道具、每个大型资产（车、船、宅门、招牌建筑、机甲）有参考就挂。场景在栈桥上、画面里出现渡船，不挂渡船参考，每一帧都会画出一条新船；大型资产还没有参考图的，先回 visual-assets 补建。（取自 shuohao-skills）
- 跨镜要一致、但视觉设定里还没有条目的物件（四镜都出现的一支笔、一件外套），逐镜用完全相同的英文短语写死，并在本轮报告里点名，交 art-director 补条目和参考图；不把它塞进已有条目冒充。
- 缺参考图就等参考图出好，不静默降级成文生（visual-assets §10）；用户明确说这一镜不用参考图时才写进决策记录后改走文生。

**反向核对起点**：写完 `frame_prompt` 后，从英文正文里反向摘出每个人的手位、持物、视线、可见状态，和 `boundary.start` 逐项比一次；只看中文 `keyframe` 或字段说明、不看真正提交的英文正文，漂移会漏掉。反例：`boundary.start` 是"右手空着、看对方"，终点是"右手握铃绳、看门"，起始帧写成"手已握住铃绳"——好看，但越界了。

**坐标与状态只认一份当前账**：接触戏先把每个人、手、可移动道具在动作前、中、后的点位和归属排成同一张状态表，再从它写视觉设定、`boundary`、`keyframe`、`frame_prompt` 与 `video_prompt`。提交前反查同一状态是否有两套点位、道具起点是否真的在承载物内部、终点是否与下一镜一致；出现冲突就先修状态表，不挑一套顺眼的数字写进提示词。

**静态够及不等于动作可完成**：必拍的推、抛、滑、滚、抓等动作还要核起点、接触全程、离手后的运动距离、接触材质与障碍物。若结果必须靠一段未经证实的长距离滑行或凭空补帧才成立，先调人物与道具位置、改变拍法或回分镜；视频提示词只能描述已经物理可行的路径，不能用终点句代替过程证据。实拍前仍记未验证，出视频后逐帧核动作和落点。

**表演瞬间跟着剧本情绪走**：台词的 `emotion` 是唯一情绪来源，起始帧的表情肌肉、姿态和视频提示词的语气都从它投影；剧本写"压着嗓子"，起始帧写下颌收紧、身体不前倾，不升级成"低吼"。认为情绪不成立就回剧本改 `emotion`，不在分镜和视频提示词里各写一个。情绪也不自动决定景别。

## 6d. 风格化画风的关键帧：事实 → 画风投影 → 可读性约束

日漫、韩漫、国漫等画风（styles.md）写起始帧时分三层，顺序固定，画风词不能顶替事实：

1. **场景与主体事实**：§6、§6b 的全部内容（谁、在哪、起点姿态、构图、机位、光、尺度）。
2. **画风投影**：`drama.json` 的 `style` 句加本镜需要的局部变化（冷暖分区、局部高反差、背景降对比）。全剧用同一套画风基底，单镜不换。
3. **可读性约束**：只写本帧确实可能丢的信息——雨幕遮脸、暗部吞掉持物、特效粒子盖住身份锚点、武器和肢体轮廓粘连、前后层特效的遮挡关系。写不出具体风险就不加；不给每帧挂一长串防畸变禁词。

按镜头类型选词：
- **叙事关键帧**（转向、揭示、场尾落点）：强透视、前景遮挡、重心偏置，只在它们承担压力或揭示时用。
- **对话镜**：半身构图、肩后前景、柔和侧光、背景降对比；风险集中在脸、视线、持物和背景抢注意。
- **动作/特效帧**：冻结帧里可见的处理（方向性拖影、流光残迹、碎片定格、冲击点形变）停在一个边界瞬间，不写动作过程。特效体系按题材只选一系（仙侠剑气/水墨飞白、赛博能量束/霓虹光刃、魔法辉光/冰晶、火焰/火花/电弧/沙尘），不为热闹混用。

"动态张力""电影运镜感"不进关键帧；镜头类型名（叙事关键帧、对话镜）只是选词入口，不写进正文。

## 7. 景别、切点、节奏

- 景别由"必须读到的信息在哪个尺度"决定，不是情绪越强越近；憋屈段守在中近景/过肩，底牌与反击才进近景、大特写。说话、表情镜的下限是中近景（脸高 ≥ 画高 1/5，见 §1）。必拍事实（`kind: count`、`action`）和关键动作不能只由人物身高小于画高 1/6、关键物件长边小于画高 1/8 的镜承担：远景只建空间和站位，动作和数量交给下一镜的中景或插入镜（video-prompts-general §2b 可见性一行，E34）。
- 一场先宽一档定位，再在工作景别上下一格来回（中景 ↔ 中近景 ↔ 近景 ↔ 特写）；不先给空景全景；切点必须带来可见变化（景别、角度、主体至少改一项；同景别同主体跳切是 AI 剪辑感，G27）。
- 深浅相间、长短相间，避免"均匀病"；但不切得太碎（§7c 下限），同一个人的连续戏用长镜头（§7b）。
- **反应镜头是免费的戏**：重台词之后切听者的脸 2–3 秒，不需要台词——最便宜的快节奏手段（不说话的反应镜可以单人，§1）。但用户要"台词多、反应快"：反应镜里听者也可以有一句短反应（当场出声），不留空拍。
- 每集第一切要有主体在动（冷开场认领）；关键动作单独成切给一个 2 秒插入特写作重音；段尾留钩。
- 动接动：切点选在动作中间；上一镜的推近或动作不在下一镜重来。

## 7b. 长镜头：同一个人不拆两个镜头

用户原话："如果是同一个人的话就不要弄两个镜头，直接选择生成一个 10 秒或者合适的长镜头。"每次切镜，生成模型都要重新猜一遍脸、光和背景，同一个人切两次就多一次漂移；台词和动作也会被切点截断。

- **默认合并**：同一场里，相邻两个镜头主体是同一个人，中间没有别人的镜头或插入特写，就合并成一个长镜头生成。一个人连续做事（放下杯子→抬头→开口）、连续说两句，都在同一个长镜头里完成。时长按内容定（常见 8–10 秒），上限取 `drama.json` 的 `shot_seconds.max`（H3 `duration` 4–15 整数秒，模板默认 15）。
- **只有这几种情况才拆**：景别、机位明显变化（全景交代位置之后切特写强调物件）；剧情需要（插入对方反应、插入物件特写、揭示）；时间跳跃。拆开时在后一镜写 `split_reason`，说清楚为什么必须拆。G45 查相邻同人镜没写 `split_reason` 的情况。
- 合并后按长镜头写视频提示词：几个动作节拍、几句台词、运镜变化怎么排，见 [video-prompts-general.md](video-prompts-general.md) §3b。
- 合并后秒数超过 `shot_seconds.max` 的，先删同质节拍（重复的反应、重复的强调），再考虑在剧情转折处拆开并写 `split_reason`。
- 正反打来回切（甲说—乙说—甲说）不算同一个人相邻，照常拆；甲的反应插在乙的两句之间时，乙的两句就是两个镜头。
- 长镜头里要有东西在变：一镜里有景别或视点的实际变化（缓推、跟移），或一次完整的动作与反应交接；十几秒只有同一张脸同一个构图，观众读到的是幻灯片。镜内变化照样写进 motion。
- 一张起始帧只描述了镜头开头；镜头越长，后面越依赖视频提示词把节拍写清（video-prompts-general §3b）。

## 7c. 节奏下限：不切得太碎

用户原话："拍摄镜头切换太快。"EP001 成片 26 镜 78.7 秒，好几镜只有 1–2 秒，台词没说完就切、动作没看清就走。节奏只设下限，不设上限（长镜头按 §7b）：

| 镜头 | 成片取用下限 | 说明 |
|---|---|---|
| 对白镜 | 台词说完 + 0.8 秒，且不短于 2.5 秒 | 一句完整台词在一个镜头里说完，不在句中切 |
| 反应镜 | 1.5 秒 | 看得清表情变化 |
| 插入特写 / 冲击剪辑 | 可短于 1.5 秒 | 必须在 shots.json 写 `fast_cut_reason`（"冲击剪辑：拳头命中那一帧"） |
| 同一场的平均镜长 | ≥ 2.5 秒 | 平均值太低 = 切得太碎，先合并同一人的相邻镜 |

- 参数在 `drama.json` 的 `pace`（`dialogue_min` 2.5、`dialogue_tail` 0.8、`reaction_min` 1.5、`insert_min` 1.5、`scene_avg_min` 2.5）。
- 分镜阶段：G42 查计划取用（motion/duty/continuity 里写的"取用约 X 秒"；没写就按整条 `seconds`）是否低于下限、同场平均是否过低。剪辑阶段：cut.py 在剪辑单里逐镜标"过短"、给出同场平均镜长（edit-and-delivery §2）。

## 7d. 景别词表、机位三栏、摄影机行为

**景别**按"必须读到的信息在哪个尺度"选：
- **远景**：地理、人与环境的力量对比、人被空间吞没；靠轮廓、方位、距离读，不承担表情。
- **全景**：建立空间、孤立感、群体权力、同时发生的后果。
- **中景**：互动、手势、双人策略、调度。
- **中近景**：对话距离的单人、仍保留手部；一场停在工作景别时的对切多落在这一档。
- **近景**：决定、证据、被藏住的反应、无法撤回的认识。
- **特写**：一张脸、一只手、一处伤成为本镜唯一事实；代价是暂时切掉空间参照。
- **大特写**：只留眼睛、嘴、指节或物件上的一处细节；要有"非看不可"的理由。
- **插入/细节镜**：已经建立意义的关键物件或动作（`kind: object/hands/feet`）。

近景、特写是常用档，不是留给高潮的稀缺资源；要防的是把景别当情绪音量旋钮（情绪一升级就收紧，本镜到底要观众读到什么没人回答）。

**竖屏收窄了可用景别**：9:16 的横向只有 16:9 的三分之一强，远景、全景靠横向铺开的信息（谁站在谁旁边、离出口多远）会挤成一条或小到读不出。竖屏交代空间靠**纵深**：前景、中景、后景分层，用门框、桌沿、台阶、人的前后遮挡立关系；做不到就别让全景承担交代空间，改用一个更近的镜头单独交代一次。横屏项目照常用。

**建立镜头要自己挣到位置**：快节奏短剧默认地理在动作里到达（人物已经在做的事、说的话带出空间），不先给空景全景（§7）。交代空间的镜头只在两种情况成立：空间事实本身承担因果（距离决定来不来得及、出口决定能不能走、谁站在门口决定谁看见），或后面镜头的方位判断依赖它而动作本身给不出。成立时也优先带着人物和动作的取景，一镜完成两件事。

**机位写三栏，互不推导**：

| 维度 | 词表 | 回答什么 | 写在哪 |
|---|---|---|---|
| 水平角度 | 正面 / 斜侧（四分之三）/ 正侧 / 后斜侧 / 背面 | 观众能读到多少表情、站在谁一侧 | `framing`，并写在轴线哪一侧 |
| 机位高度 | 地平 / 低（仰）/ 平视 / 高（俯）/ 顶视 | 这一刻谁大于谁；平视是主动选择"势均力敌"，不是没选 | `framing` |
| 焦段意图 | 广 / 标准 / 长（压缩纵深、隔离主体） | 人与人的距离显得更远还是更近 | `frame_prompt` 的镜头句（真人画风写 mm，2D 画风按 §6b 第 8 项换词） |

- 仰拍不等于正面：从背后仰拍是"跟在他身后、他在变大"，从正面仰拍是"他压向我们"。写"俯拍"时先确认想要的是不是其实是"从她背后越过肩膀"（那是水平角度）。
- 长焦不等于特写：长焦拍全景会把纵深压平，"隔着半个房间对峙"会被拍成"面对面"。
- 竖屏里高度变化比横屏更贵：纵向本来就长，俯仰会迅速吃掉人物所在的高度，同样的俯角读起来更强。要表达权力，先看水平角度和距离能不能承担，再动高度。

**摄影机行为要有动机**，一个时间段内选一套：固定（观察、紧张、仪式、受困）；摇/俯仰（揭示信息、转移注意）；推/拉（改变亲近、压力或认识）；跟（移动本身带策略）；环绕（关系或空间在原地被重新评估，没有这层理由就是装饰）；升降（高度本身有意义，不为"开场要大气"）；手持（导演已选定的身体不稳或现场感）。同一段里不同时要求固定和移动；甩镜、荷兰角、变焦推拉是点睛手段，只在视角、失衡或注意力突然改变时用。运镜写进 motion，不进起始帧。

**一场的景别走法**：比本场真正要演的景别先开宽一档，第二镜落到工作景别，之后在工作景别上下一格来回；宽景和特写是离开工作景别的标记事件，用过就回来，场尾略放开是常见收法。例：客厅摊牌，第 1 镜全景交代谁堵着门，第 2 镜落中景，之后中景与中近景对切，只在她把信封推过茶几时切一次特写，随即回中近景，场尾退回中景。一路单调收紧的场次到中段就没有余量了。

## 7e. 对白估时

先排完整的声音事件，再定镜长；不先定一个短镜长再让人物加快语速塞台词（G04 按 `speech_rates` 估时是下限检查，不替代这一步）。

- 有同一句、同语言、同表演方式的配音时，用实际发声区间；把文件首尾静默和句内停顿分开，不把整个文件长度当说话时间。没有音频时按原文、人物语速、`emotion` 和换气估一个区间，标明"文本估计"。数字、缩写按实际读法算。
- 顺序说话的多句、多人对白累加，句间停顿与听者反应按顺序加入；能并行的动作（边说边抬眼）和对白共用时间，必须等话说完才发生的动作另占时间。
- 在 `motion` 或 `duty` 里简写依据，例如"对白按克制语气文本估计 8–10 秒（含句内停顿）；开口前 0.5 秒，说完后反应 1 秒；抬眼与对白并行"——按上沿需要 11.5 秒，H3 取整到 12 秒，余下 0.5 秒停在终点。数字是本例的预算，不是统一余量。
- 超过 `shot_seconds.max` 时按语义和可见状态的闭合点拆镜（写 `split_reason`，G45），并看整集总时长（G14）；放不下时回剧本删同质台词或拆集，不擅自删词、不把正常对白改成快读。
- 估计只是规划依据；生成后仍要听完整性、语速和尾音（production-and-review）。

## 8. 信息顺序：底牌、反应优先、承受者

- 分镜先安排信息再安排景别：什么时候让观众知道底牌，什么时候让反派知道，什么时候看他的反应。爽剧默认观众先于反派看见底牌。
- 事件靠画外声、视线、物体响应证明，镜头留给反应的人；不为证明每个名词切到手机、把手、脚印。底牌实物要看清时给插入镜，信息靠台词说出来，不靠可读文字。
- 打击、否定、翻盘要让观众看到后果被谁接住：反派失去控制、证据被确认、利益真的拿回来，各自有镜头；反应镜放在事实落地之后。
- 每个揭示事实写清：现在给还是扣住、何时释放、靠什么保护（逆光剪影保护身份时不改光源方向）。
  - 一个事实写一条：依据剧本哪一场；现在展示还是暂时扣住；靠什么看得见或听得见；什么动作、台词或切点允许释放；用什么保护（背影、只露腿的入场、门缝、前景遮挡、延迟对焦、逆光成剪影或压暗到只剩轮廓）。同一镜里的不同事实可以在不同时间放出。
  - 用光保护身份时不改光源的身份和方向，只写人物落在明区还是暗区，并在本镜 `frame_prompt` 的排除项里写明（`his face stays in shadow, only his silhouette is readable`），否则模型会直接给一张清晰正脸。
  - 反过来，本镜负责交付的证据或听者的关键反应，不能为了画面好看被遮住。神秘感不是默认加分项。
- **承受者的反应不强制单独一镜**：独立反应镜、双人镜里的调度、清楚的群像反应、声音、物件状态都可以承载后果；现有画面已经清楚就不补镜。审查按"后果能不能被理解"判，不按反应镜数量判。
- **交付面遮挡**：成片的字幕条、系统面板、印章字位置由剪辑决定（edit-and-delivery §4）；本镜必须被读到的东西（脸与视线、决定性的手部动作、证物）不能只落在字幕条或面板区域里。发布平台的播放控件、角标区只有在决策记录里写明了占用位置时才避让，不凭猜测给每镜加通用安全框。

## 8b. 按戏型问问题

写镜头前，按这场戏的类型先回答下面的问题；答案决定哪里切镜、哪里停住，不按戏型套固定景别：

- **对峙戏**：双方的议程和筹码是什么？哪一次行动真正改变了距离、证据、关系或退路？谁必须接住这个改变？只有这些转向需要新镜头。
- **动作戏**：观众必须看懂哪条路径、哪次接触、什么结果？先保证地理和道具归属，再决定一镜保持、按起势/接触/结果拆，还是切反应。
- **情绪戏**：触发是什么，人物怎样看得见地处理它，它促成或压住了什么选择？沉默、手部、距离和不切镜都能承载，不把情绪名自动配到特写或推镜。
- **悬疑/恐怖**：观众、角色、威胁各自知道什么？什么现在给、什么扣住、由什么画面或声音释放？遮挡既不能提前泄底，也不能藏掉本镜负责交付的证据。
- **喜剧**：铺垫、误读和纠正分别由谁看到？笑点来自节奏、同框并存还是切换？不让反应镜去解释已经成立的笑点。
- **保持不动也可以是表演**：威胁落下后角色拒绝给对方反应，稳定的视线和有意固定的机位就是人物策略；不为"情绪必须变化"硬加吞咽、握拳这类无来源的小动作。

## 8c. 表演设计：承接对方行为 → 改变局面

外部审查实例：六集里 180 个人物镜有 165 镜带对白，加上反复解释能力的段落，成片读成"人物轮流说明情况"。对白多本身不是错，错在台词之外没有人接住对方做的事。

- **写 motion 先写"接住"**：本镜人物对上一镜对方的行为（一句话、一个动作、一件证据）做出什么可见的回应——夺过、合上、推回、后退、笑容僵住、别过脸、把笔放下——再写台词在这个动作的哪一刻说出。只写"开口说台词、说完看着对方"的镜，是在说明情况，不是在演戏。
- **表演设计写动作，不写台词复述**：设计要"笑僵住、慢慢合箱、认输"，motion 就写成三拍动作链（笑容停住 → 双手按住箱盖慢慢合上 → 把箱子推回），起始帧停在箱子还开着、笑容还在的那一刻，`must_show` 登记"合箱认输"（kind: action），审片按它逐拍核对。
- **改变局面**：这一拍之后谁多了一个筹码、谁退了一步、谁失去了什么；说不出变化的镜，合并进相邻镜或删掉。
- **能力规则讲清之后只提醒**：规则在画面或台词里讲清一次后，后面只允许一句话的提醒；新角色确认能力 ≤1 句；跨集回顾 ≤5 秒（screenplay §5b3）。承担解释或确认能力规则的镜写 `"explains_ability": true`。
- **机械门**：G48 同集 `explains_ability` 镜超过 2 镜或计划取用合计超过 12 秒、第二集起开头 30 秒内超过 1 镜报 warn；G49 同场有台词的人物镜 ≥3 个且一半以上 motion 里没有承接对方行为的动作或反应词，报 warn。阈值在 `drama.json` 的 `gate_limits`（`ability_explain_shots`、`ability_explain_seconds`、`recap_window`、`recap_explain_shots`、`talk_only_ratio`、`talk_only_min_shots`）。G49 只看有没有写动作词，写得对不对由 reviewer 按 review-checklists §E2 判；"保持不动也是表演"（§8b）的镜写 `waive: ["G49"]` 并在决策记录里写理由。
- **姿势自带身份含义**：双手交叠在腰前、拱手、垂手侍立，在画面上读作"等候吩咐"，只有剧情里此刻确实如此才写；人物文静、年轻、是女性都不构成理由。没有特定意图时，写这个人自己的习惯动作（按着文件、负手、单手撑桌、摆弄随身物）。（取自 shuohao-skills）

## 9. 接触动作与插入镜

- 接触前后状态要清楚；接触可双人同框或手部特写，也可按叙事有意省略，但观众必须能确认事件发生。
- 出拳：过肩镜，命中帧起震屏；挨打后接踉跄撞物；不拍两张脸同框互殴。
- 递物、抢物：交接那一下双人同框（过肩或侧面双人中景，两人的手和物件都在画内）；前后需要细节时，再补持有者的手出画（朝对方所在一侧）或接收者的手入画（从对侧）。不让物件在两人手里各出现一次。
- 落点必须精确的接触（撞到台阶边、坐倒、物件落在指定位置），目标模型支持尾帧时用尾帧锁落点，否则把落点拆成下一镜的起始帧（video-prompts-general §7）。
- **双人接触镜的起始帧写法（三图分工）**：参考图最多 3 张——甲的身份、乙的身份、底板（顺序按 visual-assets §7 的 A/B 结论，没测前沿用"底板在前"并相应改 Picture 编号）；道具不再单独挂图，尺寸材质写进正文。每人用"名字 + 一条最显眼的外观"称呼（`Ren, the tall boy in the black T-shirt`），不用 he/she；写明谁在画左、谁在画右、各自朝向、身高差；起始帧停在接触之前（谁的哪只手在哪、离对方多远）；最后写"每人只出现一次、画面里正好两个人"。[官方][社区]

  ```text
  [景别, 机位高度, 焦段]. [甲名], the [甲最显眼的外观], stands on screen-left, [朝向]; [乙名], the [乙最显眼的外观], stands on screen-right, [朝向]; [乙名] is about [N] cm taller, [甲名]'s eyes are level with [乙名]'s chin. [接触前一刻：谁的哪只手在哪里、两人相距多远]. Picture 1 is the real place where this happens, not a flat backdrop: both people stand on its solid ground; keep its layout, edges and landmarks; camera position and framing follow this description; do not copy any person from it. Picture 2 sets only [甲名]'s identity and Picture 3 sets only [乙名]'s identity: keep their faces, hairlines and builds; poses and framing follow this description. Each person appears exactly once; exactly two people in the frame. [尺度锚点句]. The scene is set … Style: …, no text.
  ```
- 插入镜（`kind: hands/feet/object`）不写单人固定句，但仍写 no text、写清画左画右；手的数量写死，每只手写明是谁的、从画框哪条边伸入、主人在画外哪侧（`Gu's own right hand enters from the bottom-left edge; his body is just outside the frame on screen-left`，E35）。

## 9b. 复杂调度：竖屏多人、单房对白、证据揭示、群体、动态对象

这些是思考步骤，不是镜头数量模板；对话对象必须可辨，默认听者入画，单人对白按 §1 验证；接触归属与因果仍须清楚。

**竖屏多人**：先画出人能怎样通行，再决定纵向画幅怎样表现关系。用前中后景、门框、台阶、桌沿建立深度；写清谁能接近证据、出口或权力位置；头像高低只在空间真实且有意义时表达地位；两人对话时仍留出第三人监听、反应或阻挡的位置（在全景或过肩前景里）。设计顺序：空间锚点与入口 → 每人的目标和筹码 → 群体注意中心 → 关键动作前后的站位 → 哪些同时反应必须留在宽镜里 → 只有丢信息时才切插入或近景。常见问题：站位只为填满画面；背景人物切镜后无故换边；重要人物一直被前景挡住而剧情并没利用这种遮挡。

**单房对白**：运动来自人物策略、物件和注意变化，不来自无理由走动。先列会造成压力的空间关系：出口、座位、桌面或证物、会增加时间压力的声源（电话、电梯）；谁先占据哪个位置；谁能碰、打开、藏起或拒绝某件物。每一轮按"说话或沉默的策略 → 对方怎样接住或拒绝 → 物件、视线或空间发生什么 → 谁暂时掌权"检查。反应不必总拍脸：不碰纸袋、把钥匙推过边界、手从门把上移开也是反应。不为"画面丰富"让人物轮流起身、倒水、看窗。

**证据揭示**：先写清观众知道了什么，再选镜头：证据在哪、谁控制；揭示前观众能读到什么；构成证据的是形状、状态、文字，还是人和物的关系；谁先看见，谁又看见对方已经看见；得知后哪个行动变了。证据是文字时，文字走后期叠加，镜头给足停留（§7c 插入镜下限）让观众读完，不用一闪而过的插入镜假装观众读到了；证据只是纹样或断角时，提示词不临时造字。

**群体与轴线**：按作用分区，不给每个人单建一条轴线——主行动者与对手的主轴、见证者或队列所在区、入口/出口与权力位置、群体注意方向的变化。公开揭示或家庭冲突里，再按行动能力分知情者、能拍板的人、利益相关者、普通旁观者；只有新事实改变了某组人能做什么，才给这组人新动作（作证、拦住、让路、退出、保持沉默）。不让所有人轮流说同一种惊叹，也不把每个背景人物都建成资产（visual-assets §1b）。

**多人关系投影**：多人对峙先写一行有方向的关系——此刻谁保护、协作、施压、观察谁，由哪个剧本动作或信息状态支持——再翻成站位、身体朝向、视线、距离和行动线。关系只对本镜有效；同一人物可以在剧情转向后换边，但一格画面里不能既和甲背靠背结盟、又从对立行动线朝甲施压，除非本镜就是表现转向的那一刻。写完逐句核对人物、持物和阵营，避免提示词把同一个人写进两个互斥位置。

**动态物件与竞赛**：球、车辆、武器、证物、争夺中的工具会把控制权带过切点。设计前写清当前时间/回合、区域、控制者、运动方向、目标路线和可用反制（不适用的省略，不为填表编数据）。一次关键行动要让观众看懂：从什么可见状态开始、控制权怎样被争夺或转移、方向或战术为何改变、结束时物件和人分别在哪。慢动作、特写、欢呼不能替代丢失的空间阶段；对手的战术调整要能追溯到此前看见的信息，不每轮重置成同一站位。

**观察方向要对得上底板**：镜头在门外朝内拍，就不能绑门内朝外的底板，即使"还是同一扇门"。选底板前逐项比机位所在一侧、可见锚点、朝向、时段、天气和光；没有合适的就请 art-director 派生新底板（visual-assets §4），不带着错的方向拍。

## 10. 门与自检

机械门：G46 必拍事实有镜承担（error）；G47 数量事实写进起始帧；G48 能力规则重复解释；G49 场内对白镜只说不做；G42 节奏下限；G43 说话人视线；G44 台词语种与读音；G45 同一人相邻镜没写 `split_reason`；G32 `requires_setup` 的铺垫镜存在且在前（事件镜没写起因也提示）；G34 尺度锚点；G35 环境动态；G02 起始帧含画内人数句（单人固定句或 exactly N，multi_person 镜必须 exactly N）；G53 台词镜听者入画（单人要 `single_reason`）；G52 恶意执行预演 `adversarial_preflight`；G08 同场同人朝向一致；G23 锁面逐字进起始帧提示词；G24 关键帧/终点/提示词无回指词；G25 同场两人朝向互补；G26 边界链逐项一致；G27 同景别同主体跳切；G13 关键帧长度。

例外理由（`single_reason`、`multi_person_reason`、`split_reason`、`gaze_reason`、`fast_cut_reason`、`axis_break`）按 video-prompts-general §2b 过搬家测试。

reviewer 的必答问题统一在 [review-checklists.md](review-checklists.md) §E（E1 一眼看懂与覆盖、E2 职责视线与节奏、E3 起始帧、E4 视频提示词、E5 风格与连续性），按其 §0 的分级与格式写 finding（镜头 ID、证据、影响、必须达到的修订结果）。实际 take 按 quality-contract.md 看图听审，不以提示词写全代替。

## 10b. 镜头修订与 ID

镜头 ID 代表同一个导演决定，不等于列表位置：
- **重排**：职责不变，保留原 ID，刷新相邻边界（G26）。
- **插入**：新职责建新 ID，不给后面所有镜头重新编号。
- **内容修订**：同一职责下改构图、站位或边界，保留 ID，重拍开新 take（硬约束 8）。
- **拆分**：原镜被两个以上新职责取代时，停用旧 ID，每个新镜建新 ID；不把旧 ID 偷给其中一个子镜。
- **合并**（例如按 §7b 把同一人相邻两镜并成长镜头）：停用全部旧 ID，建一个新 ID。
- 停用的 ID 不复用于无关镜头（visual-assets §11 同理）。

拆、并、恢复旧职责时，在 `项目开发/决策记录.md` 写一行：前身、后继、停用的 ID 和原因。改完重新核对：剧本对白承载（G11）、`requires_setup` 指向（G32）、`frame_parent` 指向（G40）、相邻边界、总时长，以及审查和剪辑单里还引用旧 ID 的地方；旧 ID 只在决策记录里解释历史，不能再被当前镜头或剪辑单引用。"是不是同一个导演决定"由 director 按镜头职责、信息变化和边界判断，不按文本相似度或数组位置判。

## 10c. 常见反模式

- 镜头表只是改写剧本句子，没说观众怎么看、得到什么变化。
- 把小说旁白按逗号切进镜头，视频提示词只剩"嘴唇开合说话"。
- 资产管理名、文件名、IMG ID 漏进提示词正文；参考图标记插进台词里。
- 无动机运镜（单独一句"镜头缓缓推进"不说为什么）。
- 每句情绪台词都切大特写；相邻两镜同景别、同角度、同关系，切了等于没切（G27）。
- 保留了对白，却删掉承担后果的反应；人物或道具切镜后无故换位。
- 负面约束堆砌：防缺陷补丁在提示词头尾重复上百字，正文动作被稀释；补丁只在目标模型确有该缺陷时加（记入模型观察）。
- 套话式布光（"电影感光影"）代替真实的光源方向和受光结果（§6b 第 7 项）。
