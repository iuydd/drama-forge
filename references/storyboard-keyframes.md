# 分镜与冻结关键帧：一镜一人的镜头语法

## 1. 一镜一人的镜头单位

- 一个镜头只拍一个人或一双手；关系和冲突靠特写与剪辑建立。露第二张脸只允许在 `multi_person_reason` 成立时（例如必须同框的碰杯），且要写 lips closed。
- 每镜一个戏剧任务（情绪步骤：受气 / 加压 / 底牌 / 反击 / 押注 / 兑现 / 新问题）、一个主动作、一次可读的情绪转变。
- 每镜约 5 秒，对白长的按容量加长到 ≤8 秒，不加速。
- 复杂度预算：人数、接触、运镜叠加主体运动、口型与长对白、必须可读文字、状态转换、节拍数——超标就拆镜：拆出插入镜（手、脚、物件）、减少同时动作、把文字移到后期、加强参考。

## 2. 从剧本到镜头：动作只落实一次

先做**动作落实表**：来源动作｜主要落实镜头｜动作前事实｜动作后事实｜其他镜头作用。每个来源动作只有一个主要落实镜头，其他镜头只加反应、细节或新理解。上一镜终点是"右手刚开始伸出"，下一镜才完成取物；上一镜已经取到，下一镜就从"已经持有"开始，不再拿一次（AI 视频最常在下一镜开头把上一镜的动作重演一遍）。

剧本每场每句对白都要有镜头承载（G11）；多句台词按语义闭合点拆到多个单人镜。

## 3. 轴线三行记账与左右唯一读法

每场在 `scenes[].axis` 写三行：

```text
轴线：遥 ↔ 三上（两人连线）
working side：摄影机常驻窗一侧
屏幕方向：遥固定占画面左、面朝画右；三上固定占画面右、面朝画左
```

- 裸写的 left/right 一律指**画面**左右；人物自身的左右带主体（his left hand）。
- 越轴那一镜标 `axis_break` 并写理由，之后重新声明 working side。
- 遥的镜头用窗一侧底板，三上的镜头用投影一侧底板；底板要写清画左画右各是什么（G19）。

## 4. 正反打配对

一镜一人时，两人的空间关系只剩三条线索：屏幕位置、视线方向、机位高度。任何一条对不上，观众会读成两人在看同一个画外第三者。

- A 镜甲在画面左看向右，B 镜乙就在画面右看向左（`facing` 互补，G25）。
- 机位高度按身高差对应：拍高的一方略仰、拍矮的一方略俯；势均力敌用对称的高度与景别，不对称要有理由（压迫感）。
- 过肩镜：本项目允许前景一个虚焦的肩（不露脸）作为第二人；写明前景是谁的肩、占画多少。出拳用过肩镜。
- 同场同人朝向一致（G08）。

## 5. 起点 → 唯一动作 → 终点（边界链）

每镜写一条可见状态链，终点必须能直接当下一镜的起点：

```jsonc
"boundary": {
  "start": {"position": "长桌桌角", "facing": "left", "gaze": "画左的三上", "hands": "右手握笔", "held": "笔", "state": "面无表情"},
  "end":   {"position": "长桌桌角", "facing": "left", "gaze": "画左的三上", "hands": "右手离开桌上的笔", "held": "无", "state": "下巴微抬"}
}
```

- 六个子项写**绝对事实**，不写"同上""保持不变""与上一镜相同"（G24）——图片模型逐张独立生成，看不到上一镜。
- 同场同主体的相邻镜头，前一镜 `end` 与后一镜 `start` 逐项比对（G26）；不一致就是镜外瞬移或道具凭空换手，要么补一镜要么改边界。
- 交接跨镜：物件在甲镜朝乙所在的屏幕一侧出画，在乙镜从对侧入画；写清谁→谁、怎么接、落在哪。
- 状态链"未知 ≠ 恢复默认"：湿发、伤、拿在手里的东西一直有效，直到剧本明确改变。

## 6. 冻结关键帧配方

`keyframe`（中文）和 `frame_prompt`（英文）描述同一格画面，按顺序写：目的 → 焦点主体 → 画框（景别、机位高度、轴线哪侧）→ 地理（前中后景、入口方向）→ 边界投影（起点的位置、朝向、视线、手、持物）→ 表演瞬间（当前景别读得出的载体：视线、呼吸、姿态、持物方式，不写"愤怒"）→ 光（来源方向）→ 文字（无）→ 排除。

- **首帧只写起点**：先与终点做差集，删掉本镜结果里才出现的事实（手已握住、门已开、字已亮）；出现"先、再、随后、最终"、表情从 A 到 B、推拉摇移、进出转身，都移到 motion。判据：一个静物摄影师能否一次拍下全部描述。
- 每个人都写身体朝向；印章字要放的一侧留空（构图偏另一侧，脑后留出空位）。
- 可渲染检查：每人位置与间距、前中后景、视觉重点、景别、机位、光源方向、每人姿态朝向手部持物——接手的人能否照着画出来而不用自己发明事实。
- 约 100–150 词够用；起始帧提示词 = 主体与动作 → 参考图分工 → The scene is set … → Style: …（含一镜一人句和 no text）。
- 视觉依据在成稿后回填：从关键帧正文读出这一格里谁需要被认出，一镜一人时人物条目最多 1 个（画外另注）。

## 7. 景别、切点、节奏

- 景别由"必须读到的信息在哪个尺度"决定，不是情绪越强越近；憋屈段守在中近景/过肩，底牌与反击才进近景、大特写。
- 一场先宽一档定位，再在工作景别上下一格来回（中景 ↔ 中近景 ↔ 近景 ↔ 特写）；不先给空景全景；切点必须带来可见变化（景别、角度、主体至少改一项；同景别同主体跳切是 AI 剪辑感，G27）。
- 3 秒一切是短剧的呼吸；深浅相间、长短相间，避免"均匀病"。
- **反应镜头是免费的戏**：重台词之后切听者的脸 2–3 秒，不需要台词——一镜一人下最便宜的快节奏手段。但用户要"台词多、反应快"：反应镜里听者也可以有一句短反应（当场出声），不留空拍。
- 每集第一切要有主体在动（冷开场认领）；关键动作单独成切给一个 2 秒插入特写作重音；段尾留钩。
- 动接动：切点选在动作中间；上一镜的推近或动作不在下一镜重来。

## 8. 信息顺序：底牌、反应优先、承受者

- 分镜先安排信息再安排景别：什么时候让观众知道底牌，什么时候让反派知道，什么时候看他的反应。爽剧默认观众先于反派看见底牌。
- 事件靠画外声、视线、物体响应证明，镜头留给反应的人；不为证明每个名词切到手机、把手、脚印。底牌实物要看清时给插入镜，信息靠台词说出来，不靠可读文字。
- 打击、否定、翻盘要让观众看到后果被谁接住：反派失去控制、证据被确认、利益真的拿回来，各自有镜头；反应镜放在事实落地之后。
- 每个揭示事实写清：现在给还是扣住、何时释放、靠什么保护（逆光剪影保护身份时不改光源方向）。

## 9. 接触动作与插入镜

- 接触拆三态 before / contact / after，写明谁、哪只手、朝哪边；一镜一人时接触只拍手或只拍承受方。
- 出拳：过肩镜，命中帧起震屏；挨打后接踉跄撞物；不拍两张脸同框互殴。
- 递物、抢物：先拍持有者的手出画（朝对方所在一侧），再拍接收者的手入画（从对侧）；不让物件在两人手里各出现一次。
- 插入镜（`kind: hands/feet/object`）不受一镜一人句约束，但仍写 no text、写清画左画右。

## 10. 门与自检

机械门：G02 一镜一人句；G08 同场同人朝向一致；G23 锁面逐字进起始帧提示词；G24 关键帧/终点/提示词无回指词；G25 同场两人朝向互补；G26 边界链逐项一致；G27 同景别同主体跳切；G13 关键帧长度。

reviewer 判的：切点是否带来可见变化；反应镜是否接住了后果；底牌是否先于反派被观众看见；每个来源动作只落实一次；首帧没有把结果画进去；静音看一遍接触表冲突是否仍可读。
