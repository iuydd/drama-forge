# 原创剧编剧任务（每次开新剧时发给执行代理；【】按需改）

使用 drama-forge 的编剧知识库（references/编剧/）创作，不要只给创作建议。

目标：爽、新颖、有长期追更动力。
不要局限于【修仙、游戏入侵、系统、战神、霸总】。
主角可以很强，不能靠强行削弱来制造悬念（编剧/03）。

1. 先生成 【12】 个核心机制不同的创意（编剧/02 机制指纹去重、编剧/09 两阶段漏斗），筛选 【3】 个，自动选择最值得开发的一个继续。
2. 默认 【24】 集，每集约 【75–90】 秒；交付全季大纲和前 【3】 集完整剧本（剧本格式按 2-剧本.md）。
3. 可以使用"观众知道主角有底气，但对手不知道，群众不断改变风向"的连续反转机制；使用时重点读编剧/15，允许高强度拉扯。但每轮必须有新信息、主角行动或实际后果；不要只重复辱骂、打断揭晓或撤销已经获得的胜利。
4. 把正文、人物设定、能力与资源状态、伏笔、审稿结果和下一批续写状态保存到项目文件（位置见 1-立项与改编.md「原创剧项目文件」）。
5. 不要把大纲当作已完成的正文；不要声称没有数据支持的爆款率或观众效果。
