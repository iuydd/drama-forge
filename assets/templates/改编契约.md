## 来源

- **原著**：【书名 / 原稿名】；文件 `输入/【文件名】`；共【N】章 / 集；sha256【前 12 位】
- **使用权**：【用户声明持有 / 授权方式；说不清的写"未决"】
- **拆解范围**：【全量 / 拆到第 N 章（覆盖本季所需单元 + 1 单元余量）；跳过的章：……】
- **故事框架**：【升级流 / 复仇线 / 单元剧 / 多线交织 / 蜕变成长】
- **开篇替换点**：【第 N 章（sequence）：一句话说那个可见、有代价、当场发生的转折】；它之前观众必须知道的：【……，开场后怎么在当下补进去】
