# 项目启动说明

这是待填写的项目模板，不包含模型绑定、凭证、授权或执行证据。现行规则见 [Skill 入口](../../../SKILL.md)；兼容字段的版本号不是当前 Skill 版本。

- 分工：默认同一 agent 完成前期与生产，绑定冻结任务及有效批准来源；用户明确选择外部 Brain 时才填写对应通道与返回路径。brain 等兼容字段沿用原格式，不要求第二个会话。
- 版本：保留适用的 policy、brain、fidelity 与原门禁，不将旧 PASS 改名升级。
- 生产：按活动集和交付计划推进，在实测资源与有效授权内并发，不以硬件容量代替本次预算。

- 当前任务、活动集/阶段与已验收产物：从真实项目恢复。按本次计划确定交付范围。
- 阅读：先读当前工作契约，再按阶段地图读相关模块，不加载历史补丁。
- 模型与权限：填写本次选用的实际型号、版本、推理设置、能力证据和角色权限。盲看上下文隔离；子代理不持有凭证、生成提交或发布权限。
- 资源与费用：填写实测资源容量、本次并发预算、付费上限及有效授权。只下发依赖和门禁满足的任务；未知提交先对账。
- 环境：连接和凭证由批准的环境映射提供；不把密钥写入此文件或日志。记录实际可用的执行、声音和合成适配器。
- 剧本与表演：先写完整事件，再估片长。角色意图、语气、表情、知情和动作成立；事件/台词 ID 跨拆镜保留。
- 生成：默认实际上传有序独立资产，注明各图职责和完整可见范围；空场景不清掉人员，不融合首帧。锁定动作对象、路径、起终状态与先后关系，保持已锁画质；旧首帧路线仅按明确选择执行。
- 后期：按当前采用音轨和实际事件锚点派生字幕/UI，保护脸、手、证物和动作；核对合成器确实消费派生安排。
- 验收：同次 G3 查看完整声画字幕/UI事件；最终门禁绑定同版成片、时间线、实际渲染输入和观察证据。
- 经验：只在当前项目记录真实问题、证据、处理与适用范围；不混入他人的私人记录。
- 交付：填写所需母版与渠道副本规格；需要手机副本时先核实通道字节上限，保留原母版。
